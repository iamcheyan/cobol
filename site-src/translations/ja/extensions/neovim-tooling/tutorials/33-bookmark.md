# ブックマーク：bookmark.nvim

Aerial で構造を見て、grep で内容を探せます。**では「昨日、途中まで編集したあの場所」はどうやって覚えておけばいいでしょうか？**

bookmark を使えば、任意の行に印を付けて、次回ワンキーで戻れます。

---

## 1. 解決する問題

| 要件 | ブックマークなし | bookmark あり |
|---|---|---|
| 特定の位置を覚える | 記憶または `:marks` に頼る | ブックマークを付ける |
| 複数の位置を移動する | `Ctrl-o` / `Ctrl-i` の履歴 | `]b` / `[b` |
| すべての印を一覧する | できない | `<leader>mm` |
| プロジェクト単位で保存する | できない | できる（プロジェクト単位） |

## 2. 設定

`lua/plugins/bookmark.lua`：

```lua
opts = {
  sign = " ",
  sign_color = "#e0af68",
  mouse = true,
},
```

| オプション | 値 | 意味 |
|---|---|---|
| `sign` | ``  `` | 左端のブックマークアイコン |
| `sign_color` | `#e0af68` | 黄色 |
| `mouse` | `true` | マウスクリックに対応 |

### キー

| キー | コマンド | 動作 |
|---|---|---|
| `<leader>mt` | `:BookmarkToggle` | 現在行のブックマークを切り替える |
| `<leader>mm` | `:BookmarkList` | すべてのブックマークを一覧表示 |
| `]b` | `:BookmarkNext` | 次のブックマーク |
| `[b` | `:BookmarkPrev` | 前のブックマーク |
| `<leader>mc` | `:BookmarkClear!` | **現在のバッファ**のブックマークを消去 |
| `<leader>mC` | `:BookmarkClear` | **プロジェクト全体**のブックマークを消去 |

### `<leader>m` グループに注意

which-key の設定では `<leader>m` は **bookmarks** グループです。`mh`、`mH`、`mt`、`m0`、`ma`、`mA` はすべて本プラグインが使います。

## 3. 使用場面

### 場面1：翌日に作業を再開する

第27レッスンを途中まで編集し、翌日続ける場合：

1. その行にカーソルを移動する
2. `<leader>mt` でブックマークを付ける
3. 翌日、ファイルを開く
4. `<leader>mm` で一覧を表示するか、直接 `]b` を押す

### 場面2：長いファイルの複数箇所に印を付ける

数百行ある第32レッスンで、3箇所を確認したい場合：

1. 各箇所で `<leader>mt`
2. `]b`／`[b` で3箇所を移動する

行番号（`:120`）を覚えるより確実です。行番号は変わりますが、ブックマークは行と一緒に移動します。

### 場面3：コードレビューで気になる点を記録する

他の人のコードを読んで気になる箇所が3つ見つかった場合：

1. 各箇所にブックマークを付ける
2. 読み終えたら `<leader>mm` で振り返る
3. 対応後に `<leader>mc` で消去する

## 4. 練習

### 練習1：ブックマークを付ける

```sh
cd ~/development/cobol
nvim lessons/32_bank-reconciliation-project/lesson.cob
```

1. `1000-INIT` などの段落にカーソルを移動する
2. `<leader>mt`
3. 左端を見る

**合格条件**：左端に `` アイコンが表示される。

### 練習2：移動する

1. ファイル内の別の場所へ移動する
2. `]b` を押す

**合格条件**：ブックマークの位置に戻る。`[b` でも行き来できる。

### 練習3：一覧を表示する

1. 2箇所にブックマークを付ける
2. `<leader>mm`
3. 一覧を見る

**合格条件**：2つのブックマークが表示され、選択して移動できる。

### 練習4：現在のバッファのブックマークを消去する

1. `<leader>mc`

**合格条件**：現在のファイルのブックマークが消え、他のファイルのものは残る。

### 練習5：プロジェクトのブックマークを消去する

1. `<leader>mC`

**合格条件**：**プロジェクト全体**のブックマークが消去される。**こちらは影響範囲が広い**ので注意してください。

### 練習6：マウスを使う

1. 左端のブックマークアイコンをクリックする（`mouse = true`）

**合格条件**：該当位置へ移動するか、関連する操作が実行される。

## 5. つまずいたとき

### ファイルを閉じてもブックマークは残るか

プラグインの保存方式（プロジェクト単位の永続化）によります。通常は次回開いたときにも残ります。**実際に確認してください**。ブックマークを付けて Neovim を再起動し、残っているか見ます。

### `<leader>mC` で消しすぎた

`BookmarkClear` は**プロジェクト全体**に作用します。現在のファイルだけを消すには `<leader>mc`（`BookmarkClear!`）を使います。

### アイコンが四角になる

`sign = " "` にはアイコンフォントが必要です。端末が対応していない場合は四角で表示されます。

### ブックマークは行と一緒に移動するか

ブックマークは行を記録します。行を挿入または削除すると、通常はブックマークもその行に追随します。**ただし、その行自体を削除するとブックマークが消える場合があります。**

### Vim 組み込みの `m` マークと競合する

Vim 標準の `ma` はマークを設定します。プラグインは `<leader>m*` を使うため、プレフィックスが異なり競合しません。

## 6. 他のプラグインとの関係

| 要件 | ツール |
|---|---|
| 「途中まで編集した位置」を覚える | bookmark（`<leader>mt`） |
| ファイル構造を見る | aerial（`<leader>cs`） |
| 定義へ移動する | `gd`（`cobol.nvim` / LSP） |
| 内容を検索する | `<leader>fw`（snacks） |
| 前回の編集位置に戻る | `Ctrl-o` / `gi` |

**bookmark は「手動で印を付ける」機能で、他の機能は「自動で位置を特定する」ものです。**

## 8. 適用範囲

- このページの設定は `lua/plugins/bookmark.lua` に基づきます：`<leader>mt`／`mm`／`mc`／`mC`、`]b`／`[b`、`mouse = true`。
- `<leader>mC` は**プロジェクト全体**を消去し、`<leader>mc`（現在のバッファ）より範囲が大幅に広くなります。
- ブックマークの永続化動作は実際に確認してください。このプラグインは自作（`iamcheyan/`）です。
