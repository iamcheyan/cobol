# 第 19 課 改変練習の参考解答

この解答では `exercise.md` の 2 つの改変練習だけを扱い、応用問題の解答はありません。どちらも一時ディレクトリ内のフィクスチャのコピーで行います：

```sh
scratch=$(mktemp -d)
cp lesson.cob accounts.txt transactions.txt "$scratch/"
cd "$scratch"
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o lesson_19 lesson.cob
```

## 1. 取引ファイルが先に EOF に達する場合

コピーした `transactions.txt` には先頭 2 行だけを残します。取引ストリームがすでに EOF に達していても、プログラムは主ファイルの 3 番目のレコードを独立して読み続けます。最後の集計は次のとおりです：

```text
关闭完成 账户记录数=003 交易记录数=002
```

取引 EOF が設定するのは `WS-TRANSACTION-EOF` だけです。主ファイルの EOF フラグは `N` のままなので、次のループで主ファイルの読み取りが続きます。最初の主ファイル 2 行と 2 件の取引は通常どおり出力され、終了コードは `0` です。

## 2. 空の口座主ファイル

コピーした `accounts.txt` を空にし、4 件の取引は残します。口座ファイルは最初の `READ` で EOF に達しますが、プログラムは取引ファイルの読み取りを 1 件ずつ続けます。最後の集計は次のとおりです：

```text
关闭完成 账户记录数=000 交易记录数=004
```

空の主ファイルによって `WS-TRANSACTION-EOF` が `Y` に設定されることも、取引レコードが飛ばされることもありません。4 件すべての取引が出力され、終了コードは `0` です。

どちらの改変でもソースを変更する必要はありません。各入力の EOF、状態、件数が独立していれば、先に終了したストリームがもう一方を止めることはありません。
