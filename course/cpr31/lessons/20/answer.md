# 第 20 课修改练习参考答案

本答案只覆盖 `exercise.md` 中的两项修改练习，不提供举一反三练习答案。

## 1. 删除账户 A000000004 的交易

删除 `transactions.txt` 中以 `A000000004` 开头的 20 字符行。主档当前键 `A000000003` 小于下一条交易键 `A000000005`，因此程序先报告 `ACCOUNT_ONLY` 并只推进主档。随后 `A000000005` 匹配，`A000000006` 成为交易单边记录。

```text
SUMMARY MATCHED=002 ACCOUNT_ONLY=001 TRANSACTION_ONLY=001
```

## 2. 将交易键改为 A000000003

将第二条交易改为：

```text
A000000003D000005000
```

它仍为 20 字符，且文件保持升序。该键与第二条主档记录相等，程序报告 `MATCH` 并同时推进两边。只剩账户 `A000000001`、`A000000003`、`A000000005` 三个匹配，以及交易 `A000000006` 单边：

```text
SUMMARY MATCHED=003 ACCOUNT_ONLY=000 TRANSACTION_ONLY=001
```
