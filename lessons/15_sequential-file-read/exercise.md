# 第 15 课练习：逐行读取文本文件

所有练习都在临时目录里操作副本：仓库里的 [`transactions.txt`](./transactions.txt) 是共享夹具，不要就地改写，也不要把运行产物留在课目录。先准备一次性运行环境：

```sh
cd lessons/15_sequential-file-read
scratch_dir=$(mktemp -d)
trap 'rm -rf "$scratch_dir"' EXIT
cobc -x -Wall -o "$scratch_dir/lesson_15" lesson.cob
cp transactions.txt "$scratch_dir/"
```

两项修改练习都从这份干净夹具副本开始；跑完删除 `$scratch_dir` 即完成复位。

## 修改练习（答案见 [`answer.md`](./answer.md)）

### 1. 追加第 5 条记录（行顺序与 EOF）

- 基线：原始夹具副本，4 行、195 字节（可见字符 43+53+42+53 = 191，加 4 个换行符）。
- 改动位置与约束：只改临时目录里的夹具副本，不动 `lesson.cob`、不改仓库夹具；新行不超过 100 字符：

  ```sh
  printf 'DAY-20261013|TXN-000005|D|0001234567|10.00\n' >> "$scratch_dir/transactions.txt"
  ```

- 重新编译/运行：只改了输入数据，**不需要重新编译**。运行：

  ```sh
  ( cd "$scratch_dir" && ./lesson_15 ); echo $?
  ```

- 完整预期差异：标准输出多出一行 `レコード=DAY-20261013|TXN-000005|D|0001234567|10.00`；`EOF=はい レコード数=` 由 `04` 变成 `05`；`オープン=OK` 与 `クローズ=OK` 两行不变；退出码仍为 `0`。
- 原因：行顺序文件按行切分记录，追加的行在下一次 `READ` 时被成功读出并计数加一；直到再下一次 `READ` 才触发 `AT END`。

### 2. 空文件（空输入边界）

- 基线：同一份原始夹具副本。
- 改动位置与约束：把副本清空，不动源码：

  ```sh
  : > "$scratch_dir/transactions.txt"
  ```

- 重新编译/运行：不需要重新编译。运行：

  ```sh
  ( cd "$scratch_dir" && ./lesson_15 ); echo $?
  ```

- 完整预期差异：标准输出不再有任何 `レコード=` 行；只剩 `オープン=OK`、`EOF=はい レコード数=00`、`クローズ=OK` 三行；退出码 `0`。
- 原因：空文件仍能成功 `OPEN`；第一次 `READ` 立即进入 `AT END`，所以既没有成功记录，也没有任何错误状态。
