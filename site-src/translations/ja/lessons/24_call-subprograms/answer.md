# 第24課の変更練習解答

[`exercise.md`](./exercise.md) の2つの変更練習を扱います。発展課題は対象外です。両方とも元の2つのソースから始め、それぞれ独立して実施します。変更後はメインプログラムとサブプログラムを一緒にコンパイルします。

```sh
mkdir -p build
cobc -x -Wall -o build/lesson_24 lesson.cob amount_check_24.cob
./build/lesson_24
rm -rf build
```

## 1. 金額上限を1500.00に上げる

元の `amount_check_24.cob` の `0000-VALIDATE-AMOUNT` にある

```cobol
               WHEN LK-AMOUNT > 1000.00
```

を次のように変更します。

```cobol
               WHEN LK-AMOUNT > 1500.00
```

`1000.01` は `0 < 1000.01 ≤ 1500.00` を満たすため、`WHEN OTHER` を通って `VALID` を返します。`9999999.99` は新しい上限を超えるので `LIMIT-EXCEEDED` のままです。全出力（20行）：

```text
呼び出し元：開始
呼び出し前 金額=0000125.50
呼び出し戻り 状態=VALID
呼び出し前 金額=0000000.00
呼び出し戻り 状態=ZERO-AMOUNT
呼び出し前 金額=0001000.00
呼び出し戻り 状態=VALID
呼び出し前 金額=0001000.01
呼び出し戻り 状態=VALID
呼び出し前 金額=0000000.01
呼び出し戻り 状態=VALID
呼び出し前 金額=0000999.99
呼び出し戻り 状態=VALID
呼び出し前 金額=9999999.99
呼び出し戻り 状態=LIMIT-EXCEEDED
呼び出し前 金額=0000500.00
呼び出し戻り 状態=VALID
呼び出し元：サブプログラムから戻り継続
検査総数=008 有効=006 拒否=002
ゼロ金額拒否数=001 上限超過拒否数=001
```

元の実行から変わるのは3行だけです。4件目の状態が `LIMIT-EXCEEDED` から `VALID` になり、最後の件数2行が変わります（有効 `005→006`、上限拒否 `002→001`）。検査総数 `008` とゼロ金額拒否 `001` は変わらず、`8 = 6 + 2` が成り立ちます。

制御フロー：`呼び出し前 金額=` は各 `CALL` 前、`呼び出し戻り 状態=` は同じ `CALL` の後に表示されます。8件の後に `呼び出し元：サブプログラムから戻り継続` が表示されるため、メインプログラムが続いて `PERFORM 3000-DISPLAY-SUMMARY` を実行し、サブプログラムが終了させていないことが分かります。

## 2. ゼロ金額ケースを1セントにする

元の `lesson.cob` の `1200-CHECK-ZERO-AMOUNT` にある

```cobol
           MOVE ZERO TO WS-AMOUNT
```

を次のように変更します。

```cobol
           MOVE 0.01 TO WS-AMOUNT
```

`0.01` はゼロではなく、`1000.00` 以下なので、サブプログラムは `VALID` を返します。`1500-CHECK-SMALL-POSITIVE` と同額のため、`金額=0000000.01` が2回出力されます。全出力：

```text
呼び出し元：開始
呼び出し前 金額=0000125.50
呼び出し戻り 状態=VALID
呼び出し前 金額=0000000.01
呼び出し戻り 状態=VALID
呼び出し前 金額=0001000.00
呼び出し戻り 状態=VALID
呼び出し前 金額=0001000.01
呼び出し戻り 状態=LIMIT-EXCEEDED
呼び出し前 金額=0000000.01
呼び出し戻り 状態=VALID
呼び出し前 金額=0000999.99
呼び出し戻り 状態=VALID
呼び出し前 金額=9999999.99
呼び出し戻り 状態=LIMIT-EXCEEDED
呼び出し前 金額=0000500.00
呼び出し戻り 状態=VALID
呼び出し元：サブプログラムから戻り継続
検査総数=008 有効=006 拒否=002
ゼロ金額拒否数=000 上限超過拒否数=002
```

2件目の金額は `0000000.00` から `0000000.01` へ、状態は `ZERO-AMOUNT` から `VALID` へ変わります。件数はゼロ金額拒否 `001→000`、上限拒否は `002` のまま、有効 `005→006` です。サブプログラムと上限は変更していないため、`1000.01` は引き続き `LIMIT-EXCEEDED` であり、`8 = 6 + 2` が成り立ちます。
