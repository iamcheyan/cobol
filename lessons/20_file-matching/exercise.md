# 第 20 课练习：顺序键匹配

## 修改练习（答案见 `answer.md`）

将两份夹具复制到临时运行目录，只修改副本。每行长度和账户键顺序都必须保持正确。

1. 从 `transactions.txt` 删除账户号 `A000000004` 对应的整行。运行程序，检查主档键 `A000000003` 如何与当前交易键比较，并记录 `MATCHED`、`ACCOUNT_ONLY`、`TRANSACTION_ONLY` 计数。
2. 从原始夹具出发，把交易文件中的 `A000000004` 键改成 `A000000003`，并将金额改为 `000005000`。确认交易与主档键相等时两条流同时前进。

每次修改后保留完整输出。说明哪个分支推进了主档、交易，或两者。
