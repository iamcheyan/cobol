# 第 08 課演習：ミニ口座取引バッチ

この演習では第 01〜08 課で学んだ `WORKING-STORAGE` 項目、`MOVE`、`COMPUTE`、`IF`、`EVALUATE`、`PERFORM VARYING`、名前付き段落のみを使います。サンプルデータはプログラム内に固定され、ファイル、表、データベースは使いません。

## 変更演習（解答例は `answer.md`）

2つの変更は重ねず、それぞれ元の `lesson.cob` から始めます。実行後は最終残高だけでなく、出力全体を確認してください。

1. `WS-OPENING-BALANCE` の初期値を `1000.00` から `2000.00` に変更します。コンパイル・実行し、`処理件数`、`承認件数`、`拒否件数`、`最終残高` を記録します。
2. `2100-LOAD-SAMPLE` の `WHEN 3` にある出金額を `1500.00` から `1085.40` に変更します。その時点で利用可能な残高と同額の出金が受理されるか確認し、最終残高と結果件数を記録します。

各変更後に実行します。

```sh
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_08 lesson.cob
./build/lesson_08
```

解答例は、この変更演習のみを扱う `answer.md` を参照してください。

## 学んだことを応用する（解答なし）

固定バッチに第6取引を追加します。取引コードと金額を選び、受理されるか説明し、各取引後の残高を記録してください。最後に `処理件数`、`承認件数`、`拒否件数`、`最終残高` を示します。現在残高と同額の出金を少なくとも1件含め、実際に処理した取引数だけ `処理件数` が増えることも確認してください。

最後のサンプル番号と読込ロジックも必要に応じて更新します。サンプルは固定データのままにし、ファイル入力、表、データベースは追加しません。変更後の固定形式ソース全体、コンパイルコマンド、実出力、終了コードを提出してください。解答はありません。
