# L3 フィクスチャ

フィクスチャは顧客集計の4ストリーム入力（ACCOUNT、L2 accepted TRANSACTION、CUSTOMER SNAPSHOT、PREVIOUS-DAY）を構成する合成データです。バイナリ/テキストのレイアウトとバージョンは、隣接するCopybookおよびDESIGN.mdに定義されています。入力はASCIIの固定幅レコードでLF終端です。日付とキーは顧客順、口座順、突合を確認できるよう選んでいます。

`normal/`は手作業で追跡するケースです。`cases/`には境界条件と業務隔離ケースがあり、顧客snapshot欠落、無効顧客、古いsnapshot、顧客数/件数上限を含みます。`expected/`には独立して求めた期待出力があります。構造エラーはRC8で公開されず、業務隔離はRC4となり、適格レコードを公開し、隔離レコードは理由とともに保持します。
