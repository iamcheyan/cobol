# 第 06 課 演習：PERFORM

この演習で使うのは第 06 課で学んだ内容だけです：`PERFORM VARYING` のカウントループ、`EVALUATE` による分類、`COMPUTE` による累計、そして `DISPLAY` 出力。

## 修正演習（`answer.md` に参考解答があります）

この課の元の `lesson.cob` から出発し、毎回 `WS-LAST-SAMPLE` の `VALUE` だけを `0`、`1`、`3`、`4` に設定し、他のソースコードは変更しません。

1. `0`：ループ本体は 0 回実行される。
2. `1`：第 1 筆のサンプルだけを処理する。
3. `3`：3 筆の固定サンプルを処理する。
4. `4`：3 筆の既知サンプルと 1 筆の `UNMAPPED` を処理する。

毎回修正したあと再コンパイルして実行します。

```sh
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_06 lesson.cob
./build/lesson_06
```

それぞれの値について表示されるサンプル行数と `WS-PROCESSED-COUNT` の値を記録し、インデックスが最終番号と等しいときにループ本体がそれでも実行される理由を説明してください。参考解答は `answer.md` を参照。

## 発展演習（参考解答はありません）

4 筆の固定支払いサンプルを設計し、`PERFORM VARYING` で順番に処理し、各回で番号・カテゴリ・金額を表示し、ループ終了後に処理件数をまとめて表示してください。`EVALUATE` を使って番号ごとに各サンプルを出力し、表・ファイル・名前付き段落は使わないこと。

最終番号が 0 と 4 のそれぞれの場合でテストし、完全な固定書式ソースコード、実際のコンパイルコマンド、両方の境界での実際の出力と終了コードを提出し、「最終番号が 0 のとき 1 筆も処理されない」ことをどうやって確認したかを説明してください。
