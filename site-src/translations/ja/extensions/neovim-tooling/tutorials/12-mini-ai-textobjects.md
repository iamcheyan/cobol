# テキストオブジェクト：mini.ai

`ciw`（単語を変更）、`di(`（括弧内を削除）は Vim 標準のテキストオブジェクトです。**mini.ai はテキストオブジェクトを「文字境界」から「意味上の境界」へと拡張します。**

COBOL でよくある場面です。カーソルが `WS-ACCOUNT-STATUS` の途中にあり、識別子全体を変更したいとします。`ciw` はハイフンで止まります。`-` は `iskeyword` の一部ではないからです。必要なのは `cia`（「引数」を変更）か `cii`（インデントされたブロックを変更）です。

---

## 1. 解決する問題

Vim 標準のテキストオブジェクトには `w`、`s`、`(`、`"` など、文字単位の境界しかありません。実際のコーディングでは、**構造**に基づいて選択する必要があります。

| 選択したいもの | 標準の方法 | mini.ai |
|---|---|---|
| 関数呼び出し全体 `foo(a, b)` | 手動で `f(` `%` | `au`（around usage） |
| 引用符内の内容（引用符の種類を問わない） | `ci"` または `ci'` を試す | `ciq`（任意の引用符） |
| ファイル全体 | `ggVG` | `a g`（`ag`） |
| インデントブロック | `vii` は使えない | `aii` / `iii` |
| 数値 | `diw` の後に手動で修正 | `did`（digit） |

mini.ai の方法は、**カーソルの文脈を判断して適切な境界を自動で見つける**ことです。


![4 つの `PIC` の幅はそれぞれ違います。`ciw` はハイフンで止まり、`ciW` なら語全体を置換できます。](images/12-textobjects-context.png)

4 つの `PIC` の幅はそれぞれ違います。`ciw` はハイフンで止まり、`ciW` なら語全体を置換できます。

## 2. 設定内容

`lua/plugins/mini-ai.lua` に設定があり、`n_lines = 500`（検索範囲の上限は500行）です。

### カスタムテキストオブジェクト

| オブジェクト | 意味 | 説明 |
|---|---|---|
| `o` | block / conditional / loop | Treesitter ブロック |
| `f` | function | 関数 |
| `c` | class | クラス |
| `t` | tag | HTML/XML タグ |
| `d` | digit | 数字 |
| `e` | CamelCase / snake_case | 複合語 |
| `g` | entire buffer | ファイル全体 |
| `u` | usage / 関数呼び出し | 関数呼び出しの括弧内 |
| `U` | usage（ピリオドを含まない） | 同上。関数名に `.` を含めない |
| `a` | argument | 引数 |
| `i` | indent | インデントブロック |
| `q` | quote | 任意の引用符（`"` `'` `` ` ``） |
| `b` | 任意の括弧ペア | `()` `[]` `{}` |
| ` ` | whitespace | 連続した空白 |

### 接頭キー

`i`（inner、境界を含まない）と `a`（around、境界を含む）を使います。

```text
ia   一个参数
aa   参数及其逗号
ii   缩进块内部（不含首尾行）
ai   缩进块整体
iq   引号内内容
aq   连同引号
```

## 3. COBOL で便利な組み合わせ

### ケース1：識別子全体を変更する

カーソルが `WS-ACCOUNT-STATUS` の任意の位置にある場合：

```text
cia      改一个参数（整个 word，包含连字符）
```

**`ciw` を使うとどうなるか**：`-` はキーワード文字ではないため、`ciw` は `WS` だけを選択し、結果は `新しい名前-ACCOUNT-STATUS` になります。

**注意**：`a`（argument）は mini.ai による「引数」の判定に依存します。`PIC X(10)` では識別子全体ではなく `X(10)` が選択されることがあります。**最も確実なのは、先に目視で確認するか、直接 `viW` を使うこと**です（vimgrep の W は空白区切りの単語です）。

### ケース2：PIC 節全体を選択する

```text
vi(      选括号内（10）
va(      连同括号（X(10)）
```

### ケース3：文字列リテラル全体を選択する

```text
viq      引号内内容（不管单双引号）
vaq      连同引号
```

`ciq` は「引用符内を、元の値に関係なくすべて置き換える」操作です。シングル引用符かダブル引用符かを事前に確認する必要がないため、`ci"` より便利です。

### ケース4：DIVISION ブロック全体を選択する

Treesitter の COBOL parser が必要です。設定には明示的に次の記述があります。

```lua
-- COBOL currently has no Treesitter parser in this configuration.
-- Keep mini.ai's Treesitter objects available for other languages,
-- but make them a no-op instead of raising an error in COBOL buffers.
if vim.tbl_contains({ "cobol", "cbl", "cob" }, vim.bo.filetype) then
  return {}
end
```

**そのため、COBOL buffer では `iao`、`iaf`、`iac` は動作しません**。これはエラーを避けるため、設定作成者が意図して機能を制限しています。COBOL 以外のファイル（Lua、Python、JS）では使えます。

## 4. よく使うオブジェクト早見表

| コマンド | 動作 |
|---|---|
| `cia` | 1つの引数を変更 |
| `ciq` / `caq` | 引用符内を変更 / 引用符も含める |
| `vii` / `vai` | インデントブロックの内側 / 全体を選択 |
| `di(` / `da(` | 括弧内 / 括弧ごと削除 |
| `yig` / `dag` | ファイル全体をコピー / 削除 |
| `cid` | 数字を変更 |
| `cie` | CamelCase または snake_case の単語を変更 |
| `viu` | 関数呼び出しの括弧内を選択 |

### `ig` の特徴

`ig`（inner entire buffer）は先頭と末尾の空行を飛ばします。`ag` はすべてを含みます。ファイル全体をまとめて処理するときに便利です。

```text
ggdag    删除整个文件内容
```
⚠️ 危険な操作です。まず `u` を押して取り消せることを確認してください。

## 5. which-key との連携

設定では27個のテキストオブジェクトが which-key に登録されています。`a` または `i` を押して**少し待つ**と、利用可能なオブジェクトの一覧が表示されます。

```text
 a  around
 i  inner
```

続けてオブジェクトの文字を押します。文字が分からないときは、これが最も手早い方法です。

## 6. 練習

### 練習1：`ciw` と `cia` を比較する

```sh
cd ~/development/cobol
nvim lessons/25_using-parameters/lesson.cob
```

1. カーソルを `AMOUNT-ARGUMENT` の途中に置く
2. `ciw` を押し、`X` を入力して `<Esc>` を押す —— 結果を確認する
3. `u` で元に戻す
4. `cia` を押し、`X` を入力して `<Esc>` を押す —— 結果を確認する

**確認ポイント**：`ciw` は `-` で区切られた一部分だけを変更し、`cia` は単語全体を変更します。この比較が mini.ai の価値を理解する近道です。

### 練習2：`ciq` で引用符内を変更する

1. `VALUE "C0001042"` のような行を見つける
2. カーソルを引用符内に置く
3. `ciq` を押して新しい値を入力する

**確認ポイント**：シングル引用符かダブル引用符かを事前に確認せず、内容を変更できます。

### 練習3：`yig` でファイル全体をコピーする

1. `yig` を押す
2. `:new` で新しい buffer を開く
3. `p` を押す

**確認ポイント**：ファイル全体がコピーされ、先頭と末尾に余分な空行はありません（`ig` は空行を飛ばします）。

### 練習4：インデントブロック

インデントのある任意のコードブロック（例：`IF ... END-IF`）で：

1. `vii` で内側を選択する
2. `d` で削除する
3. `u` で元に戻す

**確認ポイント**：選択範囲が `IF` の次の行から `END-IF` の前の行までになっています。

### 練習5：which-key を確認する

1. `a` を押して1秒待つ
2. 表示された一覧を確認する
3. `<Esc>` で終了する

**確認ポイント**：27個のテキストオブジェクトの名前と説明が表示されます。

## 7. つまずきやすい点

### COBOL で `iao` が効かない

COBOL の filetype では Treesitter の COBOL parser がないため、設定が空の一覧を返します。**これはバグではなく、エラーを防ぐための動作です。** 代わりに `vii` を使ってください。

### `cia` が意図しない範囲を選ぶ

`a`（argument）の境界判定は文脈によって異なります。`PIC X(10)` では `X(10)` だけが選択されることがあります。**範囲が不確かな場合は、まず `v` で Visual mode に入り、選択範囲を確認してから操作してください。**

### `ig` でファイル全体を削除して慌てる

`u` で元に戻せます。Neovim を終了していなければ、Vim の undo tree を使って確実に取り消せます。

### `n_lines = 500` を超えると動かない

mini.ai は上下500行までしか検索しません。非常に大きなファイルで離れた場所に移動すると、境界を見つけられないことがあります。これは性能を守るための制限です。

## 9. 適用範囲

- この記事のキー設定は、あなたの設定（`lua/plugins/mini-ai.lua`）に基づきます。テキストオブジェクトは27個で、`n_lines = 500` です。
- **COBOL buffer では `o`、`f`、`c` の3つの Treesitter オブジェクトが設定により無効化されています**（COBOL parser がないため）。動作を期待しないでください。
- `a`（argument）の境界判定は文脈に依存するため、位置によって結果が変わります。COBOL では `W`（空白区切りの単語）のほうが予測しやすいです。
- [マルチカーソルの記事](08-multicursor-batch-editing.md)と組み合わせるのがおすすめです。`viq` で選択した後にマルチカーソルを追加すると、複数の文字列をまとめて変更できます。
