# 囲み記号の編集：mini.surround

数字の列を引用符で囲む、`(` を `[` に変える、括弧を一段削除する。手作業では「先頭に移動、挿入、末尾に移動、挿入」という手順になります。

mini.surround を使うと、**3つのキーと対象の記号**で操作できます。

---

## 1. 解決する問題

| 作業 | 手作業 | mini.surround |
|---|---|---|
| 単語を引用符で囲む | `i"` `<Esc>` `a"` `"` | `gsa"` |
| `(` を `[` に変える | 2つの括弧をそれぞれ変更 | `gsr([` |
| 外側の引用符を削除 | 2か所を削除 | `gsd"` |
| 行全体を括弧で囲む | 両端を手作業で編集 | `gsa(`（Visual mode で選択後） |

## 2. 設定内容

`lua/plugins/mini-surround.lua`：

```lua
mappings = {
  add = "gsa",
  delete = "gsd",
  replace = "gsr",
  find = "gsf",
  find_left = "gsF",
  highlight = "gsh",
  update_n_lines = "gsn",
}
```

| キー | 動作 |
|---|---|
| `gsa` | **add**：囲み記号を追加 |
| `gsd` | **delete**：囲み記号を削除 |
| `gsr` | **replace**：囲み記号を置換 |
| `gsf` | **find**：次の囲み記号を前方検索 |
| `gsF` | **find_left**：後方検索 |
| `gsh` | **highlight**：カーソル位置の囲みを強調表示 |
| `gsn` | 検索行数を更新（既定値は20行） |

`gs` は固定の接頭キーです。その後に操作を表す文字、さらに**対象の記号**を続けます。

## 3. 追加：`gsa`

### 基本的な使い方

単語にカーソルを置き、`gsa` の後に記号を入力します。

```text
gsa"      给当前词加双引号
gsa'      加单引号
gsa)      加圆括号（自动匹配成 ( )）
gsa(      同上
gsa]      加方括号
gsa}      加花括号
gsa<      加尖括号
```

### 行全体に追加する

```text
gsa<CR>   给当前行加换行包围？不——需要先选中
```

正しい方法は、先に**Visual mode**で複数行を選択し、その後 `gsa)` を押すことです。各行に括弧が追加されます。

実際の操作例（COBOL の場合）：

```text
V 选中 3 行
gsa"      每行都加上了双引号
```

### カスタム記号

囲み記号には任意の文字列を入力できます。

```text
gsa<space>   加一个空格
gsa DIVISION.
```

mini.surround は「囲み記号として任意のテキストを入力する」機能をサポートしています。README では、`gsa` の後に `f`（find right）などの特殊キーを入力する例が紹介されています。**実際によく使うのは、単一文字の記号です。**

## 4. 削除：`gsd`

```text
gsd"      删掉最近的引号对
gsd)      删掉最近的括号对
gsdb      删除最近的一对，任意类型
```

`gsdb`（b = bracket）は、種類を問わず**直近の**囲み記号を削除します。外側がどの種類の括弧か分からないときに使います。

## 5. 置換：`gsr`

```text
gsr("     把 ( ) 换成 " "
gsr)'     把 ( ) 换成 ' '
gsr*}     把 { } 换成 * *
```

**先に古い記号、次に新しい記号を入力します。** 2文字を続けて入力してください。

## 6. 検索と強調表示

| コマンド | 動作 |
|---|---|
| `gsf"` | 次の `"` を前方検索 |
| `gsF"` | 前の `"` を後方検索 |
| `gsh` | カーソルがあるペアを強調表示 |

`gsh` は、括弧が何重にも入れ子になっている場所で特に便利です。押すと、自分がどの階層にいるか分かります。

## 7. COBOL で便利な場面

### ケース1：複数のフィールドを引用符で囲む

```cobol
01  WS-FLAG-A  PIC X(1) VALUE A.
01  WS-FLAG-B  PIC X(1) VALUE B.
```

`A` と `B` をそれぞれ `"A"` と `"B"` にします。

1. `A` にカーソルを置く
2. `gsa"` を押す

より効率的な方法は、マルチカーソル（`<leader>n` で順に一致箇所を選択）を使ってから、一度だけ `gsa"` を押すことです。

### ケース2：`PIC X(10)` の括弧を変更する

```text
光标在 (10) 内
gsr(]    括号从 ( ) 变成 [ ]  ← 语法上 demo 用，实际 COBOL 不用方括号
```

**注意**：COBOL の `PIC` で使えるのは丸括弧だけです。この例は置換操作そのものを示しています。

### ケース3：`COPY` のファイル名を引用符で囲む

```cobol
COPY ACCOUNT-REC.CPY.
```

次のように変わります。

```cobol
COPY "ACCOUNT-REC.CPY".
```

1. `ACCOUNT-REC.CPY` にカーソルを置く
2. `gsa"` を押す

### ケース4：余分な括弧の階層を削除する

```cobol
COMPUTE X = ((A + B)).
```

内側にカーソルを置き、`gsd)` を押すと一段削除され、`COMPUTE X = (A + B).` になります。

## 8. 練習

### 練習1：引用符を追加する

```sh
cd ~/development/cobol
nvim lessons/23_copybooks/lesson.cob
```

1. `COPY ファイル名.` という文を見つける
2. ファイル名にカーソルを置く
3. `gsa"` を押す

**確認ポイント**：ファイル名が引用符で囲まれます。

### 練習2：括弧の種類を変える

`( )` を含む任意の行で：

1. 括弧内にカーソルを置く
2. `gsr("[` を押す

**確認ポイント**：`(` と `)` が `[` と `]` に変わります。

### 練習3：一段削除する

1. 括弧が二重になっている算術式を見つける
2. 内側にカーソルを置く
3. `gsd)` を押す
4. `u` で元に戻す

**確認ポイント**：直近の一段だけが削除され、外側は残ります。

### 練習4：`gsh` で位置を確認する

1. 括弧が入れ子になった `COMPUTE` 文を見つける
2. 中ほどにカーソルを置く
3. `gsh` を押す

**確認ポイント**：現在の階層に対応する括弧のペアが強調表示されます。

### 練習5：複数行をまとめて括弧で囲む

1. `V` で `DISPLAY` 文を3行選択する
2. `gsa(` を押す

**確認ポイント**：3行がそれぞれ括弧で囲まれます（選択範囲全体を一度だけ囲むのではありません）。

### 練習6：テキストオブジェクトと組み合わせる

1. `viq` で引用符内の内容を選択する
2. `gsa'` でシングルクォートに変える

**確認ポイント**：テキストオブジェクトと surround を組み合わせて使えます。

## 9. つまずきやすい点

### `gsa` が反応しない

`gsA` ではなく `gsa` であることを確認してください。また、**続けて記号を入力する必要があります**。`gsa` だけではなく `gsa"` のように入力します。

### 置換後の記号が合わない

`gsr("[` の順序は「古い記号 → 新しい記号」です。`gsr["(` と入力すると `[` を `(` に変えようとします。一致するものがなければ何も起きません。

### 対象の記号が見つからない

既定では上下20行までしか検索しません。入れ子が深い場合は `gsn` で範囲を広げます。

```text
gsn100
```

### `gsd` で違う階層を削除する

削除されるのは**直近の**階層です。カーソル位置が重要です。先に `gsh` を押し、削除したい階層が強調表示されることを確認してください。

### COBOL のコメント行にある括弧

コメント行（7列目が `*`）にある括弧も認識されます。操作前に、カーソルがコメント内にないことを確認してください。

## 11. 適用範囲

- この記事のキー設定は、あなたの設定（`lua/plugins/mini.surround.lua`）に基づきます。既定の接頭キーは `gs` です。
- 検索範囲の既定値は20行で、`gsn` で変更できます。
- COBOL の `PIC` 構文で使えるのは丸括弧だけです。`gsr("[` のような置換は、COBOL の実際の `PIC` 節には使わず、操作のデモにとどめてください。
- 複数行をまとめて記号で囲む場合は、先に Visual mode で選択してから `gsa` を使います。選択範囲全体ではなく、**各行に個別に**記号が追加されます。
