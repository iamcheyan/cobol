# 第 22 课修改练习参考答案

本答案只覆盖 `exercise.md` 中的两项修改练习，不提供举一反三练习答案。每项都从原始夹具副本开始运行。

## 1. 把孤立交易改为账户 A000000009

替换原记录：

```text
A000000004D000007500
```

为：

```text
A000000009D000007500
```

运行输出中，该交易被接受；账户 `A000000009` 不再是只有主档的账户。摘要变为：

```text
SUMMARY INPUT=006 SORTED=006
ACCEPTED=004
REJECTED=002 MASTER_ONLY=000
```

接受文件新增：

```text
A000000009C0001009D000007500
```

拒绝文件只剩 `A000000006` 的 `NO_ACCOUNT` 记录和 `A000000007` 的 `BAD_AMOUNT` 记录。

## 2. 修正账户 A000000007 的金额

把最后一条交易从：

```text
A000000007D00000X001
```

改为：

```text
A000000007D000000001
```

九位金额字段变为纯数字，因此记录进入接受文件。摘要变为：

```text
SUMMARY INPUT=006 SORTED=006
ACCEPTED=004
REJECTED=002 MASTER_ONLY=001
```

接受文件新增：

```text
A000000007C0001007D000000001
```

拒绝文件仍有 `A000000004`、`A000000006` 两条 `NO_ACCOUNT` 记录。金额字段代表 0.01；程序只做格式验证和输出，不更新主档余额。
