# Standalone COBOL Examples

These examples can be read and run independently of the 32-lesson main curriculum. We recommend completing the corresponding main lessons first, then using these as topic-focused exercises.

| Example | Corresponding lessons | Practice topics |
|---|---|---|
| `INPUTCSV.COB` | Lessons 18, 23 | `UNSTRING`, Copybooks, CSV output |
| `FIXEDREC.COB` | Lessons 10, 17 | Fixed-length records, `REDEFINES`, status validation |
| `TBLSRCH.COB` | Lessons 11, 13 | `OCCURS`, `SEARCH ALL` |
| `BATCHRPT.COB` | Lessons 22, 32 | Sorted input, control breaks, audit reports |

Run from this directory:

```sh
make check
make run
make clean
```
