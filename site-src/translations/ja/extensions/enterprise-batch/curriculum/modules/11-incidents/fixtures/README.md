# モジュール11 フィクスチャガイド

各フィクスチャは、`MANIFEST`（営業日、レイアウトバージョン、ファイルチェックサム）と宣言されたファイル本体を含む**入力ディレクトリ**です。障害フィクスチャは「入力ディレクトリに配信された生の入力」であり、**変更してはいけません**。`fixtures/SHA256SUMS`は`instructor/modules/11-incidents/tools/gen_course.py`が生成し、`scripts/check.py`が実行の前後に照合します。

フィクスチャの名前には**中立な事象ID**を使用しています。この表には症状と元のRCのみを記載し、**根本原因は含みません**。各夹具の根本原因（講師用）は`instructor/modules/11-incidents/INSTRUCTOR.md`および対応する`ROOT-CAUSE.md`を参照してください。

| フィクスチャ | 症状（根本原因を含まない） | 発見時RC |
|---|---|---:|
| `normal/` | 口座3件、正常な取引4件、拒否なし | 0 |
| `INC-2026-001/` | JOB002の構造エラー。当日の公開なし | 8 |
| `INC-2026-002/` | 現状のシステムがRC0で公開するが、残高が業務台帳と一致しない | 0（欠陥） |
| `INC-2026-003/` | JOB001が中止（ファイルとManifestの宣言が不一致）。公開なし | 12 |
| `INC-2026-004/` | JOB005が中止し、候補が生成されない | 8 |
| `INC-2026-005/` | JOB003が中止（実行環境への注入）。公開なし | 12 |
| `INC-2026-006/` | 現状のシステムがRC0で公開するが、制御合計が上流の宣言と一致しない | 0（欠陥） |
| `INC-2026-007/` | JOB002の構造エラー（レコード長／配置の不一致）。公開なし | 8 |

- `INC-2026-005`の入力は`normal`と同一です。障害は実行環境に起因します（`student/run.sh`を参照）。
- データは固定の決定論的データ（FR-10）で、乱数やseedは使用しません。
- 各事象の**元入力の複製**は`INC-2026-00X/student/input/`に別途保存されており、内容は同一です。
- `enterprise-customer/customer.v1`は**入力ディレクトリの夹具ではありません**。これは11.5保守課題用の独立したバージョン管理対象の企業顧客レイアウトV1基準（23バイト）で、MANIFESTはありません。移行／ロールバック／並行検証にのみ使用します。

生成コマンド：`python3 instructor/modules/11-incidents/tools/gen_course.py`（`fixtures/`、`expected/`、`SHA256SUMS`を再生成します）。
