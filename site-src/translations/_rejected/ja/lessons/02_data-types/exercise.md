# 第 02 課 演習：データ型と PIC

この演習で使うのは第 01 課と第 02 課で学んだ内容だけです。固定書式のソースファイル、`PIC` / `VALUE` フィールド宣言、`DISPLAY` 出力、`STOP RUN`。`MOVE`、算術、条件、ループ、グループ項目、ファイル操作は使いません。

値を変える前に、一つ考えてください。このフィールドは「識別子」なのか「数量」なのか。一度でも間違えれば先頭ゼロは消え、下流の突き合わせがすべて噛み合わなくなります。

## 修正演習（`answer.md` に参考解答があります）

### 基準

この課の元の [`lesson.cob`](./lesson.cob)（プログラム名 `DATA02`、`WORKING-STORAGE SECTION` にフィールドが平らに並んでいます）から始めてください。発展演習には先に取りかからないでください。

### 変更箇所と制約

次の 3 つのフィールドの `VALUE` 句だけを変更してください。`PIC`、フィールド名、フィールドの順序、`PROCEDURE DIVISION` はそのままにします。

1. `WS-BRANCH-CODE`：初期値 `2048` を `3107` に変更（`PIC 9(4)` はそのまま）。
2. `WS-CURRENCY-CODE`：初期値 `"USD"` を `"EUR"` に変更（`PIC X(3)` はそのまま）。
3. `WS-CUSTOMER-NUMBER`：初期値 `"0002046819"` を `"0000000042"` に変更（`PIC X(10)` はそのまま）。

3 つ目では、顧客番号がなぜ `PIC 9(10)` に変更せずにテキスト型のままなのかを説明してもらいます。

### 再コンパイルと実行

```sh
mkdir -p build
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_02 lesson.cob
./build/lesson_02
```

### 完全な期待差分

元のプログラムの標準出力と比べ、ちょうど 3 行だけが異なり、他の 26 行は 1 バイトも変わりません。

| 元の出力行 | 修正後の出力行 | 理由 |
|---|---|---|
| `支店コード=2048` | `支店コード=3107` | `9(4)` の初期値を 2048 から 3107 に変更。4 桁の幅は変わらない |
| `通貨コード=USD` | `通貨コード=EUR` | `X(3)` の 3 文字を `EUR` に置き換え |
| `顧客番号=0002046819` | `顧客番号=0000000042` | `X(10)` は 1 文字ずつ保存し、先頭の 8 個のゼロをそのまま残す |

`cobc -fsyntax-only` と `cobc -x` はどちらも 0 を返し、診断メッセージは出ません。プログラムの終了コードも 0 です。`value size exceeds data size` のような警告が出た場合、変更が宣言した幅を超えています。`PIC` を誤って書き換えていないか確認してください。

### 境界セルチェック（本演習の一部）

`WS-BRANCH-CODE` の初期値を一時的に `12345` に変更し、コンパイル（`-Wall` の有無で比較可）して実行し、コンパイラの出力とプログラムが印刷した支店コードを記録してください。終わったら `3107` に戻してください。この結果が `PIC 9(4)` の幅宣言とどう関係しているか、そして `-Wall` を付けなくてもこの警告が出るかどうかを説明してください。

## 発展演習（参考解答はありません）

ある保険会社の夜間バッチのために、保険の平なフィールドカタログを作成してください。最低でも以下を含めてください。保険番号（先頭ゼロを含む）、契約者名、通貨、保険料、保障額、契約発効日、ステータスコード。

要件：

- 第 02 課で学んだ独立したフィールド宣言、`PIC`、`VALUE`、`DISPLAY` のみを使ってください。グループ項目、`MOVE`、条件、ループ、ファイル操作は使いません。
- 各フィールドについて、名前、`PIC`、初期値を書き、それが識別子・数量・金額のどれに当たるかを示してください。金額の場合は整数部と小数部の桁数を明記してください。
- どのフィールドがビジネス上の検証を依然必要とするか（例：発効日の暦上の妥当性、ステータスコードの合法値）を指摘してください。
- ソースコード、選定理由、実際のコンパイルコマンドと実行出力を提出し、各フィールドの出力幅が宣言した `PIC` と一致することをどう確認したか説明してください。
