# カラー編集：ccc.nvim

CSS、Lua、ターミナル配色ファイルに `#3b82f6` と書かれているとき、どんな色か知りたい、少し明るくしたい、`rgb()` に変換したいと思っても、16進数を手作業で編集するのは大変です。

ccc.nvim はカラーピッカーと形式変換機能を提供します。

---

## 1. 解決する問題

| 要件 | 手作業 | ccc |
|---|---|---|
| `#3b82f6` の色を確認 | 想像するか外部ツールを開く | その場でハイライト表示 |
| 明るさを調整 | RGB を手計算 | スライダーで調整 |
| `rgb()` / `hsl()` に変換 | 手計算またはサイトを利用 | `<leader>cC` |
| 新しい色を選択 | 色コードを覚えて入力 | ピッカーで選択 |

## 2. 設定内容

`lua/plugins/ccc.lua`：

```lua
cmd = { "CccPick", "CccConvert" },
keys = {
  { "<leader>cp", "<cmd>CccPick<cr>", desc = "Color Picker (ccc)" },
  { "<leader>cC", "<cmd>CccConvert<cr>", desc = "Color Convert (ccc)" },
},
opts = {
  highlighter = {
    auto_enable = false, -- 禁用自带的 buffer 高亮
    lsp = false,
  },
},
```

| キー | コマンド | 動作 |
|---|---|---|
| `<leader>cp` | `:CccPick` | カラーピッカーを開く |
| `<leader>cC` | `:CccConvert` | 色の形式を変換 |

### 重要：自動ハイライトを無効化

```lua
highlighter = {
  auto_enable = false,
  lsp = false,
},
```

設定コメントでは理由を次のように説明しています：

```lua
-- 禁用自带的 buffer 高亮，避免与极速的 mini.hipatterns 争抢高亮组
```

**ccc はバッファ内の色コードに自動で背景色を付けます**が、この設定では同じ処理を `mini.hipatterns` が担当します（[mini.hipatterns のページ](29-rainbow-delimiters.md)を参照）。両方が同じハイライトグループを奪い合うため、ここでは ccc の機能を無効にしています。

**その結果**、バッファ内の色ハイライトは ccc ではなく mini.hipatterns によるものです。ccc が動作するのは `<leader>cp` / `<leader>cC` を手動で実行したときだけです。

## 3. カラーピッカー（`<leader>cp`）

色コード（例：`#3b82f6`）にカーソルを置いて `<leader>cp` を押します：

```text
┌─────────────────────────────┐
│  #3b82f6                    │
│  R ████████░░  59           │
│  G █████████░░░ 130         │
│  B █████████████ 246        │
│  ─────────────────────────  │
│  [hex] [rgb] [hsl] ...      │
└─────────────────────────────┘
```

### 操作

| キー | 動作 |
|---|---|
| `h` / `l` | 調整するチャンネルを切り替え（R/G/B または H/S/L） |
| `j` / `k` または `↑` `↓` | 値を増減 |
| `0`–`9` | 数値を直接入力 |
| `<CR>` | 確定 |
| `q` または `<Esc>` | キャンセル |

### 色空間の切り替え

ピッカーは複数の表記形式に対応しています。`Tab` または矢印キーで切り替えます：

- `hex`：`#3b82f6`
- `rgb`：`rgb(59, 130, 246)`
- `hsl`：`hsl(217, 91%, 60%)`
- ほかの形式（設定による）

## 4. 形式変換（`<leader>cC`）

色コード上にカーソルを置き、`<leader>cC` を押して変換先の形式を選びます：

```text
将 #3b82f6 转换为：
  > rgb
    hsl
    ...
```

選択すると、その場で置き換わります。

## 5. COBOL での利用場面

COBOL のソースコードで**色を扱うことはほとんどありません**。ただし、次のような用途があります：

### 場面 1：ターミナル配色やステータスバーのテーマを編集

`~/nvim/colors/` や `lua/config/ui_highlights.lua` で色を定義するとき、`<leader>cp` で色を調整できます。

### 場面 2：コースサイトの CSS を編集

`site-src/site.css` に色の定義があります。テーマ色を変えるには：

1. 色コードにカーソルを置きます
2. `<leader>cp` で調整します
3. 確定します

**注意**：コースサイトの CSS はデザイントークン（`var(--purple)` など）を使っています。色コードを直接変更するとテーマ切り替えが壊れる場合があります。変更前に[第32課](../../../lessons/32_bank-reconciliation-project/README.md)付近のテーマの説明を確認してください。

### 場面 3：mini.hipatterns がハイライトした色を調べる

ccc の自動ハイライトは無効なので、バッファ内の色見本は mini.hipatterns が表示します。具体的な色コードを確認するには `<leader>cp` を開いてください。

## 6. 練習

### 練習 1：カラーピッカーを開く

1. 色コードのあるファイルを開きます（例：`~/nvim/lua/config/ui_highlights.lua`）
2. `#` で始まる色コードにカーソルを置きます
3. `<leader>cp`

**確認ポイント**：現在の色コードを示すカラーピッカーが開く。

### 練習 2：色を調整

1. ピッカーで `j` / `k` を押し、いずれかのチャンネルを調整します
2. バッファ内の色コードがリアルタイムに変わることを確認します
3. `<CR>` で確定します

**確認ポイント**：色コードが変更される。

### 練習 3：キャンセル

1. `<leader>cp`
2. 何度か調整します
3. `q` または `<Esc>` を押します

**確認ポイント**：色コードが変わらず、キャンセルされる。

### 練習 4：形式を変換

1. `#3b82f6` にカーソルを置きます
2. `<leader>cC`
3. `rgb` を選びます

**確認ポイント**：`rgb(59, 130, 246)` のような形式に変わる。

### 練習 5：mini.hipatterns によるハイライトを確認

1. CSS ファイルを開き、色コードに背景色が付くか確認します
2. 設定を確認します

```vim
:lua =require("ccc").config.highlighter
```

**確認ポイント**：`auto_enable = false` であれば、背景色見本は ccc によるものではありません。

## 7. よくある問題

### `<leader>cp` を押しても反応しない

カーソルを色コード（例：`#3b82f6`）の上に置く必要があります。色コード以外の場所で開くと、色が見つからないというメッセージが表示されます。

### バッファに色ハイライトが表示されない

ccc の自動ハイライトは無効です（`auto_enable = false`）。ハイライトは mini.hipatterns が提供します。意図した動作で、故障ではありません。

**ccc でもハイライトしたい場合**：`auto_enable = true` に変更します。ただし mini.hipatterns とハイライトグループを奪い合います。

### 変換後の形式が違う

`<leader>cC` では変換先の形式を選べます。間違えた場合は `u` で元に戻して、やり直してください。

### ピッカーでキー操作が効かない

ピッカーには独自のキー操作があります（`h`/`l` でチャンネル切り替え、`j`/`k` で値を調整）。通常の vim モードとは異なります。利用できる場合は `?` でヘルプを表示してください。

### COBOL ファイルで `<leader>cp` を押しても色が見つからない

正常です。COBOL ソースには色コードがありません。このプラグインは COBOL 開発での用途が限られ、主に設定ファイルや CSS で使います。

## 9. 適用範囲

- このページの設定元は `lua/plugins/ccc.lua` です：`<leader>cp`（ピッカー）、`<leader>cC`（形式変換）。
- **自動ハイライトは無効**（`auto_enable = false`）です。バッファ内の色ハイライトは mini.hipatterns が表示します。ハイライトグループの競合を避けるための設定です。
- COBOL のソースには色コードがほとんどないため、このプラグインは主に設定ファイルや CSS で使います。
- コースサイトの CSS はデザイントークンを使っています。色コードを直接変更すると、明暗テーマの切り替えが壊れる場合があります。
