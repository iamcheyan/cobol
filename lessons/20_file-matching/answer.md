# 第 20 课修改练习参考答案

本答案只覆盖 `exercise.md` 中的两项修改练习，不提供举一反三练习答案。两项都在临时目录的夹具副本上做：

```sh
scratch=$(mktemp -d)
cp lesson.cob accounts.txt transactions.txt "$scratch/"
cd "$scratch"
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o lesson_20 lesson.cob
```

## 1. 删除账户 A000000004 的交易

删除副本 `transactions.txt` 中以 `A000000004` 开头的 20 字符行（删后文件仍有 3 行且保持升序）。此时主档当前键 `A000000003` 小于下一条交易键 `A000000005`，所以程序先报 `口座のみ` 并只推进主档；随后 `A000000005` 与主档配对，`A000000006` 成为交易单边记录：

```text
口座のみ 口座番号=A000000003 顧客番号=C0001003 残高=0000002.00
一致 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75 種別=T 金額=0000040.00
取引のみ 口座番号=A000000006 種別=D 金額=0000020.00
照合件数=002 口座のみ=001 取引のみ=001
```

不变量自查：`2 + 1 = 3`（主档记录数），`2 + 1 = 3`（删后交易记录数）。退出码 `0`。

## 2. 把交易键 A000000004 改为 A000000003

把副本交易文件中以 `A000000004` 开头的那一行改成：

```text
A000000003D000005000
```

它仍是 20 字符，且文件顺序 `A000000001`、`A000000003`、`A000000005`、`A000000006` 保持升序。该键与第二条主档记录相等，程序报 `一致` 并同时推进两边：

```text
一致 口座番号=A000000003 顧客番号=C0001003 残高=0000002.00 種別=D 金額=0000050.00
一致 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75 種別=T 金額=0000040.00
取引のみ 口座番号=A000000006 種別=D 金額=0000020.00
照合件数=003 口座のみ=000 取引のみ=001
```

不变量自查：`3 + 0 = 3`（主档记录数），`3 + 1 = 4`（交易记录数）。退出码 `0`。

两题说明同一件事：分类结果与计数完全由“当前键谁大”决定，所以输入必须真的升序、键必须唯一；程序本身不校验这两点。
