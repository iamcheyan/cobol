# 英単語の練習：VimQuest.nvim

設定しているプラグインの中で、**コードを書かない唯一のプラグイン**です。コードベースを英単語クイズに変えてくれます。

COBOL やプログラミングの識別子、コメント、エラーメッセージの多くは英語です。VimQuest はプロジェクトからコードファイルをコピーし、単語問題をコメントとして挿入して、エディター内で練習できるようにします。

---

## 1. 解決する問題

| 要件 | 一般的な方法 | VimQuest |
|---|---|---|
| プログラミングで使う英単語を学ぶ | 文脈から切り離して単語帳で暗記 | **実際のコードの中で練習** |
| 作業を中断せずに練習する | 別のウィンドウに切り替えて単語を暗記 | Neovim から離れずに練習 |
| 練習した語を覚える | 単語帳は忘れやすい | コードの文脈と組み合わせる |

**目的は「英語学習」であり、「コードを書くこと」ではありません。** ただし、インストール済みなので使い方を知っておくと便利です。

## 2. 動作の流れ

```
1. 扫描项目，随机选代码文件
2. 复制到临时会话目录
3. 把词汇任务作为注释注入（填空、同义替换等）
4. 在任务下方加 Prev/Next 跳转和 Vim 操作提示
5. 你直接改答案行
6. 检查答案 → 开始新一轮或恢复原项目
```

**重要な安全上の点**：ファイルは一時ディレクトリにコピーされ、**元のファイルは変更されません**。終了後に `:VimQuestStop` で元に戻ります。

## 3. 問題形式

| 種類 | 内容 |
|---|---|
| **Fill** | 中国語の意味を手がかりに、文中の空欄に英単語を補う |
| **Replace** | 同義語を中心となる単語に置き換える |
| **Delete** | 文中の余分な単語を削除する |
| **Meaning** | 中国語の説明から英単語を書く |
| **Japanese Meaning** | 日本語の説明から英単語を書く |
| **Example Translation** | 日本語の例文から単語を推測する |

## 4. コマンド

設定では `cmd` として登録されており、`<leader>` のショートカットは割り当てられていません。そのため、**コマンドで実行します**。

| コマンド | 動作 |
|---|---|
| `:VimQuestStart` | 新しいラウンドを開始 |
| `:VimQuestStop` | 停止して元のプロジェクトに戻る |
| `:VimQuestNext` | 次の課題へ移動 |
| `:VimQuestPrev` | 前の課題へ移動 |
| `:VimQuestNextRound` | 元のプロジェクトで次のラウンドを始める |
| `:VimQuestRestart` | 新しい課題で再開する |
| `:VimQuestTasks` | 課題を検索して移動する |
| `:VimQuestList` | すべての課題を quickfix に表示する |
| `:VimQuestCheck` | ラウンド全体を採点してレポートを表示する |
| `:VimQuestHint` | 現在の課題のヒントを表示する |
| `:VimQuestStats` | 今回のラウンドの統計を表示する |
| `:VimQuestWords` | 単語を連続入力する練習を開く |

**注意**：プラグインの README には `<leader>qs` などのデフォルトキーが記載されていますが、この設定では**`cmd` のみを登録**し、キーは割り当てていません。コマンドを使ってください。

### セッション中の `K`

アクティブなセッションでは `K` を押すとヒントが表示されます。セッション外では `K` は LSP hover です。

## 5. 単語練習（`:VimQuestWords`）

下部に2行の小さなウィンドウが表示されます。

```text
account
en: a record of money | ja: 口座 | zh: 账户
```

- 1行目には入力する単語が表示されます。
- 2行目には英語、日本語、中国語の説明が表示されます。
- 正解すると `stdpath("data")/vimquest/words_seen.json` に記録されます。
- 練習済みの単語は `Comment` でハイライトされますが、ランダム候補には残ります。
- `/exit` を入力すると閉じます。
- 右ボタンをドラッグするとウィンドウを移動できます（位置は現在のセッション中に記憶されます）。

## 6. 設定

```lua
require("vimquest").setup({
  task_count = 10,          -- 每轮任务数
  copy_file_count = 10,     -- 复制的文件数
  wordlist = "lua/vimquest/data/ogden-850-words.json",
  exclude_dirs = {
    [".git"] = true,
    ["node_modules"] = true,
  },
  code_extensions = { ... },
})
```

| オプション | 値 | 意味 |
|---|---|---|
| `task_count` | 10 | 各ラウンド10問 |
| `copy_file_count` | 10 | 10ファイルをコピー |
| `wordlist` | Ogden 850語 | 基本語彙リスト |

単語リストは **Ogden Basic English 850語**を使います。英語の中核となる850語です。

## 7. 練習

### 練習1：ラウンドを始める

```sh
cd ~/development/cobol
nvim
```

1. `:VimQuestStart`
2. コピーと課題の挿入が終わるまで待つ

**合格条件**：練習セッションが始まり、コード内にコメント形式の課題が表示される。

### 練習2：回答して採点する

1. 課題にカーソルを移動する
2. 指示に従って回答行に入力する
3. `:VimQuestCheck`

**合格条件**：ラウンド全体の結果レポート（正解数）が表示される。

### 練習3：課題間を移動する

1. `:VimQuestNext`
2. `:VimQuestPrev`

**合格条件**：課題間を移動できる。

### 練習4：ヒントを見る

1. 課題にカーソルを置く
2. `:VimQuestHint`

**合格条件**：その課題のヒントが表示される。

### 練習5：単語を練習する

1. `:VimQuestWords`
2. 表示された単語を入力して Enter を押す
3. `/exit` を入力して終了する

**合格条件**：単語が判定され、下部の小ウィンドウが閉じる。

### 練習6：元のプロジェクトに戻る（重要）

1. `:VimQuestStop`

**合格条件**：元のプロジェクトファイルに戻り、**練習の痕跡が残っていない**。

## 8. つまずいたとき

### コマンドが見つからない

プラグインは `cmd` として登録され、`VeryLazy` で読み込まれます。起動直後はまだ読み込まれていない場合があります。

```vim
:Lazy
```

VimQuest の状態を確認してください。または数秒待ってから試してください。

### `<leader>qs` のショートカットがない

設定では**コマンドだけを登録し、キーは割り当てていません**（`cmd = {...}` で、`keys` はありません）。`:VimQuestStart` などのコマンドを使います。

### 練習後に自分のファイルが見つからない

`:VimQuestStop` で元に戻ります。忘れた場合は次を確認してください。

```vim
:pwd
```

現在のディレクトリが一時ディレクトリではないか確認します。

### 単語が簡単すぎる／難しすぎる

単語リストは基礎語彙の Ogden 850 です。変更するには `wordlist` 設定を変えます。

### COBOL コードと混ざって読みにくい

課題は**コメント形式で挿入**され、元のコードはそのまま残ります。COBOL のコメントは第7列の `*` なので、課題はコメントとして表示され、コードには影響しません。

### 統計ファイルの場所

```vim
:echo stdpath("data") .. "/vimquest/words_seen.json"
```

## 10. 適用範囲

- このページの設定は `lua/plugins/vimquest.lua` に基づきます。**コマンドのみ登録し、`<leader>` のショートカットは割り当てていません**（README のデフォルトキーはこの設定にはありません）。
- 一時ディレクトリ内で動作し、**元のプロジェクトは変更しません**。`:VimQuestStop` で元に戻ります。
- 単語リストは Ogden 850 の基礎英語です。
- このツールは「英語学習」用で、COBOL の開発ワークフローには影響しません。練習しなくても機能が欠けることはありません。
