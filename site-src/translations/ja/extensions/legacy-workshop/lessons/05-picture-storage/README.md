# PIC、符号、小数点与存储格式

## 学習目標

PIC X/A/9、V による暗黙の小数点、S 符号、編集用符号、JUSTIFIED、SIGN、USAGE DISPLAY/COMP/COMP-3。バイト数はコンパイラ ABI によって異なります。

このレッスンを終えると、上記の用語を自分の言葉で説明し、小さなプログラムの中で該当する宣言や処理箇所を見つけられるようになります。構文を暗記するだけでなく、まず入力、出力、状態の変化を観察しましょう。

## サンプルコード

[`L05.COB`](./L05.COB) を開きます。このレッスンのソースファイルは固定形式です。Division と段落は Area A から始まり、宣言文や実行文は Area B に記述されています。まずソースを一行ずつ読んでから、実行しましょう。

## コンパイルと実行

リポジトリのルートディレクトリから次を実行します。

```sh
mkdir -p build
cobc -fsyntax-only extensions/legacy-workshop/lessons/05-picture-storage/L05.COB
cobc -x -Wall -o build/l05 extensions/legacy-workshop/lessons/05-picture-storage/L05.COB
./build/l05
```

期待される結果：数値フィールドと編集出力フィールドが表示されます。

コンパイラが形式や列位置のエラーを報告した場合は、まず第 7、8、12、72 列を確認してください。次に、ピリオド、変数の PIC、スコープを終了する文を確認します。`-Wall` は追加の警告を表示するため、警告の内容を理解してから対処するか判断してください。

## 各部分を理解する

1. `IDENTIFICATION DIVISION` はプログラム単位を宣言し、`PROGRAM-ID` はコンパイラが認識するプログラム名です。
2. `DATA DIVISION` は、プログラムの実行時に使うデータを記述します。このレッスンにフィールド宣言がある場合は、レベル番号と PIC を確認してください。
3. `PROCEDURE DIVISION` は実行の開始位置です。`0000-MAIN` は読みやすさのための段落名にすぎず、自動的に繰り返し実行されることはありません。
4. 各文は、制御フロー文によって経路が変わるか、`STOP RUN` でプロセスが終了するまで、ソースの順番どおりに実行されます。

## 変更練習

金額を符号付きの負数に変更し、DISPLAY と COMP-3 を比較します。各フィールドの範囲と小数桁も確認してください。

変更のたびに、構文チェック、コンパイル、実行をやり直します。一度に変更する概念は一つだけにし、変更前後の出力を記録してください。

## cobol.nvim を使った学習

レコード 01 で <leader>cr を使います。結果は一般的なレイアウトの推定値として扱い、cobc -C またはコンパイラのドキュメントで対象の ABI を確認してください。

プラグインが反応しない場合は、まず現在のファイルタイプを確認します：`:set filetype?`。続いて `cobc --version` を確認してください。プラグインはナビゲーション、レイアウトのヒント、診断に使います。プログラムをコンパイルできるかどうかは、GNUCOBOL による実際のコンパイル結果で判断してください。
