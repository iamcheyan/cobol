# 第 13 课练习：SEARCH 与 SEARCH ALL

本节只使用第 11–13 课讲过的内容：`OCCURS` 表格、`INDEXED BY` 索引、`SEARCH` / `SEARCH ALL`、`SET`、`MOVE` 和 `DISPLAY`。

## 修改练习（会在 `answer.md` 提供参考答案）

1. 将 `1000-LOAD-ACCOUNTS` 中账户 `0002468101` 的余额从 `520.00` 改为 `600.00`，运行两种查找，核对它们返回的余额。
2. 把账户表从四项扩为五项，在末尾追加账户 `0009999999`、余额 `75.00`，并把第二个搜索目标从 `0005550000` 改为 `0009999999`。保持键值唯一且按 `ASCENDING KEY` 递增，运行两种查找。

每项从原始 `lesson.cob` 独立修改，不要叠加。每次修改后运行：

```sh
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_13 lesson.cob
./build/lesson_13
```

注意：扩表时不要只更新 `OCCURS` 上界而漏装入对应数据，否则新表项的账户号会是空格，查找也不会命中。参考答案见 `answer.md`，只回答以上修改练习。
