# 第 02 課演習：データ型と PIC

この演習では第 01・02 課で学んだ固定形式ソース、`PIC` / `VALUE` によるフィールド宣言、`DISPLAY`、`STOP RUN` のみを使います。`MOVE`、算術、条件分岐、ループ、グループ項目、ファイル操作は使いません。

値を変更する前に、その項目が「識別子」か「数量」かを考えてください。取り違えると先頭ゼロが失われ、後続の照合が合わなくなります。

## 変更演習（解答例は `answer.md`）

### 基準

この課の元の `lesson.cob`（プログラム名 `DATA02`、すべての項目が `WORKING-STORAGE SECTION` に平坦に宣言されているもの）から始めます。応用演習を先に行わないでください。

### 変更箇所と制約

次の3項目の `VALUE` 句だけを変更します。`PIC`、項目名、順序、`PROCEDURE DIVISION` は変更しません。

1. `WS-BRANCH-CODE`：初期値 `2048` を `3107` に変更（`PIC 9(4)` のまま）。
2. `WS-CURRENCY-CODE`：初期値 `"USD"` を `"EUR"` に変更（`PIC X(3)` のまま）。
3. `WS-CUSTOMER-NUMBER`：初期値 `"0002046819"` を `"0000000042"` に変更（`PIC X(10)` のまま）。

3つ目について、顧客番号を `PIC 9(10)` ではなくテキスト型のままにする理由を説明してください。

### 再コンパイルと実行

```sh
mkdir -p build
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_02 lesson.cob
./build/lesson_02
```

### 期待される差分

元の標準出力と比べて、異なるのはちょうど3行で、残り26行は一文字も変わりません。

| 元の出力 | 変更後 | 理由 |
|---|---|---|
| `支店コード=2048` | `支店コード=3107` | `9(4)` の初期値を変更。4桁のまま |
| `通貨コード=USD` | `通貨コード=EUR` | `X(3)` の3文字を変更 |
| `顧客番号=0002046819` | `顧客番号=0000000042` | `X(10)` は10文字をそのまま保持し、先頭のゼロも残る |

### 境界の確認（同じ演習の一部）

`WS-BRANCH-CODE` の初期値を一時的に `12345` にして、`-Wall` の有無それぞれでコンパイルして実行し、コンパイラー出力と表示された行を記録してください。その後 `3107` に戻します。結果が `PIC 9(4)` の幅とどう関係するか、また `-Wall` なしでも警告が出るか説明してください。

- 各項目の名前、`PIC`、初期値を示し、識別子・数量・金額のどれかを説明してください。金額は整数部と小数部の桁数も示します。
- 始期日の暦上の妥当性や状態コードの有効値など、業務検証が必要な項目を挙げてください。
