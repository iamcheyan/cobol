# 第21課の変更練習解答

この解答は exercise.md の2つの変更練習だけを扱い、発展課題の解答は含みません。どちらも一時ディレクトリのフィクスチャ複製で行います。

```sh
scratch=$(mktemp -d)
cp lesson.cob accounts-unsorted.txt "$scratch/"
cd "$scratch"
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o lesson_21 lesson.cob
```

## 1. 入力の先頭2行を入れ替える

複製の `A000000005` 行と `A000000001` 行を入れ替えます（他の2行はそのまま）。ファイルは次のようになります。

```text
A000000001C0001001000100000
A000000005C0001005000025075
A000000004C0001004000002500
A000000002C0001002000000200
```

整列出力は元のフィクスチャと完全に同じで、口座番号の昇順のままです。

```text
ソート済み 口座番号=A000000001 顧客番号=C0001001 残高=0001000.00
ソート済み 口座番号=A000000002 顧客番号=C0001002 残高=0000002.00
ソート済み 口座番号=A000000004 顧客番号=C0001004 残高=0000025.00
ソート済み 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75
入力レコード数=004 出力レコード数=004
```

入力手続き `1000-LOAD-INPUT` が4行を読み、それぞれを1回 `RELEASE` します。出力手続き `2000-RETURN-SORTED` がソート作業ファイルから4行を `RETURN` します。終了コードは `0` です。

## 2. 口座 A000000006 を追加する

元のフィクスチャから作った複製の末尾に、次の27文字を追加します。

```text
A000000006C0001006000000001
```

口座番号 `A000000006` はソートキーの最大値なので最後に並びます。残高数字 `000000001` は `9(7)V99` で `0000000.01` と表示されます。

```text
ソート済み 口座番号=A000000001 顧客番号=C0001001 残高=0001000.00
ソート済み 口座番号=A000000002 顧客番号=C0001002 残高=0000002.00
ソート済み 口座番号=A000000004 顧客番号=C0001004 残高=0000025.00
ソート済み 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75
ソート済み 口座番号=A000000006 顧客番号=C0001006 残高=0000000.01
入力レコード数=005 出力レコード数=005
```

入力手続きが5件を渡し、出力手続きが5件を取得するため、件数の不変条件 `005 = 005` が成り立ちます。終了コードは `0` です。

どちらの練習もソース変更は不要です。`SORT` は `SD-ACCOUNT-NUMBER` だけで並べ替えるため、入力ファイルの物理的な行順は結果に影響しません。
