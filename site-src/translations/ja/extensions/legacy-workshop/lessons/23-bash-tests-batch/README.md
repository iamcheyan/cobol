# Bash連携：一括チェックと回帰テスト

## 学習目標

find／配列の安全な扱い、ループ、一時ディレクトリ、stdout／stderr、終了コード、diff、テスト用フィクスチャ、クリーンアップ用trap。

このレッスンを終えると、上記の用語を自分の言葉で説明し、小さなプログラムの中で該当する宣言や実行箇所を見つけられるようになります。構文を暗記するだけでなく、まず入力、出力、状態の変化を観察してください。

## サンプルコード

[`L23.COB`](./L23.COB)を開いてください。本レッスンのソースファイルは固定形式です。Divisionと段落はArea Aから始まり、宣言文と実行文はArea Bに記述します。まずソースを1行ずつ読んでから、実行してください。

## コンパイルと実行

リポジトリのルートディレクトリから次を実行します。

```sh
mkdir -p build
cobc -fsyntax-only extensions/legacy-workshop/lessons/23-bash-tests-batch/L23.COB
cobc -x -Wall -o build/l23 extensions/legacy-workshop/lessons/23-bash-tests-batch/L23.COB
./build/l23
```

期待される動作：回帰テスト用スクリプトがプログラムをコンパイルし、フィクスチャを実行して出力を検証します。失敗した場合は、ゼロ以外の終了ステータスを返します。

コンパイラが形式や列位置のエラーを報告した場合は、まず7、8、12、72列目を確認してください。次にピリオド、変数のPIC、スコープ終端文を確認します。`-Wall`は追加の警告を表示します。警告の内容も理解してから対処するかどうかを決めてください。

## 順を追って理解する

1. `IDENTIFICATION DIVISION`はプログラム単位を宣言し、`PROGRAM-ID`はコンパイラが認識するプログラム名です。
2. `DATA DIVISION`はプログラムの実行時に使うデータを記述します。本レッスンにフィールド宣言がある場合は、レベル番号とPICに注目してください。
3. `PROCEDURE DIVISION`は実行の入口です。`0000-MAIN`は読みやすくするための段落名にすぎず、自動的に繰り返し実行されることはありません。
4. 各文は、制御フロー文で経路が変わるか、`STOP RUN`でプロセスが終了するまで、ソースの順序どおりに実行されます。

## 変更演習

期待される出力を変更してテストが失敗することを確認し、プログラムを修正してから再度実行してください。`bash -x`を使ってスクリプトの実行を観察します。

変更するたびに、構文チェック、コンパイル、実行をもう一度行ってください。一度に変更する概念は1つだけにし、変更前後の出力を記録してください。

## cobol.nvimを使った学習

COBOLの構文に関する問題には`:CobolQuickfix`を使い、シェルのアサーションが失敗した場合はexpectedとactualの差を確認してください。

プラグインが応答しない場合は、まず現在のファイルタイプを確認します：`:set filetype?`。続いて`cobc --version`を確認してください。プラグインは移動、レイアウトのヒント、診断に役立ちます。プログラムをコンパイルできるかどうかは、GNUCOBOLによる実際のコンパイル結果で判断してください。
