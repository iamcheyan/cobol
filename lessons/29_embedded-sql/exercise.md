# 第 29 课练习：宿主变量与 SQL 状态

本节只使用第 29 课讲过的内容：GixSQL 预编译、`EXEC SQL ... END-EXEC`、宿主变量、`SQLCODE` 分支与 `CONNECT`/`CONNECT RESET`。

## 修改练习（会在 `answer.md` 提供参考答案）

先运行 `./build.sh run` 保存基准输出。每次修改 `lesson.cob` 后都重新运行同一条命令——脚本会重建数据库，避免上一次结果污染本次练习：

```sh
./build.sh run
echo $?
```

1. 把第一次查询的账号从 `A000000001` 改为 `A000000002`。核对客户号与余额，并说明 `SELECT ... INTO` 如何把数据库列放进 COBOL 字段。
2. 从原始源码开始，把第二次查询的账号从 `A99999999X` 改为 `A000000002`。比较两次查询走的是哪条 `SQLCODE` 分支，以及标准输出的差异。

约束：不改 `schema.sql`，不改 `build.sh`；每次都要从干净数据库开始，并记录退出码。参考答案见 `answer.md`。
