# 第 18 课修改练习参考答案

本答案只覆盖 `exercise.md` 中的两项修改练习，不提供举一反三练习答案。

## 1. 将姓名增加到 21 个字符

将第五行姓名改为：

```csv
C0005042,"123456789012345678901",0003210001,A,OVER21
```

字段扫描在 21 个字符处记录 `FIELD_TOO_LONG`，不会把额外字符写入 20 字符字段。该行被拒绝；其余三条原本有效的记录保持有效，结果汇总：

```text
SUMMARY ROWS=06 VALID=03 REJECTED=03
```

## 2. 增加第六个字段

将第一行改为：

```csv
C0001042,"Ada Lovelace",0001234567,A,REGULAR,EXTRA
```

第五个逗号开始第六字段，解析器记录 `TOO_MANY_FIELDS`，并拒绝整行。其余夹具不变时，汇总为：

```text
SUMMARY ROWS=06 VALID=03 REJECTED=03
```
