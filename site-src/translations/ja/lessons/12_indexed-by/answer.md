# 第 12 課変更演習：参考解答

この解答は `exercise.md` の2つの変更手順だけを扱います。「学んだことを応用する」の解答はありません。手順1は本課の元の `lesson.cob` から始め、手順2は手順1の結果から続けます。

## 手順1：口座テーブルを5項目に拡張

容量とロード済み件数を 5 に変更します。

```cobol
          05 WS-ACCOUNT-ENTRY OCCURS 5 TIMES
             INDEXED BY WS-ACCOUNT-IDX.
```

```cobol
       01 WS-LAST-ACCOUNT PIC 9 VALUE 5.
```

`1000-LOAD-ACCOUNTS` の4件目の後に5件目を追加します。4件目の末尾のピリオドを削除し、5件目の末尾だけにピリオドを残してください。

```cobol
           MOVE 520.00 TO WS-ACCOUNT-BALANCE(4)
           MOVE "0005550001" TO WS-ACCOUNT-NUMBER(5)
           MOVE 75.00 TO WS-ACCOUNT-BALANCE(5).
```

ロードでは引き続き数値添字を使用し、走査ではインデックスを使用します。ループ構造は変更しません。再コンパイルして実行した標準出力：

```text
口座=0001234567 BALANCE=0001000.00
口座=0007654321 BALANCE=0000250.75
口座=0000000042 BALANCE=0000000.00
口座=0002468101 BALANCE=0000520.00
口座=0005550001 BALANCE=0000075.00
処理件数=005
```

末尾だけが変わります。5行目が追加され、処理件数が `004` から `005` に変わります。先頭4件のロード文と添字は変更していないため、最初の4行はバイト単位で同一です。容量、ロード済み件数、ループ終点をすべて4から5に揃えています。インデックスは1から5まで進み、5件目の処理後に6となるため、`UNTIL 索引 > WS-LAST-ACCOUNT` が成立して終了します。`cobc -fsyntax-only` と `cobc -x -Wall` は診断なしでどちらも 0 を返し、実行の終了コードも 0 です。

## 手順2：範囲外境界

`OCCURS` が5のまま `WS-LAST-ACCOUNT` だけを `6` にすると、コンパイラーはエラーを報告しません。ループ終点は実行時比較であり、`WS-ACCOUNT-IDX` はコンパイル時に範囲外と確定した定数ではないためです（固定の範囲外リテラル添字とは異なります）。

`cobc -x -Wall` は診断なしで 0 を返し、既定設定での実行終了コードも 0 です。標準出力は5行目の後にテーブル外のデータを1行追加し、処理件数は `006` と表示します。

```text
口座=0001234567 BALANCE=0001000.00
口座=0007654321 BALANCE=0000250.75
口座=0000000042 BALANCE=0000000.00
口座=0002468101 BALANCE=0000520.00
口座=0005550001 BALANCE=0000075.00
口座=<テーブル外の無意味なバイト> BALANCE=<テーブル外の無意味なバイト>
処理件数=006
```

6行目（上では `<テーブル外の無意味なバイト>` と表記）は口座テーブル外のメモリーを読み取ったものです。有効な口座レコードではありません。実測では NUL を含む無意味なバイトが出力され、端末によって空白または文字化けに見えます。業務結果として扱えません。「終了コード0なら正しい」とは限らない例です。

実行時の添字検査を有効にすると結果は変わります。

```sh
cobc -x -fsubscript-check=full -fec=EC-BOUND-SUBSCRIPT -o build/lesson_12_checked lesson.cob
./build/lesson_12_checked
```

標準出力は5口座目で止まり、標準エラーに libcob の範囲外エラーが表示されます（行番号とファイルパスはローカルの実出力に従います）。

```text
libcob: lesson.cob:36: error: subscript of 'WS-ACCOUNT-BALANCE' out of bounds: 6
note: maximum subscript for 'WS-ACCOUNT-BALANCE': 5
```

6項目目へのアクセス時にプログラムが停止し、終了コードは 1 です。既定のコンパイルではインデックスの範囲外アクセスは保護されません。したがって、ループ終点がテーブル容量を超えないことを守る必要があります。上記オプションでコンパイルすれば、範囲外アクセスを直ちに検出して明示的な失敗にできます。
