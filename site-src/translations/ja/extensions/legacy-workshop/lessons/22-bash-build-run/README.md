# Bash連携：確実なコンパイルと実行スクリプト

## 学習目標

shebang、set -euo pipefail、スクリプトのディレクトリ特定、コマンドの確認、一時的なbuildディレクトリ、引数の転送、終了コード。

このレッスンを終えると、上記の用語を自分の言葉で説明し、小さなプログラムの中から該当する宣言や実行箇所を見つけられるようになります。構文を暗記するだけではなく、まず入力、出力、状態の変化を観察しましょう。

## サンプルコード

[`L22.COB`](./L22.COB)を開きます。このレッスンのソースファイルは固定形式です。Divisionと段落はArea Aから始まり、宣言文や実行文はArea Bに記述します。まずソースを1行ずつ読み、その後に実行しましょう。

## コンパイルと実行

リポジトリのルートディレクトリから実行します。

```sh
mkdir -p build
cobc -fsyntax-only extensions/legacy-workshop/lessons/22-bash-build-run/L22.COB
cobc -x -Wall -o build/l22 extensions/legacy-workshop/lessons/22-bash-build-run/L22.COB
./build/l22
```

期待される動作：サンプルのソースコードがrun.shによってコンパイル、実行され、ビルド成果物はbuild/に保持されます。

コンパイラが書式や列位置のエラーを報告した場合は、まず7、8、12、72列目を確認します。次にピリオド、変数のPIC、スコープを終了する文を確認してください。`-Wall`を付けると追加の警告が表示されます。警告も内容を理解してから、対処するかどうかを判断しましょう。

## 各部分を理解する

1. `IDENTIFICATION DIVISION`はプログラム単位を宣言し、`PROGRAM-ID`はコンパイラに認識されるプログラム名です。
2. `DATA DIVISION`は、プログラムの実行時に使うデータを記述します。このレッスンにフィールド宣言がある場合は、階層番号とPICを確認しましょう。
3. `PROCEDURE DIVISION`は実行の入口です。`0000-MAIN`は読みやすさのための段落名であり、自動的に繰り返し実行されるわけではありません。
4. 各文はソースコードの順に実行されます。制御フロー文によって経路が変わるか、`STOP RUN`によってプロセスが終了するまで続きます。

## 変更して練習する

./run.shを実行します。COBC=/path/to/cobcを設定してコンパイラを変更し、コンパイラが見つからない場合にスクリプトが出すエラーを確認しましょう。

変更するたびに、構文チェック、コンパイル、実行をやり直してください。一度に変更する概念は1つだけにし、変更前後の出力を記録しましょう。

## cobol.nvimで学ぶ

エディタのターミナルでrun.shとこのレッスンのCOBOLファイルを開き、:CobolLintと./run.shを交互に実行します。

プラグインが反応しない場合は、まず現在のファイルタイプを確認します。`:set filetype?`を実行し、続けて`cobc --version`を確認してください。プラグインは移動、レイアウトのヒント、診断に使います。プログラムをコンパイルできるかどうかは、GNUCOBOLによる実際のコンパイル結果で判断します。
