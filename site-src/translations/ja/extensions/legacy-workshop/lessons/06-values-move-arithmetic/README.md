# VALUE、MOVE と算術文

## 学習目標

VALUE による初期化、MOVE の型の適合性と切り捨て、ADD/SUBTRACT/MULTIPLY/DIVIDE、ROUNDED、ON SIZE ERROR。

このレッスンを終えると、上記の用語を自分の言葉で説明し、小さなプログラムの中から対応する宣言や実行箇所を見つけられるようになります。構文を暗記するだけでなく、入力、出力、状態の変化を観察しましょう。

## サンプルコード

[`L06.COB`](./L06.COB) を開きます。このレッスンのソースファイルは固定形式です。Division と段落は Area A から始まり、宣言文と実行文は Area B に記述します。まずソースを1行ずつ読み、その後で実行してください。

## コンパイルと実行

リポジトリのルートディレクトリから、次のコマンドを実行します。

```sh
mkdir -p build
cobc -fsyntax-only extensions/legacy-workshop/lessons/06-values-move-arithmetic/L06.COB
cobc -x -Wall -o build/l06 extensions/legacy-workshop/lessons/06-values-move-arithmetic/L06.COB
./build/l06
```

期待される動作：価格に数量を掛け、その後、数量を加算します。

コンパイラが書式や列位置のエラーを報告した場合は、まず第7、8、12、72列を確認します。次に、ピリオド、変数の PIC、スコープ終端文を確認してください。`-Wall` は追加の警告を出力します。警告の内容も理解したうえで、対処するかどうかを判断しましょう。

## 各部分を理解する

1. `IDENTIFICATION DIVISION` はプログラム単位を宣言し、`PROGRAM-ID` はコンパイラが認識するプログラム名です。
2. `DATA DIVISION` は、プログラムの実行時に使うデータを記述します。このレッスンにフィールド宣言がある場合は、階層番号と PIC を確認してください。
3. `PROCEDURE DIVISION` は実行の入口です。`0000-MAIN` は読みやすくするための段落名にすぎず、自動的に繰り返し実行されることはありません。
4. 各文はソースの順に実行され、制御フロー文によって処理経路が変わるか、`STOP RUN` でプロセスが終了するまで続きます。

## 変更練習

価格と数量を変更し、ROUNDED を追加してみましょう。また、より小さな受け取りフィールドを試し、オーバーフローや切り捨てを観察してください。

変更のたびに、構文チェック、コンパイル、実行をやり直します。一度に変更する概念は1つにし、変更前後の出力を記録してください。

## cobol.nvim で学ぶ

算術文の診断を確認し、プラグインのナビゲーションを使って WS-TOTAL の PIC 宣言を調べます。

プラグインが反応しない場合は、まず現在のファイルタイプを確認します：`:set filetype?`。次に `cobc --version` を確認してください。プラグインはナビゲーション、レイアウトのヒント、診断に使います。プログラムをコンパイルできるかどうかは、GNUCOBOL による実際のコンパイル結果で判断します。
