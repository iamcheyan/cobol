# GnuCOBOL 実践コース総目録

## コース概要

プログラミング、Linux、Oracle/PostgreSQL、CSV/TXT の基礎知識はあるものの、COBOL は初めてという学習者を対象にしています。Linux 上で動作する GnuCOBOL のバッチプログラムを自力で完成させることを目指します。CSV と固定長ファイルの処理、データ検証、ファイル照合、移行、レポート、データベースバッチを扱い、継続プロジェクトを通じて小さなコンソールプログラムから銀行照合システムへ段階的に発展させます。

各レッスンの成果物は `lesson.cob`、`README.md`、`exercise.md`、`answer.md` です。README では目標、概念、ビルドと実行、行ごとの解説、入出力、企業での利用場面を扱います。練習には、参考解答付きの改変課題と解答のない応用課題があり、解答ファイルが扱うのは改変課題だけです。

コースのソースはリポジトリ規約の固定形式です。7桁目が標識領域、Area A/B は8/12桁目から始まり、プログラム本文は72桁目を越えません。コンパイラと対象プラットフォームの動作は、実際に GnuCOBOL/Linux で検証した結果を基準にします。

## 学習の依存関係とプロジェクトの発展

```text
01–08 言語と制御フロー
  → 09–14 レコード配置とメモリーテーブル
  → 15–22 ファイル読み書き、CSV/固定長、ソート、照合
  → 23–28 Copybook、サブプログラム、インターフェース、エラー、ログ、ビルド
  → 29–31 実際の Embedded SQL、カーソル、ファイルとデータベースの同期
  → 32 銀行照合の卒業プロジェクト
```

プロジェクトデータは定数出力や手作業のサンプルから始まり、口座・取引レコード、再現可能な入力フィクスチャへと進みます。その後、CSV、固定長ファイル、複数ファイル、照合出力、モジュール間インターフェース、データベーススナップショットを順に加え、最後に完全なバッチとして統合します。各総合練習で使う構文やツールは、その前提課で学んだものに限ります。

## 学習計画

各課の所要時間には読む、変更する、実行する、練習する時間を含み、全体で約111時間です。
第29～31課で使う Embedded SQL ツールチェーンとデータベース依存関係は、環境検証の結果に応じて決まります。
