# 第 31 課演習：ファイルスナップショットとデータベーススナップショットの差異

この演習では、第 31 課までに学んだ内容だけを使います。GixSQL のプリコンパイル、ホスト変数、`SQLCODE` の分岐、結果テーブル `RECON_RESULT`、および第 30 課までのファイル入出力とカーソルです。

## 修正演習（参考解答は `answer.md`）

どちらも**元のフィクスチャ**から始めます（`snapshot.txt` は 3 行のまま、`schema.sql` は変更せず、`lesson.cob` も変更しません）。まず 1 回実行し、基準となる結果を保存します。

```sh
./build.sh run
echo $?
cat differences.txt
sqlite3 build/lesson31.db "SELECT ACCOUNT_NO, FILE_STATUS FROM RECON_RESULT;"
```

スクリプトは実行のたびに `build/lesson31.db` を再作成し、`differences.txt` を切り詰めるため、手作業で消す必要はありません。ただし、**次の演習に進む前にフィクスチャを元の内容に戻してください**。2 つの変更を重ねてはいけません。

1. **ファイル側の金額を変更する。** `snapshot.txt` 2 行目の金額を `000010000` から `000087500` に変更します（行は 27 バイトのまま、ほかのフィールドは変更しません）。再実行し、2 行目の分類、標準出力の `BALANCE=`、3 つの集計件数、`differences.txt` の行数と内容を確認します。
2. **データベース側に行を追加する。** `schema.sql` の `ACCOUNT_SNAPSHOT` の挿入リスト末尾に `('A000000003', 'C0001003', 25.00)` と `('A000000099', 'C0001099', 500.00)` を追加します（挿入リストの要素として追加し、直前の行末にカンマ、最後の行末にセミコロンを付けます）。再実行し、3 行目の分類、集計件数、`differences.txt` が空かどうか、`A000000099` が標準出力・差異ファイル・`RECON_RESULT` のどこかに現れるかを確認します。

制約：`lesson.cob` と `build.sh` は変更しません。`snapshot.txt` の各行を 27 バイト（9 桁の金額、左側をゼロで埋める）に保ちます。各演習の終了コードを記録し、変更後の `RECON_RESULT` の行数を `sqlite3` で確認します。参考解答は [`answer.md`](./answer.md) を参照してください。

## 発展演習（解答なし）
