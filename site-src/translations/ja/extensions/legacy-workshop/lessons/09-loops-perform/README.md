# PERFORM、ループ、段落制御

## 学習目標

PERFORM 段落、TIMES、UNTIL、WITH TEST BEFORE/AFTER、後続の段落へのフォールスルー防止、EXIT PERFORM の境界。

このレッスンを終えると、上記の用語を自分の言葉で説明し、小さなプログラムの中で該当する宣言箇所や実行箇所を見つけられるようになります。構文を暗記するだけでなく、まず入力、出力、状態の変化を観察してください。

## サンプルコード

[`L09.COB`](./L09.COB) を開きます。このレッスンのソースファイルは固定形式です。Division と段落は Area A から始まり、宣言文や実行文は Area B に記述されます。まずソースを1行ずつ読んでから、実行してください。

## コンパイルと実行

リポジトリのルートディレクトリで実行します。

```sh
mkdir -p build
cobc -fsyntax-only extensions/legacy-workshop/lessons/09-loops-perform/L09.COB
cobc -x -Wall -o build/l09 extensions/legacy-workshop/lessons/09-loops-perform/L09.COB
./build/l09
```

期待される結果：ループで 1 から 5 までが表示されます。

コンパイラが書式や列位置のエラーを報告した場合は、まず 7、8、12、72 列目を確認してください。次に、ピリオド、変数の PIC、スコープ終端文を確認します。`-Wall` は追加の警告を表示します。警告も内容を理解してから、対処するかどうか判断してください。

## 各段落の理解

1. `IDENTIFICATION DIVISION` はプログラム単位を宣言し、`PROGRAM-ID` はコンパイラが認識するプログラム名です。
2. `DATA DIVISION` はプログラムの実行時に使うデータを記述します。このレッスンにフィールド宣言がある場合は、レベル番号と PIC を確認してください。
3. `PROCEDURE DIVISION` は実行の開始位置です。`0000-MAIN` は読みやすさのための段落名にすぎず、自動的に繰り返し実行されることはありません。
4. 各文はソースの順序どおりに実行されます。制御フロー文で経路が変わるか、`STOP RUN` でプロセスが終了するまで続きます。

## 変更演習

条件を TEST AFTER に変更します。カウンターの上限を追加し、無限ループが発生しないことを確認してください。

変更のたびに、構文チェック、コンパイル、実行を再度行ってください。一度に変更する概念は1つにして、変更前後の出力を記録してください。

## cobol.nvim で学ぶ

PERFORM 段落の呼び出し箇所で gd を使い、za でループ段落を折りたたみます。

プラグインが反応しない場合は、まず現在のファイルタイプを確認します。`:set filetype?` を実行し、次に `cobc --version` を確認してください。プラグインは移動、レイアウトのヒント、診断に使います。プログラムがコンパイル可能かどうかは、GNUCOBOL による実際のコンパイル結果で判断してください。
