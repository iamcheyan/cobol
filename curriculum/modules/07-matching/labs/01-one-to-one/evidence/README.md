# 学员证据模板（请实际执行后填写）

- Git commit / 自己的源码 SHA256：
- OS、架构、`cobc -V`：
- 营业日、输出目录、开始/结束时间：
- 输入校验和及来源版本：
- 构建/运行命令、原始退出码：
- 正常报告与预期 diff：
- Master=Match+MasterOnly：
- Transaction=Match+TxOnly：
- 按分类还原的输入金额核对：
- EOF 六种状态的手工 trace：
- 长/短/缺文件/逆序/重复/NUL/锁的结果：
- 不存在失败输出目录的证据：
- 压力档位、matcher RSS、耗时和限制：
- 调查结论、尚未验证事项：

不要把本模板或讲师机器结果当作自己的运行证据。
