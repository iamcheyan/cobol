# 第 14 课练习：账户和交易匹配

本节只使用第 09–14 课讲过的内容：层级记录、`REDEFINES`、`OCCURS` 表格、`INDEXED BY` 索引、`SEARCH ALL`、`EVALUATE`、`IF`、`PERFORM` 和 `DISPLAY`。数据全部在内存中。

## 修改练习（会在 `answer.md` 提供参考答案）

1. 将第四笔转账的目标账户从 `0009999999` 改为已存在的 `0002468101`。运行程序，确认转账成功、来源和目标余额变化，且拒绝数为零。
2. 从原始源码开始，将第四笔转账目标设为 `0001234567`，金额设为 `100.00`。确认该笔因来源余额不足被拒绝，并且两边余额都不变。

两项练习分别从原始 `lesson.cob` 开始，不要叠加。每次修改后运行：

```sh
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_14 lesson.cob
./build/lesson_14
```

每次都要核对交易结果、三个账户的最终余额和汇总计数，而不只看“是否成功”一行。参考答案见 `answer.md`。
