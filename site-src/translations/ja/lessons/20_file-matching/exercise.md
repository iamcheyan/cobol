# 第 20 課の練習：順次キー照合

この節では、第 15〜20 課で学んだ内容だけを使います：順次ファイルの `SELECT`/`OPEN`/`READ`/`CLOSE`、`FILE STATUS`、`AT END`、`EVALUATE TRUE`、`IF`、段落、`PERFORM`。

## 改変練習（参考解答は `answer.md`）

どちらの変更も**一時ディレクトリ内のフィクスチャのコピーだけ**に行い、リポジトリ内の `accounts.txt` / `transactions.txt` は変更しないでください。まず一時ディレクトリを用意します：

```sh
scratch=$(mktemp -d)
cp lesson.cob accounts.txt transactions.txt "$scratch/"
cd "$scratch"
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o lesson_20 lesson.cob
```

1. コピーした `transactions.txt` から口座番号 `A000000004` に対応する行全体を削除します。`./lesson_20` を実行し、主ファイルのキー `A000000003` と現在の取引キーとの比較結果を確認して、`照合件数` / `口座のみ` / `取引のみ` の 3 件数を記録してください。
2. 元のフィクスチャから始め、コピーした取引ファイルでキー `A000000004` を `A000000003` に、金額を `000005000` に変更します（20 文字のまま、ファイルの昇順も維持します）。実行後、この取引が主ファイル `A000000003` と照合され、両方のストリームが進むことを確認してください。

制約：`lesson.cob` は変更しないこと。各行の長さと口座キーの順序は正しく保ってください。

各変更の後に 3 分類の件数、終了コード、出力全体を記録し、どの分岐で主ファイル、取引ファイル、または両方が進んだかを説明してください。さらに件数の不変条件で確認します：`照合件数 + 口座のみ` は主ファイルのレコード数と等しく、`照合件数 + 取引のみ` は取引レコード数と等しくなる必要があります。参考解答は `answer.md` を参照してください。

## 応用（解答なし）

両方の入力に重複口座キーを 1 つずつ追加し、さらにそれぞれに昇順に反するレコードを追加します。プログラムを拡張して重複キーと降順キーを検出し、選んだ拒否方針を記述し、照合、片側のみ、重複、未ソートの各ケースを検証するフィクスチャを作成してください。

ソース、コンパイルと実行のコマンド、各フィクスチャの実際の出力と終了コード、および読み漏らしがないことをどの件数不変条件で確認したかの説明を提出します。解答はありません。両方のファイル全体を `OCCURS` 表に読み込むことも、`SORT` を呼び出すことも禁止です。
