# 行ごとにカーソルを追加する：multicursor-line.nvim

`multicursor-line.nvim` は、自分たちで開発した Neovim プラグインです。Vim で選択した行や矩形範囲を、各行の先頭文字の前、絶対行頭、行末、または行頭と行末の交互位置にカーソルを配置した状態へ変換します。範囲を選んでキーを 1 つ押せば、その位置をまとめて編集できます。

本稿は `multicursor.nvim` とは別に、独立したプラグインとして解説します。内容はローカルの `lua/plugins/multicursor-line.lua` とプラグイン実装に基づいています。

## 1. 範囲を選んでからカーソルを追加

基本の流れは次のとおりです。

1. Vim 標準の操作で対象行を選びます。2 行なら `Vj`、現在の段落なら `vip`、ファイル全体なら `ggVG` です。
2. Visual モードで `<leader>mh` などの配置キーを押します。
3. 選択した各行の対応する位置にカーソルが追加されます。
4. `i` または `a` を押して同時に入力します。Backspace もすべてのカーソルに反映されます。
5. `<Esc>` でマルチカーソル編集を終了します。

ポイントは「先に選び、後から適用する」ことです。プラグインは選択範囲だけを処理するため、変更対象の行を推測しません。

native バックエンドで撮影した実画面です。各行のインデントを飛ばし、`01` の前にカーソルが置かれています。`i` を押すと同時入力を始められます。

## 2. 5 種類のカーソル配置

| 配置 | 位置 | 主なキー |
|---|---|---|
| スマート行頭（head） | 各行の先頭文字の前。インデントを飛ばす | Visual モード `<leader>h`、Normal モード `<leader>mh` |
| 絶対行頭（bol） | インデントより前の第 0 列 | Visual モード `<leader>H` / `<leader>0`、Normal モード `<leader>mH` / `<leader>m0` |
| 行末（tail） | 各行の最後の文字の後 | Visual モード `<leader>t`、Normal モード `<leader>mt` |
| 行頭・行末交互 | 行末と先頭文字の前を交互に配置 | Visual モード `<leader>a`、Normal モード `<leader>ma` |
| 絶対行頭・行末交互 | 行末と第 0 列を交互に配置 | Visual モード `<leader>A`、Normal モード `<leader>mA` |

範囲を正確に決めたい場合は Visual モード用のキーを使います。`<leader>m…` の助記キーは Normal モードにも登録されており、現在行とカウント指定から対象範囲を決めます。Visual block（`<C-v>`）で作った矩形選択も範囲として利用できます。

## 3. COBOL の行頭にまとめて挿入

複数の COBOL 宣言行に同じ接頭辞を追加する例です。

```cobol
       01 WS-ACCT-ID     PIC X(10).
       01 WS-ACCT-NAME   PIC X(30).
       01 WS-ACCT-BAL    PIC 9(9)V99.
```

1. 先頭行へ移動し、`V` を押してから `j` で対象宣言を選びます。
2. `<leader>mh` を押し、各行の最初の文字 `01` の前にカーソルを置きます。
3. `i` を押して文字を入力すると、すべてのカーソルに同じ文字が入力されます。
4. `<Esc>` で終了します。

Area A の前に、インデントも含めて挿入したい場合は `<leader>m0`（絶対行頭）を使います。Normal モードでは `2<leader>mh` のように、現在行と次の行にカーソルを追加することもできます。まず少ない行数で範囲を確認してから入力してください。

## 4. コマンドと行範囲

行範囲を指定できる Ex コマンドもあります。

| コマンド | 配置 |
|---|---|
| `:[range]McLineHead` | 各行の先頭文字の前 |
| `:[range]McLineBol` | 各行の第 0 列 |
| `:[range]McLineTail` | 各行の行末 |
| `:[range]McLineAlt` | 行末と先頭文字の前を交互に配置 |
| `:[range]McLineAltBol` | 行末と第 0 列を交互に配置 |
| `:McLineClear` | 現在のマルチカーソルセッションを解除 |

たとえば `:10,15McLineTail` は 10〜15 行目に行末カーソルを作ります。編集を確定する前に、各カーソルが意図した列にあるか確認してください。行の長さが異なれば行末位置も変わり、空行は独自の末尾位置になります。これは tail 配置の仕様です。

## 5. バックエンドと実装上の境界

ローカル設定では `backend = "native"` を使っています。native バックエンドは各行の位置を計算してバッファを一括更新し、カーソルごとの検索ハイライトを必要としません。用途に応じて `vm` と `multicursor` のバックエンドも選べます。

スマート行頭は各行のインデントを飛ばし、絶対行頭は第 0 列にカーソルを置きます。交互配置の開始方向は `alternate_start` で決まり、ローカル設定では `tail` です。Visual block の選択では矩形の左右端を使って位置を計算します。

このプラグインはカーソル位置を作ります。マルチカーソル中の同時入力と Backspace は選択中のバックエンドが提供します。通常編集に戻るには `<Esc>` を押してください。大きな範囲を編集する前に、少ない行数で練習し結果を確認しましょう。

## 6. 既存のマルチカーソルプラグインとの違い

| ツール | 得意な作業 |
|---|---|
| `multicursor-line.nvim` | 対象範囲が決まっている行の先頭・行頭・行末・交互位置にカーソルを追加 |
| `multicursor.nvim` | `gaip` のように motion、段落、検索結果を順に使ってカーソルを追加 |
| `vim-visual-multi` | 同じ単語を対話的に選択し、一致を飛ばしたりカーソル群を調整 |

3 つは併用できますが、用途は異なります。行の形に沿って追加するなら `multicursor-line.nvim`、文字列の一致から選ぶ場合は、`multicursor.nvim` または `vim-visual-multi` が向いています。

### ローカルのキー競合

`lua/plugins/bookmark.lua` と `multicursor-line.nvim` は、どちらも Normal モードの `<leader>mt` を登録しています。読み込み順で有効なマッピングが変わるため、`:verbose nmap <leader>mt` で定義元を確認してください。`multicursor-line` の Visual モード `<leader>mt` は別に登録されています。競合を避ける場合は `:McLineTail` を使うか、ローカルの割り当てを変更します。

## 7. 練習

### 練習 1：スマート行頭

1. COBOL のデータ宣言を 3 行選びます。
2. `<leader>mh` を押し、各カーソルがインデント前ではなく `01` の前にあることを確認します。
3. 短い接頭辞を入力して `<Esc>` を押します。

**確認**：3 行すべてに同じ接頭辞が付き、インデントは置き換わっていません。

### 練習 2：交互配置

4 行を選んで `<leader>ma` を押し、行末と先頭文字の前に交互にカーソルがあることを確認します。`<Esc>` で解除し、次に `<leader>mA` を試して絶対行頭との違いを確認します。

### 練習 3：コマンド範囲

`:10,12McLineTail` を実行し、10〜12 行目だけに行末カーソルができたことを確認してから、`:McLineClear` で解除します。

## 8. トラブルシューティング

- **キーを押しても反応しない**：Visual モードで空でない範囲を選択しているか確認し、`:verbose xmap <leader>mh` でマッピングを調べます。
- **Normal モードの `<leader>mt` でブックマークが動く**：`:verbose nmap <leader>mt` で定義元を確認するか、`:McLineTail` を使います。
- **カーソル位置が想定と違う**：選択範囲と配置を確認します。`head` はインデントを飛ばし、`bol` はインデント前の第 0 列を使います。
- **一括編集を止めたい**：`<Esc>` を押します。明示的に解除する場合は `:McLineClear` を実行します。
