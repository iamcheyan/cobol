# L1 接口与状态设计

## 输入接口

Canonical Copybook 位于 `curriculum/bank/copybooks/`。全部字段先作为文本读取，数字验证后才转换。布局与[全局契约](../../../../../docs/curriculum/BANK-SYSTEM.md)一致。

| 文件 | 字段及位置（从 1 起） | 本课验证 |
|---|---|---|
| ACCOUNT | ID 1–10，客户11–18，币种19–21，符号22，余额23–35，状态36，日期37–44，版本45–47 | ID/客户/金额数字；JPY；+/-；A/F/C；日期=作业日；001 |
| TRANSACTION | 账户1–10，交易ID11–26，日期27–34，序号35–40，方向41，金额42–54，状态55 | 键/序号/金额数字；ID为A–Z/0–9；日期=作业日；C/D；N |

本课只分类，冻结/关闭账户仍可 MATCH；不表示允许对这些账户记账。零金额合法。金额是最小单位整数，首期 JPY；本课不把 JPY 虚构为两位法定小数。输入采用严格 LF，缺末尾 LF 属接口异常。

原始字节读取：SEQUENTIAL、固定 1 字节记录，每次检查 LF 后才填入有界缓冲。这样不依赖 LINE SEQUENTIAL 对短行、NUL、Tab、CR 的规范化。单行超过宽度立即拒绝；EOF 前若还有未终结字节则拒绝。读取次数与输入字节数线性增长，代价高于块读取，性能实测见压力报告。

## 比较状态

| M EOF | T EOF | 其他条件 | 输出 | 推进 |
|---|---|---|---|---|
| 否 | 否 | M=T | MATCH | M、T |
| 否 | 否 | M<T | MASTER ONLY | M |
| 否 | 否 | M>T | TX ONLY | T |
| 是 | 否 | 无 | TX ONLY | T |
| 否 | 是 | 无 | MASTER ONLY | M |
| 是 | 是 | 无 | 计数核对并结束 | 无 |

EOF 必须优先于键比较；EOF 时旧缓冲内容没有比较意义。验证后的每条记录恰好进入一个分类。键比较采用固定宽度 ASCII 数字，因此词典顺序等于数值顺序，无需转换为二进制键。

## 责任与 RC

COBOL 检查日期、原始宽度、字段、账户键排序/唯一性、三类顺序突合及读入计数。Shell 以 SORT/uniq 检查全局交易 ID 唯一性（避免在 COBOL 中保存全部交易 ID）；这不是用外部工具替代核心突合。

| RC | 本课语义 | 发布 |
|---|---|---|
| 0 | 所有输入有效、分类与笔数核对成功 | 一次目录 rename |
| 8 | 接口/业务数据异常 | 不发布 |
| 12 | 文件/构建/锁/环境失败 | 不发布 |

本课不使用 RC4，孤立记录是正常分类。Shell 的输入输出系统调用故障必须映射 RC12。COBOL stdout 在发现后段异常前可能已有候选行，因此必须暂存，不能直接把 stdout 当正式报告。

运行目录保留输入副本、校验和、编译器版本、源码校验和、业务日和报告；原始文件从不改动。每次新目录是本课简化的 run_id。目录锁防同一目标并发发布，输出存在时拒绝覆盖。这里没有 DB 提交，不能用本课 rename 推论 DB 与文件原子性。
