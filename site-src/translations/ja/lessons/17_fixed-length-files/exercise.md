# 第 17 課演習：固定長レコード、フィールドオフセット、バイト数の照合

この演習では、第 09 課および第 15〜17 課で学んだ方法だけを使います。`SELECT` と `FD` のレコード宣言、`FILE STATUS`、`READ ... AT END`、`MOVE`、`WRITE`、固定形式の列位置規則です。

## 変更演習（解答は `answer.md`）

この課の元の `lesson.cob` と `accounts.dat` を使い、出力 FD のフィールド宣言順を変更してください。出力レコードのバイト 1〜10 を口座番号、11〜18 を顧客番号、19〜27 を残高とし、入力レコードと同じレイアウトにします。

制約：

- `FD BALANCE-FILE` 内の `01 FD-BALANCE-RECORD` の下にある 3 つの `05` 宣言だけを、口座番号 → 顧客番号 → 残高の順に変更します。
- 各 `PIC` の幅（`X(10)`、`X(8)`、`9(7)V99`）は変えません。
- 3 つの `MOVE` 文、入力 FD、すべての段落ロジックは変更しません。

変更後に再コンパイルして実行します（実行時の作業ディレクトリに `accounts.dat` が必要なので、まずフィクスチャを実行ディレクトリへコピーします）：

```sh
mkdir -p build
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_17 lesson.cob
cp accounts.dat build/
(cd build && ./lesson_17)
wc -c build/balances.dat
cmp accounts.dat build/balances.dat
rm -rf build
```

提出するもの：

- 変更後の `01 FD-BALANCE-RECORD` 宣言部分。
- 標準出力（引き続き 5 行のはずです）。
- `wc -c build/balances.dat` の出力と、`cmp` の終了コード。
- 先頭 2 件の出力レコードについて、それぞれ 27 バイトを 3 つのグループ（口座番号 / 顧客番号 / 残高）に分けて記載します。

独立した確認方法：各レコードは `10 + 8 + 9 = 27` バイトのままで、3 件の合計は `81` バイトです。フィールド名は変えていないため、各出力レコードの口座番号、顧客番号、残高の値はベースラインと一致し、レコード内のバイト位置だけが変わります。

### 課題 2：ずれを作り、その位置を特定する

1. まずレコード 1 の 49〜56 桁目にある 8 文字を記録します。

3. `:PositionJump 49` で移動し、現在の 8 文字を記録します。
4. `wc -c` でファイルの総バイト数を確認します。

- プログラムはこのファイルに対してエラーを出しますか。その理由は。

### 課題 3：復元して検証する
