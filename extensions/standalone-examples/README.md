# 独立 COBOL 示例

这些示例可脱离 32 课主线单独阅读和运行。建议先学完对应主课，再把它们用作主题练习。

| 示例 | 对应课程 | 练习主题 |
|---|---|---|
| `INPUTCSV.COB` | 第 18、23 课 | `UNSTRING`、Copybook、CSV 输出 |
| `FIXEDREC.COB` | 第 10、17 课 | 定长记录、`REDEFINES`、状态校验 |
| `TBLSRCH.COB` | 第 11、13 课 | `OCCURS`、`SEARCH ALL` |
| `BATCHRPT.COB` | 第 22、32 课 | 排序输入、控制断点、审计报表 |

从本目录运行：

```sh
make check
make run
make clean
```
