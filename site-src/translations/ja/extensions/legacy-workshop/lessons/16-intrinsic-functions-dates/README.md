# 組み込み関数、日付、数値変換

## 学習目標

FUNCTION TRIM、LENGTH、NUMVAL、CURRENT-DATE、INTEGER、MAX/MINについて学びます。表示形式、内部数値、無効な入力を区別します。

このレッスンを終えたら、上記の用語を自分の言葉で説明し、小さなプログラムの中から対応する宣言箇所や実行箇所を見つけられるようになっているはずです。構文を暗記するだけでなく、まず入力、出力、状態の変化を観察しましょう。

## サンプルコード

[`L16.COB`](./L16.COB)を開きます。このレッスンのソースファイルは固定形式です。Divisionと段落はArea Aから始まり、宣言文と実行文はArea Bに配置されています。まずソースを1行ずつ読み、その後で実行しましょう。

## コンパイルと実行

リポジトリのルートディレクトリから実行します。

```sh
mkdir -p build
cobc -fsyntax-only extensions/legacy-workshop/lessons/16-intrinsic-functions-dates/L16.COB
cobc -x -Wall -o build/l16 extensions/legacy-workshop/lessons/16-intrinsic-functions-dates/L16.COB
./build/l16
```

期待される動作：テキストを整形して数値に変換し、その後、実行環境の日付を読み取ります。

コンパイラが書式や列位置のエラーを報告したら、まず7、8、12、72列目を確認します。次に、ピリオド、変数のPIC、スコープ終端の文を確認しましょう。`-Wall`は追加の警告を表示します。警告も内容を理解してから、対処するかどうかを判断してください。

## 各部分の理解

1. `IDENTIFICATION DIVISION`はプログラム単位を宣言し、`PROGRAM-ID`はコンパイラが認識するプログラム名です。
2. `DATA DIVISION`はプログラムの実行時に使うデータを記述します。このレッスンにフィールド宣言がある場合は、レベル番号とPICを確認しましょう。
3. `PROCEDURE DIVISION`は実行の開始位置です。`0000-MAIN`は読みやすくするための段落名にすぎず、自動的に繰り返し実行されることはありません。
4. 各文はソースの順に実行されます。制御フロー文によって経路が変わるか、`STOP RUN`でプロセスが終了するまで実行されます。

## 変更して試す

空文字列と数字以外のテキストを試してください。変換処理に検証を加え、NUMVALが業務上の入力検証を代替すると決めつけないようにしましょう。

変更のたびに、構文チェック、コンパイル、実行をやり直してください。一度に変更する概念は1つに絞り、変更前後の出力を記録しましょう。

## cobol.nvimで学ぶ

FUNCTION式については、cobcに最終的な構文チェックを任せましょう。プラグインの計算機能はPICを確認するためのもので、関数の評価は行いません。

プラグインが反応しない場合は、まず現在のファイルタイプを確認します。`:set filetype?`を実行し、次に`cobc --version`を確認してください。プラグインは移動、レイアウトのヒント、診断に使います。プログラムをコンパイルできるかどうかの判断基準は、GNUCOBOLによる実際のコンパイル結果です。
