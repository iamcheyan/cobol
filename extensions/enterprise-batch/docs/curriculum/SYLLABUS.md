# 企业 COBOL Batch 教学大纲

状态：课程制作设计，不表示以下实验已实现。总工时 76 小时，包括阅读、实验、调查和证据整理。模块 07/10/11 为核心，共 30 小时；有基础者可以通过入口测评缩短前 5 模块的复习时间，但仍须交实验结果。

## 模块与课次

### 01 COBOL 与 Legacy 系统（3 小时）

- 01.1 业务日、联机与夜间 Batch、程序与 JOB 的区别；绘制初始系统图。
- 01.2 GNUCOBOL 编译、链接、运行时、构建目录；编译同一银行程序并定位构建失败。
- 01.3 DIVISION/SECTION/Paragraph、句点与范围；固定/自由格式对照。
- 成果：环境证据、最小银行批处理入口、源码到执行文件关系图。
- 验收：从干净目录复现；指出输入、输出和实际入口；能解释列截断错误。

### 02 数据定义与客户 Record（4 小时）

- 02.1 PIC X/A/9、01/05/77/78/88、VALUE、分组项与基本项。
- 02.2 S/V、金额范围、隐含小数、MOVE 类别转换、截断与补齐。
- 02.3 客户 Record v1：ID、姓名、区分、状态；建立字段目录。
- 成果：客户 Copybook、字段契约、MOVE 实验表。
- 验收：能回答位数/字节数/数值范围的区别；解释负数和 MOVE 到 X 的实际实验结果。

### 03 数据底层表示（5 小时）

- 03.1 DISPLAY、SIGN/SEPARATE、COMP/BINARY/COMP-5、COMP-3；声明逻辑与 ABI。
- 03.2 把同一金额写为原始字节，用 Hex Dump 对照符号、隐含小数、字节序和长度。
- 03.3 非法 Packed Decimal、错位/错误长度的金额解析实验。
- 成果：金额表示实验包、字节解释表、解析器及坏数据检测策略。
- 验收：解释 S9(11)V99 COMP-3 的 13 个数字位与常见 7 字节存储；实际结果以锁定环境为准；无法把文件原始字节误当字符串。

### 04 复杂数据结构（5 小时）

- 04.1 REDEFINES、66 RENAMES、OCCURS、INDEXED BY、OCCURS DEPENDING ON。
- 04.2 Copybook/COPY REPLACING、REFERENCE MODIFICATION、布局版本与偏移。
- 04.3 阅读扩展业务记录：客户、账户、地址、风险、限额、联络和审计字段。
- 成果：150+ 具名字段记录、布局目录、字段定位练习。
- 验收：字段目录与编译器实测长度一致；能查出改一个字段会移动哪些后续字段。

### 05 程序控制与清洗（4 小时）

- 05.1 IF/EVALUATE、PERFORM 段落/内联/UNTIL/VARYING、作用域和落入后续段落。
- 05.2 SEARCH/SEARCH ALL 排序前提；STRING/UNSTRING/INSPECT、INITIALIZE。
- 05.3 客户状态标准化、必填校验、金额范围和拒绝原因分类。
- 成果：可复用校验逻辑、拒绝码目录、正常/异常清洗结果。
- 验收：业务拒绝与系统失败区分；每个拒绝码有最小夹具。

### 06 文件处理（6 小时）

- 06.1 SELECT/FD/SD、OPEN/READ/WRITE/CLOSE、FILE STATUS、EOF。
- 06.2 定长字节记录与 LINE SEQUENTIAL 的不同；换行不计入逻辑记录宽度；长度异常检测。
- 06.3 缺失/空文件、短行、长行、非法数字、重复 ID、未知状态与输入控制总数。
- 06.4 相对/索引文件、REWRITE/DELETE、锁定的阅读实验与适用边界。
- 成果：校验与转换程序、有效/拒绝输出、文件状态日志。
- 验收：读入=接收+拒绝；空文件是否允许由契约决定；失败无正式产物发布。

### 07 企业 Batch 核心算法（12 小时）

- 07.1 SORT 工作文件、SD、INPUT/OUTPUT PROCEDURE；排序校验与临时空间失败。
- 07.2 MERGE 已排序流；排序键、同键次序、重复键的契约。
- 07.3 Boss L1：1:1 Master/Transaction 顺序突合，三类输出与两边 EOF 组合。
- 07.4 Boss L2：1:N，按账户做 Key Break、按交易顺序累计、退款/冲正与余额溢出。
- 07.5 Boss L3：Master、Transaction、DB Snapshot、Previous Day 多流；定义业务 N:N，而非默认笛卡尔积。
- 07.6 Boss L4：150+ 字段逐字段比较，输出字段名、偏移、旧值/新值及比较规则。
- 成果：突合设计、状态转换表、实现、分类文件、差异报告、守恒证据。
- 验收：不得用 DB/Python/全量数组替代；数据量增长时内存有界；重复键/逆序/空文件/EOF/溢出都覆盖。

### 08 COBOL + DB（6 小时）

- 08.1 经过 P1 验证的 Embedded SQL 工具链、Host/Indicator Variable、NULL、SQLCODE/SQLSTATE。
- 08.2 DECLARE/OPEN/FETCH/CLOSE Cursor，区分无数据与错误。
- 08.3 按业务日抽取客户快照，与上游文件突合，输出差异。
- 08.4 更新、唯一约束、COMMIT/ROLLBACK、连接中断和事务重试。
- 成果：DB 初始化/种子数据、游标抽取、更新 Batch、事务证据。
- 验收：真实 DB 实验；重复业务日不重复更新；提交后崩溃有恢复方案；DB 特定错误明确标注。

### 09 模块化程序（4 小时）

- 09.1 CALL/LINKAGE/USING、BY REFERENCE/CONTENT/VALUE、RETURNING、GOBACK。
- 09.2 工作区生命周期、共通 Copybook、参数长度/版本及接口不匹配。
- 09.3 抽取金额计算、客户校验、日志模块；调用者与被调者共同影响调查。
- 成果：接口规格、公共模块和调用实验。
- 验收：多次调用结果正确；无隐含共享状态；失败状态被调用方准确传回。

### 10 Shell / JCL / Scheduler（9 小时）

- 10.1 Bash 参数、环境变量、配置优先级、业务日、路径和临时目录；POSIX sh 差异。
- 10.2 RC=0/4/8/12、pipefail、JOB 依赖和 Warning 放行策略。
- 10.3 锁、输入快照、校验和、日志、原子发布、Manifest。
- 10.4 全量重跑、阶段恢复、DB 提交后发布失败、重复交易与幂等。
- 10.5 读 JCL/JP1 等示意，映射到本地 JOB Flow；不声明未验证平台可运行。
- 成果：完整夜间 JOB、依赖表、恢复清单、运行手册。
- 验收：前置失败后下游不执行；并发启动拒绝；同营业日重跑不重复扣款；四个崩溃边界可恢复。

### 11 障害调查与维护（9 小时）

- 11.1 从 Scheduler 状态、JOB Log、RC、输入清单建立时间线，保留原始证据。
- 11.2 非法数字、记录错位与运行时异常：先重现，再定位根因。
- 11.3 DB 唯一约束、0 字节文件、Master 逆序、临时空间/权限失败。
- 11.4 RC=0 但余额或控制总数错误；调查业务正确性。
- 11.5 客户区分 1 位扩为 2 位：先交影响调查，再修改和回归。
- 成果：影響調査書、修正対象一覧、修正方針、Test Case、Evidence、事故复盘。
- 验收：根因有源码/数据/日志证据；修复不改原始输入掩盖问题；说明回滚与重跑边界。

### 12 综合项目与毕业验收（9 小时）

- 12.1 接收陌生版本的银行系统与设计书，复原架构和依赖。
- 12.2 完成客户区分扩展，处理正常日、异常日、重跑日。
- 12.3 运行全夜间流程：接收→校验→排序→突合→更新→报表→发布。
- 12.4 隐藏根因事故现场调查，提交证据和恢复操作。
- 成果：完整系统、设计与运行文档、维护变更包、测试与事故证据。
- 验收：符合制作标准的硬门禁；能解释为何没有破坏上下游。

## 插件贯穿练习

01/06 用固定格式标尺与诊断；02～04 用字段跳转、Copybook 预览和记录布局估算；07 用大纲和段落跳转追踪两个读取指针；09 复核调用接口；11/12 用导航完成影响调查。每项任务都有终端替代路径，插件缺失不得阻断课程。
