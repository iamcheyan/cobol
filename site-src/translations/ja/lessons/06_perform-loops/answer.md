# 第 06 課 修正演習 参考解答

この解答は `exercise.md` の `WS-LAST-SAMPLE` に対する変更のみを扱い、発展演習には答えません。すべての値はこの課の元の `lesson.cob` から出発し、コンパイルと実行のコマンドは README の `build/` フローに従います。

```sh
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_06 lesson.cob
./build/lesson_06
```

## 最終番号が 0 の場合

`01 WS-LAST-SAMPLE PIC 9 VALUE 0.` に書き換えます。初期インデックスは 1 であり、`1 > 0` がループ本体実行前に成立するため、サンプル行は出力されません。

```text
最終サンプル番号=0
処理件数=000
```

## 最終番号が 1 の場合

`01 WS-LAST-SAMPLE PIC 9 VALUE 1.` に書き換えます。番号 1 だけが処理され、2 へのインクリメント後は `2 > 1` でループ終了します。

```text
最終サンプル番号=1
例=001 符号=D 額=125.50
処理件数=001
```

## 最終番号が 3 の場合

もとの初期値を保てば、3 件の固定サンプルがそれぞれ一度ずつ処理されます。

```text
最終サンプル番号=3
例=001 符号=D 額=125.50
例=002 符号=W 額=040.10
例=003 符号=T 額=075.00
処理件数=003
```

## 最終番号が 4 の場合

`01 WS-LAST-SAMPLE PIC 9 VALUE 4.` に書き換えます。インデックス 4 も上限以下なのでループ本体は実行されますが、サンプルは 3 件しか定義されていないため、4 回目は `WHEN OTHER` でラベル付けされます。

```text
最終サンプル番号=4
例=001 符号=D 額=125.50
例=002 符号=W 額=040.10
例=003 符号=T 額=075.00
例=UNMAPPED
処理件数=004
```

`index > last` という条件は、インデックスが上限を超えたときにだけ真となるため、最終番号自体も処理対象になります。
