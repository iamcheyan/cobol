# スクロール位置のマーカー：satellite.nvim

Neovim 標準のスクロールバーは細い線だけなので、「ファイルのどこに変更やエラー、検索結果があるのか」が分かりません。

satellite はスクロールバーの位置に**縮小表示**を描き、カーソル、検索結果、診断、Git の変更をマークします。

---

## 1. 解決する問題

| 確認したいこと | 標準のスクロールバー | satellite |
|---|---|---|
| 変更が集中している場所 | 分からない | Git マーカーで表示 |
| エラーの行 | スクロールして探す | 診断マーカーで表示 |
| 検索結果の分布 | `n` で順に移動 | すべての位置を一度に確認 |
| ファイル内のカーソル位置 | スクロールバーの位置から推測 | 強調マーカーで表示 |

## 2. 設定内容

`lua/plugins/scrollbar.lua`（ファイル名は scrollbar ですが、導入されるのは satellite です）：

| オプション | 値 | 意味 |
|---|---|---|
| `current_only` | `false` | すべてのウィンドウにマーカーを表示 |
| `winblend` | `0` | 透明にしない |
| `zindex` | `40` | 表示レイヤー |

### 対象外のファイルタイプ

```lua
excluded_filetypes = {
  "contextline_menu", "dropbar_menu", "dropbar_menu_fzf",
  "DressingInput", "cmp_docs", "cmp_menu", "blink-cmp-menu",
  "noice", "prompt", "TelescopePrompt",
  "neo-tree", "aerial", "help", "lazy", "mason",
}
```

Neo-tree、Aerial、help、lazy、mason などの画面には**マーカーを表示しません**。画面上の情報が見づらくなるのを防ぐためです。

### 4種類のマーカー

```lua
handlers = {
  cursor = { enable = true, overlap = true, priority = 100 },
  search = { enable = true },
  diagnostic = { enable = true },
  gitsigns = { enable = true },
}
```

| マーカー | 情報源 | 意味 |
|---|---|---|
| `cursor` | カーソル位置 | 最優先（100）で、ほかのマーカーより前面に表示 |
| `search` | 検索結果 | すべての一致箇所 |
| `diagnostic` | LSP / `cobc` | エラーと警告 |
| `gitsigns` | Git 差分 | 変更、追加、削除 |

`overlap = true` はマーカーの重なりを許可し、`priority = 100` はカーソルマーカーを最前面に表示します。

## 3. 表示の見方

マーカーは**ウィンドウの右端**（スクロールバーの位置）に表示されます：

```text
内容行 1                    │
内容行 2                    ▎  ← Git 改动
内容行 3                    │
  ...                       ▪  ← 错误
内容行 40                   ┃  ← 光标
```

スクロールしなくても、このファイルには変更が3か所あり、5行目付近にエラーが1つあると分かります。

## 4. COBOL での利用場面

### 場面 1：一連のコード変更後に影響範囲を確認

マルチカーソルや grug-far で複数箇所を変更した後：

1. 右側の Git マーカーを確認します
2. マーカーが密集している場所が、変更の集中箇所です
3. `:Gitsigns` で一つずつ移動する必要はありません

### 場面 2：構文エラーを探す

`cobc` の診断が表示されたら：

1. 右側の診断マーカーを確認します
2. その位置まで直接スクロールします

**COBOL のコンパイルエラーは数行に集中することがよくあります**。マーカーで範囲をすぐに把握できます。

### 場面 3：検索結果の分布を確認

`<leader>fg` で `WS-RECORD-COUNT` を検索します。picker の代わりに `/` で検索した場合は：

1. 右側の検索マーカーを確認します
2. 30か所の一致がどこに分布しているか一目で分かります

### 場面 4：長いファイルでカーソル位置を把握

第32課のような数百行のプログラムでは：

1. 縮小表示のどこにカーソルマーカーがあるか確認します
2. ファイルのどのあたりにいるか分かります

## 5. 練習

### 練習 1：Git マーカーを確認

```sh
cd ~/development/cobol
nvim lessons/17_fixed-length-files/lesson.cob
```

1. 数行変更します（保存しません）
2. 右側を確認します

**確認ポイント**：変更した行に対応する位置に Git マーカーが表示される。

### 練習 2：診断マーカーを確認

1. わざとピリオドを1つ削除します
2. `:w` で診断を実行します
3. 右側を確認します

**確認ポイント**：診断マーカーが表示される。`u` で元に戻すと消える。

### 練習 3：検索マーカー

1. `/WS-RECORD-COUNT`
2. 右側を確認します

**確認ポイント**：すべての一致箇所にマーカーが表示される。

### 練習 4：カーソルマーカー

1. 長いファイルの100行目に移動します
2. カーソルマーカーの位置を確認します

**確認ポイント**：マーカーの位置がファイル内のおおよその位置に対応する。

### 練習 5：対象外の画面を確認

1. `<leader>fe` で Neo-tree を開きます
2. Neo-tree ウィンドウの右側を確認します

**確認ポイント**：satellite のマーカーが**表示されない**（`excluded_filetypes` に含まれるため）。

## 6. よくある問題

### マーカーが表示されない

現在のファイルタイプが対象外になっていないか確認します：

```vim
:echo &filetype
```

`excluded_filetypes` の一覧と照合してください。`help`、`mason`、`lazy`、`neo-tree`、`aerial` は対象外です。

### マーカーの色がテーマに合わない

マーカーの色は対応する highlight group（`DiagnosticError`、`GitSignsAdd` など）から取得します。テーマを変更すると色も追従します。

### 特定の種類のマーカーを無効にしたい

`handlers` の該当項目を `enable = false` にします。検索マーカーを表示しない場合：

```lua
search = { enable = false },
```

### ほかのスクロールバー系プラグインと競合する

この設定では satellite を使い、snacks の scroll は無効にしています（snacks のページを参照）。両方を同時に有効にしないでください。

### ウィンドウが狭くて表示されない

ウィンドウが狭すぎるとスクロールバーの表示幅が圧迫されます。ウィンドウを広げてください。

### `current_only = false` の意味

現在のウィンドウだけでなく、すべてのウィンドウにマーカーを表示します。現在のウィンドウだけに表示するには `true` に変更します。

## 7. ほかのプラグインとの役割分担

| マーカーの内容 | 情報源 |
|---|---|
| Git の変更 | gitsigns |
| 診断 | LSP または `cobc`（`cobol.nvim` 経由） |
| 検索結果 | vim の `/` 検索 |
| カーソル | satellite 自体 |

**satellite は情報を生成しません**。ほかのプラグインの情報をスクロールバーに表示するだけです。マーカーの動作を変えるには、それぞれのプラグインの設定を変更してください。

## 9. 適用範囲

- このページの設定元は `lua/plugins/scrollbar.lua` です（ファイル名は scrollbar ですが、導入されるのは satellite です）。
- マーカーは `cursor`、`search`、`diagnostic`、`gitsigns` の4種類です。
- 15種類のファイルタイプを対象外にしています（Neo-tree、Aerial、help、mason、lazy などには**表示されません**）。
- satellite は情報を生成せず、ほかのプラグインの情報を表示します。
- snacks の scroll 機能は無効で、スクロール位置のマーカーは satellite が表示します。
