課程は段階的に実装中です。実際のコード、受け入れ確認の入口、未完了項目は[課程制作の入口](../../curriculum/README.md)を参照してください。旧版の00–29課は[`legacy-workshop/`](../../../legacy-workshop/README.md)にアーカイブされています。旧版を根拠に新課程が完成したと主張してはいけません。技術検証→モジュール07のベンチマーク→基礎課程→エンジニアリング課程→障害調査と卒業課程の順に進めます。個別の実験に合格しても、モジュール完了とはみなしません。
