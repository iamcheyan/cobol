本节只使用第 15–20 课讲过的内容：顺序文件 `SELECT`/`OPEN`/`READ`/`CLOSE`、`FILE STATUS`、`AT END`、`EVALUATE TRUE`、`IF`、段落与 `PERFORM`。

## 修改练习（会在 `answer.md` 提供参考答案）

两项都只改**临时目录里的夹具副本**，不要改动仓库内的 `accounts.txt` / `transactions.txt`。先准备临时目录：

```sh
scratch=$(mktemp -d)
cp lesson.cob accounts.txt transactions.txt "$scratch/"
cd "$scratch"
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o lesson_20 lesson.cob
```

1. 从副本 `transactions.txt` 删除账户号 `A000000004` 对应的整行。运行 `./lesson_20`，检查主档键 `A000000003` 与当前交易键的比较结果，并记录 `照合件数` / `口座のみ` / `取引のみ` 三个计数。
2. 从原始夹具出发，把副本交易文件里以 `A000000004` 开头的那行改成账户键 `A000000003`、金额 `000005000`（仍为 20 字符，且文件保持升序）。运行后确认该笔与主档 `A000000003` 配对、两条流同时前进。

约束：不改 `lesson.cob`；每行长度与账户键顺序都必须保持正确。

每次修改后记录下来类计数、退出码和完整输出，并说明哪个分支推进了主档、交易，或两者。再用计数不变量自查：`照合件数 + 口座のみ` 应等于主档记录数，`照合件数 + 取引のみ` 应等于交易记录数。参考答案见 `answer.md`。
