# 第 10 课练习：REDEFINES

本节只使用第 10 课及先修课讲过的内容：`05`/`10` 层级数据项（第 [09](../09_group-items/README.md) 课）、`REDEFINES`、`MOVE`、`DISPLAY`、`PERFORM` 段落调用（第 [07](../07_paragraphs/README.md) 课）和 `STOP RUN`。

## 修改练习（会在 `answer.md` 提供参考答案）

### 基线

从本课原始 [`lesson.cob`](./lesson.cob)（工作区中未改动的版本）开始。建议先复制一份再改，例如 `cp lesson.cob /tmp/lesson_10_ex.cob`，这样基线仍可重跑。

### 改动位置与约束

只改 `2000-LOAD-TRANSFER` 中的这一条语句：

```cobol
           MOVE 250.75 TO WS-TRANSFER-AMOUNT
```

把 `250.75` 改为 `99.99`。

约束：

- 不要改动任何 `PIC`、字段顺序、`REDEFINES` 的声明位置与对象、两个视图的长度。
- 不要改动任何 `DISPLAY` 文本，也不要改动 `1000-LOAD-DEPOSIT` 或交易码、账户号、参考号的 `MOVE` 值。
- 只允许改这一个数值字面量；不要加 `COMPUTE`、`IF`、`EVALUATE` 或新的数据项。

### 命令

```sh
mkdir -p build                                   # 输出目录必须先存在
cobc -fsyntax-only lesson.cob                    # 语法检查
cobc -x -Wall -o build/lesson_10 lesson.cob      # 编译
./build/lesson_10                                # 运行，观察 12 行输出
echo $?                                          # 退出码
```

### 预期差异

标准输出仍是 12 行，其中**只有两行变化**：

| 行 | 原始值 | 改动后的值 |
|---|---|---|
| 8 | `振込金額=00250.75` | `振込金額=00099.99` |
| 12 | `参照番号=3210025075` | `参照番号=3210009999` |

其余 10 行（含第 11 行 `金額=00076.54`）逐字节不变。语法检查、编译返回码与运行退出码都是 `0`。

完整预期输出（改动后）：

```text
取引種別=D
入金口座=0001234567
入金額=00125.50
入金参照番号=TXN-000001
取引種別=T
振込元口座=0001234567
振込先口座=0007654321
振込金額=00099.99
同じバイト列の入金ビュー:
口座=0001234567
金額=00076.54
参照番号=3210009999
```

独立核算的依据（字节位置按本课 README 的布局表）：`9(5)V99` 存 7 个数字位，`99.99` 写入负载区 21–27 位，即 `0009999`；参考号读负载区 18–27 位 = 目标账户最后三位 `321` + `0009999` = `3210009999`。存款金额只读负载区 11–17 位（目标账户前七位 `0007654`），与第 21–27 位无关，所以它不变。

### 需要回答的问题

1. 为什么 `金額=00076.54` 没有随转账金额一起变化？它由哪几个字节位置决定？
2. `参照番号=3210009999` 里的 `321` 和 `0009999` 分别来自哪一段字节？
3. 源码里哪一条语句根据交易码决定用存款视图还是转账视图？如果找不到，那么「这次写入按转账视图进行」这件事是谁决定的？程序实际校验了哪些条件？
