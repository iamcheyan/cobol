# 独立预期

文本由业务政策和人工逐笔演算确定。`normal.txt`：账户1为1000+500−200−500=800；冲正可定位非紧邻的第一笔，第四笔900透支拒绝。冻结账户余额50不变，账户3没有交易余额0。输入5=接收3+拒绝2；总期初1050+贷方500−借方700=期末850。

`boundary-aggregate-over-13.txt`有账户1两轮各贷借9,000,000,000,000，单账户每次期末合法且贷/借累计各为18,000,000,000,000；账户2再贷9,000,000,000,000。因此全局贷27,000,000,000,000、借18,000,000,000,000、期末9,000,000,000,000。该算例能抓出把全局金额误用13位的实现。

各业务拒绝expected明确列出拒绝原因和拒绝后的余额；RC8夹具不得产生expected正式报告，因为预期是没有已发布目录。全部输出由`check.py`逐字节比对，不通过对整文件trim掩盖定宽差异。
