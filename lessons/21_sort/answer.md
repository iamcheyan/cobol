# 第 21 课修改练习参考答案

本答案只覆盖 `exercise.md` 中的两项修改练习，不提供举一反三练习答案。

## 1. 交换输入的前两行

在副本中把账户 `A000000001` 与 `A000000005` 两行互换。排序输出仍为：

```text
A000000001
A000000002
A000000004
A000000005
```

输入过程读取四行并各执行一次成功的 `RELEASE`；输出过程从排序工作文件 `RETURN` 四行：

```text
SUMMARY INPUT=004 OUTPUT=004
```

## 2. 添加账户 A000000006

在原始副本末尾追加：

```text
A000000006C0001006000000001
```

账户号是排序键中最大的值，因此在已排序输出的最后一行显示。输入过程释放五条记录，输出过程返回五条：

```text
並べ替え済み ACCOUNT=A000000006 CUSTOMER=C0001006 BALANCE=0000000.01
SUMMARY INPUT=005 OUTPUT=005
```
