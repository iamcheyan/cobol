# 第 15 課演習：テキストファイルの逐次読み込み

すべての演習は一時ディレクトリーでコピーを使って行います。リポジトリー内の [`transactions.txt`](./transactions.txt) は共有フィクスチャです。直接編集したり、実行生成物を課のディレクトリーに残したりしないでください。最初に一度だけ実行環境を準備します。

```sh
cd lessons/15_sequential-file-read
scratch_dir=$(mktemp -d)
trap 'rm -rf "$scratch_dir"' EXIT
cobc -x -Wall -o "$scratch_dir/lesson_15" lesson.cob
cp transactions.txt "$scratch_dir/"
```

2つの変更演習はどちらも、このクリーンなフィクスチャコピーから始めます。終了時に `$scratch_dir` を削除すれば環境をリセットできます。

## 変更演習（解答は [`answer.md`](./answer.md)）

### 1. 5件目のレコードを追加（行順と EOF）

- 基準：元のフィクスチャコピー。4行、195バイト（可視文字の合計は 43+53+42+53 = 191、改行文字が4つ）。
- 変更箇所と制約：一時ディレクトリー内のコピーだけを変更します。`lesson.cob` とリポジトリーのフィクスチャは変更しません。追加する行は100文字以内にします。

  ```sh
  printf 'DAY-20261013|TXN-000005|D|0001234567|10.00\n' >> "$scratch_dir/transactions.txt"
  ```

- 再コンパイル／実行：入力データだけの変更なので、**再コンパイルは不要**です。次を実行します。

  ```sh
  ( cd "$scratch_dir" && ./lesson_15 ); echo $?
  ```

- 予想される完全な差分：標準出力に `レコード=DAY-20261013|TXN-000005|D|0001234567|10.00` が1行追加されます。`EOF=はい レコード数=` は `04` から `05` に変わり、`オープン=OK` と `クローズ=OK` の行は変わりません。終了コードは引き続き `0` です。
- 理由：行順ファイルは行ごとにレコードを分けます。追加した行は次の `READ` で正常に読み込まれて件数が増え、その次の `READ` で EOF になります。

### 2. 空ファイル（空入力の境界）

- 基準：同じ元フィクスチャのコピー。
- 変更箇所と制約：コピーを空にし、ソースは変更しません。

  ```sh
  : > "$scratch_dir/transactions.txt"
  ```

- 再コンパイル／実行：再コンパイルは不要です。次を実行します。

  ```sh
  ( cd "$scratch_dir" && ./lesson_15 ); echo $?
  ```

- 予想される完全な差分：`レコード=` の行はありません。`オープン=OK`、`EOF=はい レコード数=00`、`クローズ=OK` の3行だけになり、終了コードは `0` です。
- 理由：空ファイルでも正常に `OPEN` できます。最初の `READ` ですぐ `AT END` に進むため、正常に読めたレコードもエラー状態もありません。

## 学んだことを応用する（解答なし）

カスタマーサポートのイベントを表す3行のファイルを作成し、データと検証方法を自分で決めてください。1行はちょうど100文字、別の1行は101文字にします。

1. `wc -c` でファイルのバイト数を記録します。実行**前に** `レコード=` 行数と `レコード数` の予想を書きます。
2. ファイルを実行ディレクトリー内の `transactions.txt` にコピーし、本課でビルドしたプログラムで読み込みます。予想と実際を比較し、各レコードがどう区切られたか説明します。
3. バイト数、行長、レコード数をどう独立して検算したか、また101文字の行を100文字に短縮した場合に結論がどう変わるか説明します。

本課の読み込み方法だけを使用してください。ソース変更、フィールド解析、データベース書き込みは禁止です。解答はありません。
