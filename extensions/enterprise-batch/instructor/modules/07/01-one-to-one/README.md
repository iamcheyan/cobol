# L1 讲师说明

参考实现是 MATCH.COB；学员起始程序在课程目录。判分重点是两个独立 EOF、有序性校验、每次只消费应推进的记录，以及失败候选不发布。

提示阶梯：①手工列出键1/2/3/5/7/8；②问当前未消费的两条各是哪条；③问哪一条未来再也不能匹配；④最后才提示 EVALUATE TRUE 和 EOF 优先顺序。

常见缺陷：读前先比较未初始化缓冲；EOF 后继续拿旧键比较；相等只推进一侧导致重复输出；孤立交易被直接忽略；只校验第一条；在 PIC 数字接收后才推测原始宽度；发现逆序却仍发布先前明细。各缺陷必须说明触发夹具。

评分（本课100分）：状态图25、流式实现25、输入及异常20、计数/金额核算15、证据和解释15。任何失败发布、修改原输入、用数组/DB/Python代替核心算法均不通过。

NUL 故障修复证据：原实现只检查 ID 非空，16字节中含NUL也被接受；独立异常测试先失败，再增加逐字节A–Z/0–9验证。并发故障证据：预建目标.lock曾仍发布；测试先失败，再加入mkdir独占锁。

本课尚不是完整模块07：L2 Key Break/余额、L3多流、L4大记录及SORT/MERGE单元分别实施，不能因L1通过勾选整个模块。
