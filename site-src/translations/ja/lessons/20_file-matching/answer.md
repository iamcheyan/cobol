# 第 20 課 改変練習の参考解答

この解答では `exercise.md` の 2 つの改変練習だけを扱い、応用問題の解答はありません。どちらも一時ディレクトリ内のフィクスチャのコピーで行います：

```sh
scratch=$(mktemp -d)
cp lesson.cob accounts.txt transactions.txt "$scratch/"
cd "$scratch"
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o lesson_20 lesson.cob
```

## 1. 口座 A000000004 の取引を削除

コピーした `transactions.txt` から `A000000004` で始まる 20 文字の行を削除します（削除後もファイルは 3 行で、昇順を保ちます）。このとき、現在の主ファイルキー `A000000003` は次の取引キー `A000000005` より小さいため、プログラムは先に `口座のみ` を出力し、主ファイルだけを進めます。その後 `A000000005` は主ファイルと照合され、`A000000006` は取引のみのレコードに分類されます：

```text
口座のみ 口座番号=A000000003 顧客番号=C0001003 残高=0000002.00
一致 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75 種別=T 金額=0000040.00
取引のみ 口座番号=A000000006 種別=D 金額=0000020.00
照合件数=002 口座のみ=001 取引のみ=001
```

不変条件の確認：`2 + 1 = 3`（主ファイルのレコード数）、`2 + 1 = 3`（削除後の取引件数）。終了コードは `0` です。

## 2. 取引キー A000000004 を A000000003 に変更

コピーした取引ファイルで `A000000004` から始まる行を次の内容に変更します：

```text
A000000003D000005000
```

20 文字のままで、ファイルの順序 `A000000001`、`A000000003`、`A000000005`、`A000000006` も昇順のままです。このキーは主ファイルの 2 番目のレコードと等しいため、プログラムは `一致` を出力して両方のストリームを進めます：

```text
一致 口座番号=A000000003 顧客番号=C0001003 残高=0000002.00 種別=D 金額=0000050.00
一致 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75 種別=T 金額=0000040.00
取引のみ 口座番号=A000000006 種別=D 金額=0000020.00
照合件数=003 口座のみ=000 取引のみ=001
```

不変条件の確認：`3 + 0 = 3`（主ファイルのレコード数）、`3 + 1 = 4`（取引レコード数）。終了コードは `0` です。

両方の練習が示すのは同じことです。分類と件数は現在のキーのどちらが大きいかだけで決まるため、入力が本当に昇順であり、キーが一意でなければなりません。プログラムはどちらの条件も確認しません。
