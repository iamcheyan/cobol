# GnuCOBOL 实战课程总目录

> 状态：32 课目录与第 01 课最小源码例外已获用户确认。各课独立目录均含四项课程交付；按本目录的先修关系推进，每课完成后单独验证。

## 课程定位

面向有编程、Linux、Oracle/PostgreSQL 和 CSV/TXT 基础、但没有 COBOL 基础的学习者。目标是独立交付 Linux 上的 GnuCOBOL 批处理程序：CSV 与定长文件处理、数据校验、文件对账、迁移、报表和数据库批处理。贯穿项目逐步从控制台小程序演进为银行对账系统。

每课固定交付 `lesson.cob`、`README.md`、`exercise.md`、`answer.md`。README 负责目标、概念、编译运行、逐行解释、输入输出和企业场景；练习分为有参考答案的修改练习与无答案迁移练习；答案文件只回答修改练习。

课程源码采用仓库要求的固定格式：第 7 列指示符区，Area A/B 从第 8/12 列起，程序文本不越过第 72 列。编译器与目标平台行为以实际 GnuCOBOL/Linux 验证为准。

## 教学依赖链与项目演进

```text
01–08 语言与控制流
  → 09–14 记录布局和内存表
  → 15–22 文件读取/写入、CSV/定长、排序和匹配
  → 23–28 Copybook、子程序、接口、错误与日志、工程构建
  → 29–31 真实 Embedded SQL、游标、文件与数据库同步
  → 32 银行对账毕业项目
```

项目数据从课程早期的常量输出和手工样例开始；随后引入账户/交易记录，再提供可复现输入夹具，逐课增加 CSV、固定长文件、多文件、匹配输出、模块接口和数据库快照，最后组合为完整批次。每个综合练习只使用其先修课已讲授的语法和工具。
