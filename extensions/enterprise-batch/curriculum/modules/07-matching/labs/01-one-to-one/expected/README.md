# 独立预期依据

输入双方的账户键分别为 `{1,3,5,8}`、`{1,2,5,7}`。按升序取两集合并集：1共同、2交易、3账户、5共同、7交易、8账户。没有余额计算。

正常输入账户金额之和为 17000，交易金额之和为 1900。MATCH 对应账户金额 6000、交易金额800；MASTER ONLY 账户金额11000；TX ONLY交易金额1100。因此原始输入按分类还原时金额也守恒：17000=6000+11000，1900=800+1100。本课报告仅列键，核对金额需回到所保留输入快照，L2 会输出金额控制表。

边界预期由 `scripts/check.py` 直接写明，包含双方为空、单方为空、最后记录共同、两种 EOF 先后顺序。异常数据一律无正式输出、RC8；缺文件/锁/覆盖旧结果为RC12。正常日期20261009，20260230为非法日历日期。
