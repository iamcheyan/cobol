# 固定形式の列ルールとルーラー

業務ロジックを書く前に、COBOL 特有の**固定参照形式（80 列）**を理解しましょう。

---

## 1. 基礎：なぜ 80 列なのか

現代のプログラマーは自由なインデントに慣れていますが、標準 COBOL（ANSI 68/74/85）は**80 列のホレリス式パンチカード**の時代に生まれました。コードは幅 80 列のカードに穿孔されていたため、COBOL では各列の役割が厳密に定められています。

```text
列号: 1----6  7   8---11  12---------------------------------------------72  73----80
区域: SEQ    IND  Area A  Area B (语句主体)                                  IDENT
标尺:        │   │       │                                                │
代码: 000100      0000-MAIN-LOGIC SECTION.
```

### 5 つの領域の早見表

| 列 | 領域 | 構文ルールと用途 |
|---|---|---|
| **1–6** | **Sequence Number（連番領域）** | 歴史的にはカードの順番を記録し、落としたカードの束を元に戻すために使われました。現代のプロジェクトでは空欄にするか 6 桁の行番号を入れるのが一般的で、コンパイラーは既定で無視します。 |
| **7** | **Indicator（標識列）** | **行の種類を指定**します。<br>• `*`：コメント行（必ず 7 列目に置く）<br>• `/`：印刷時に改ページ<br>• `-`：文字列を次の行へ継続 |
| **8–11** | **Area A（A 領域）** | **構造定義領域**（8 列目から開始）：<br>• 4 つの Division 宣言（`IDENTIFICATION DIVISION.` など）<br>• Section 名と Paragraph 名<br>• ルートレベルのレコード変数 `01` と独立変数 `77`<br>• ファイル記述子 `FD` / `SD` |
| **12–72** | **Area B（B 領域）** | **実行文の領域**（12 列目以降から開始）：<br>• `MOVE`、`PERFORM`、`IF`、`OPEN`、`DISPLAY` などの業務命令<br>• 従属データ項目（`05`、`10`、`15` など）<br>• レベル `88` の条件名 |
| **73–80** | **Identification（識別領域）** | 歴史的にはプログラム識別子の記録に使われました。**警告：現代の GnuCOBOL や IBM のコンパイラーは 72 列目以降のコード文字をすべて無視します！** 範囲外の文字は切り捨てられるため、COBOL 初心者が見落としやすい重大な落とし穴です。 |

---

## 2. プラグインの便利な機能

`cobol.nvim` を使えば、空白を手で数える必要はありません。
1. **細線ルーラー（`│`）**：7、8、12、73 列目を正確に示します。濃い背景色の帯は使わず、文字がある場所では表示を避けます。
2. **Winbar の構造パンくず**：ウィンドウ上部に、現在の Division / Section / Paragraph の階層を表示します（例：`[ DATA DIVISION ]`、`[ PROCEDURE DIVISION > 2000-PROCESS-SECTION > 2100-PROCESS-RECORD ]`）。
3. **72 列超過の警告**：72 列を超えたコードに赤い波線を表示します。
4. **列移動ショートカット**：重要な列へ直接移動できます。
5. **Tab の自動停止位置**：行頭で Tab を押すと、7、8、12 列目へ移動します。
6. **7 列目のコメント切り替え**：コードのインデントを変えず、正しい列の `*` を切り替えます。

![Neovim の COBOL 列ルーラーと Winbar](images/fixed-format-ruler.png)

スクリーンショットのルーラーは 7、8、12、73 列目を示しています。Winbar には `[ DATA DIVISION ]` のパンくずが表示され、72 列を超えた箇所が強調されています。Neovim で実際にプラグインを動かした画面です。

## 3. 実践演習

ターミナルでサンプルファイルを開きます。

```bash
cd <仓库根目录>
nvim extensions/standalone-examples/INPUTCSV.COB
```

### 演習 1.1：ルーラーとパンくずの位置を確認する
1. 画面上部の Winbar にあるパンくずを見ます。カーソル位置に応じて、たとえば次のように変化します。
   ```text
   [ PROCEDURE DIVISION > 2000-PROCESS-SECTION > 2100-PROCESS-RECORD ]
   ```
2. エディター内の細いスチールブルーの縦線 `│` を 4 本確認します。7 列目（Indicator）、8 列目（Area A）、12 列目（Area B）、73 列目（Area B の範囲外）を示します。
3. 文字のある場所ではルーラーが表示を避け、空行や短い行では画面を縦に貫いている様子を確認します。

### 演習 1.2：列移動ショートカットを試す
Normal モードで、カーソルを任意の行に置きます。
1. **`g8`** を押すと、Area A の先頭である **8 列目**に移動します。
2. **`g12`** を押すと、Area B の先頭である **12 列目**に移動します。
3. **`g7`** を押すと、Indicator の **7 列目**に移動します。
4. **`g73`** を押すと、Identification の先頭である **73 列目**に移動します。

> 💡 **練習のコツ**：`g8` → `g12` → `g7` を何度か繰り返し、指に覚えさせましょう。

### 演習 1.3：ルーラーと Winbar の表示切り替え
`:CobolGuideToggle` を実行して表示を切り替え、もう一度実行して元に戻します。`:CobolGuideDisable` と `:CobolGuideEnable` も使えます。

### 演習 1.4：Tab の自動インデントを試す
COBOL では通常、Paragraph 名を Area A（8 列目）、文を Area B（12 列目）に置きます。空白キーを何度も押す代わりに、Tab を使います。
1. 空行を見つけて `o` を押し、Insert モードに入ります。
2. カーソルは 1 列目にあります。**`<Tab>`** を 1 回押します。
3. **確認**：先頭の空白が 7 列目（Indicator）まで移動します。
4. もう一度 `<Tab>` を押すと 8 列目（Area A）に移動します。`3100-MY-LOGIC.` のような Paragraph 名を入力できます。
5. さらに `<Tab>` を押すと 12 列目（Area B）に移動します。`DISPLAY "HELLO".` のような文を入力できます。12 列目以降の Tab は `shiftwidth` 分インデントします。
6. `<Esc>` を押して Insert モードを終了します。

### 演習 1.5：7 列目のコメントを切り替える
固定形式 COBOL の行コメントは、コメント記号を必ず 7 列目に置きます。一般的なコメントプラグインは行頭に `*` を挿入するため、コードの列位置がずれてしまうことがあります。
1. 先ほど入力した行にカーソルを置きます。
2. **`<leader>c*`** を押すか、`:CobolToggleComment` を実行します。
3. **確認**：7 列目に `*` が入り、コードのインデントを保ったまま正しい COBOL コメント行になります。
4. **`<leader>c*`** をもう一度押すと記号が削除され、実行可能な行に戻ります。
5. **複数行の切り替え**：`V` で Visual 行モードに入り、`j` で 3 行を選択してから **`<leader>c*`** を押します。選択したすべての行で 7 列目のコメントが切り替わります。

### 演習 1.6：72 列超過のガードを確認する
1. `MOVE ... TO OUTPUT-RECORD` など、任意の行末にカーソルを移動します。
2. Insert モードに入り、72 列目を超えるまで長い文字列を入力します。
3. **確認**：73 列目以降の文字に、目立つ**暗赤色の背景と明るい赤色の波線**がすぐに表示されます。
4. **考えてみましょう**：コンパイラーはこれらの文字を破棄するため、72 列目を超えたコードは欠落し、原因の分かりにくいエラーにつながります。`u` を押して入力を元に戻します。

## 4. クイックリファレンス

| キー／コマンド | モード | 動作 |
|---|---|---|
| `g7` | Normal | 7 列目（Indicator）へ移動 |
| `g8` | Normal | 8 列目（Area A の先頭）へ移動 |
| `g12` | Normal | 12 列目（Area B の先頭）へ移動 |
| `g73` | Normal | 73 列目（Identification の先頭）へ移動 |
| `:CobolGuideToggle` | コマンドライン | 表示ガイドと診断の紐付けを切り替え |
| `<leader>c*` | Normal / Visual | 1 行または複数行の 7 列目で `*` コメント記号を切り替え |
| `<Tab>` | Insert | 行頭または先頭空白で Tab：1–6 列目から 7 列目、7 列目から 8 列目、8–11 列目から 12 列目へ移動。12 列目以降は `shiftwidth` 分インデント |
