# 模块 03 讲师参考

- `M03BYTES.COB`：canonical 参考实现，`M03_LESSON=1|2|3` 选择课程。
- 学员只需要实现 `starter/M03BYTES.COB` 的三个 TODO；参考实现用于验收和提示阶梯。

## 提示阶梯

1. 先只求 `LENGTH OF`，把“声明位数”和“物理字节”分开列表（`ceil((N+1)/2)`）。
2. DISPLAY 无 `SIGN SEPARATE` 是覆盖符号；让学生先看末字节是 `0x37` 还是 `0x77`。
3. 03.2 把同一金额分别落到各类字段，用 `REDEFINES` 成 `PIC X` 再逐字节转 hex。
4. 03.3 先做长度取模，再逐半字节校验；**通过校验前不得进入算术**。
5. 结构错误（长度错位）与业务拒绝（坏半字节）分开：前者 RC8 零发布，后者 RC4 出报告。

## 评分（建议）

- 字节/位数解释与 ABI 正确 30%
- Hex 与独立核算一致 25%
- 非法 Packed / 错位检测且不先算术 25%
- 失败不发布、锁与复位 10%
- 证据完整（命令、原始 RC、校验和）10%

## 常见错误

- 用 `MOVE` 把 `COMP-3`/`COMP` 转成字符再比较（丢失原始字节）。
- 只靠 `FILE STATUS` 判断短记录（GnuCOBOL 会补空格返回 00）。
- 把负零当非法，或把 F 符号 nibble 当合法。
- 使用 `-std=cobol85` 导致 `COMP-3` 编译失败后误改 PIC。
