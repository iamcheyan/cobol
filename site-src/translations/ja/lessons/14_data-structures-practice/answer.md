# 第 14 課変更演習：参考解答

この解答は `exercise.md` の2つの変更演習だけを扱い、「学んだことを応用する」の解答はありません。各変更は元の `lesson.cob` から個別に始めます。コンパイルと実行のコマンド：

```sh
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_14 lesson.cob
./build/lesson_14
```

## 4件目の振込を成功させる

`1100-LOAD-TRANSACTIONS` で振込先口座を次のように変更します。

```cobol
           MOVE "0002468101" TO WS-TARGET-ACCOUNT(4)
```

4件目は `0007654321` から `0002468101` に `20.00` を振り込みます。結果と集計の想定値：

```text
結果=POSTED 振込元口座=0007654321 振込先口座=0002468101
口座残高 口座=0001234567 残高=0001085.50
口座残高 口座=0002468101 残高=0000295.00
口座残高 口座=0007654321 残高=0000070.00
集計 処理件数=04 成功=04 拒否=00
```

## 残高不足時にどちらの口座も更新されないことを確認

元のソースから始め、4件目の取引を変更します。

```cobol
           MOVE "0001234567" TO WS-TARGET-ACCOUNT(4)
           MOVE 100.00 TO WS-TRANSFER-AMOUNT(4).
```

振込先は存在しますが、振込元の口座 `0007654321` の残高は `90.00` だけです。想定出力：

```text
結果=拒否 REASON=INSUFFICIENT_FUNDS
口座残高 口座=0001234567 残高=0001085.50
口座残高 口座=0002468101 残高=0000275.00
口座残高 口座=0007654321 残高=0000090.00
集計 処理件数=04 成功=03 拒否=01
```

プログラムは残高を更新する前に振込元、続いて振込先を検索します。振込先がない場合や残高不足の場合に、片方だけを更新することはありません。ただし、これは文の実行順による保護だけです。本課ではトランザクション、ロールバック、再実行の保証はありません。両側が別ファイルやデータベースに保存される場合は、更新順序と失敗時の復旧を別途設計する必要があります（第31、32課参照）。
