# B04 主代理独立验收约定


## 独立性

- 先选定人工变更记录，再运行参考实现；不得从参考程序输出生成expected。
- 独立标本使用手工定位的首/中/尾字段，以及DISPLAY、COMP、COMP-3、规范化文本、忽略和敏感字段。记录原字节十六进制与人工语义值。
- 布局验收逐字段比较目录偏移/长度与编译器实际地址差和LENGTH OF，覆盖全部150+业务叶子字段；仅总长度正确不足以通过。REDEFINES别名不重复计数。

## 必须证实的行为

| 反例 | 所需证据 |
|---|---|
| 完全相同 | 无差异，记录/字段计数准确，RC0 |
| 首、中、尾业务字段分别变化 | 每次仅正确字段出现，稳定ID/名称/offset/len/规则准确 |
| 多字段跨组变化 | 独立清单与实际报告集合相等，无漏项/额外项/重复项 |
| 原字节不同但规范化文本相等 | 遵守批准的文本规则，不误报业务变化 |
| 原字节不同但解码数值相等 | 根据批准的合法编码判相等；不得将非法表示当合法相等 |
| 正负、小数缩放、边界及零 | 报告语义值与原字节相符，无精度丢失/静默截断 |
| 忽略/审计字段变化 | 按批准规则分类，计数可核对，不偷计业务差异 |
| 敏感字段变化 | 差异定位仍可审计，报告和日志无明文敏感值 |
| 非法packed nibble/符号、DISPLAY数字、编码或范围 | 在危险数值操作前拒绝；RC8且无发布 |
| 键/版本冲突、短长/截断记录、空流 | 各按批准契约处理；二进制framing按字节而非splitlines验证 |
| 输出/control/hash验收被破坏 | 独立验收拒绝且正式目录不存在 |
| 既有目标、任意锁、工具/资源失败 | 不覆盖，不删除别人锁；系统RC12不发布 |
| 学员源码与reset | COURSE_SOURCE实际被测试；starter可编译；源码/未知文件与活锁受保护 |

## 规模与课程包

压力测试分别报告输入记录数、物理宽度、处理字段数、真实最大关联组、核心子进程RSS、实际磁盘行为及故障。目录/报告全量缓存不能被测试驱动的RSS口径隐藏。测量覆盖与算法相符的增长维度。

最终证据必须固化core、runner、verifier和测试数据哈希，区分执行代理和主代理运行。教材需要真实逐字段手算、如何修改/编译/运行/定位差异、讲师评分、学生证据、编辑器插件与终端替代。读完字段目录不能替代实际比较课程；学员包答案隔离仍由B05/B14总打包验收。
