# 第 05 课练习：EVALUATE

## 修改练习（答案见 `answer.md`）

在 `lesson_05.cob` 中，每次只修改 `WS-TRANSACTION-CODE` 的 `VALUE` 子句，重新编译并运行：

1. `W`：应分类为取款。
2. `T`：应分类为转账。
3. `X`：未定义代码，应进入 `WHEN OTHER`。
4. `d`：小写字符与约定的大写 `D` 不同，也应进入 `WHEN OTHER`。

比较完整输出，确认每次只显示一个类别和一个动作。答案只覆盖这些修改练习。
