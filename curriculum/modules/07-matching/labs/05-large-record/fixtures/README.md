# 固定二进制夹具

`old.dat` 与 `new.dat` 是 `scripts/generate-fixtures.py` 生成的固定宽度二进制流：每条记录1,778B，文件中没有LF或其他分隔符。SHA256SUMS覆盖原始字节；更新夹具时先审查十六进制差异，再单独核对人工expected，不能从程序输出反向生成答案。

正常夹具旧流含客户0000000001、0000000003；新流含0000000001、0000000002、0000000003。客户0000000002为NEW-ONLY。匹配客户0000000001的revision、合法姓氏和V1分类字段变化；各位置、规则、脱敏与控制数独立写在`../expected/normal.txt`。
