# Module 11 Fixture Guide

Each fixture is an **input directory** containing a `MANIFEST` (business date, layout version, file checksums) and the declared files themselves. Incident fixtures are “raw inputs delivered to the input directory” and **must not be modified**; `fixtures/SHA256SUMS` is generated by `instructor/modules/11-incidents/tools/gen_course.py` and compared before and after execution by `scripts/check.py`.

Fixtures use **neutral event IDs**. This table gives symptoms and original RC only; it does **not include root causes**. The root cause for each fixture (for instructors) is documented in `instructor/modules/11-incidents/INSTRUCTOR.md` and its corresponding `ROOT-CAUSE.md`.

| Fixture | Symptom (no root cause) | as-found RC |
|---|---|---:|
| `normal/` | 3 accounts, 4 valid transactions, no rejections | 0 |
| `INC-2026-001/` | JOB002 structural failure; no publication for the day | 8 |
| `INC-2026-002/` | Current system publishes with RC0; balances do not match the business ledger | 0 (defect) |
| `INC-2026-003/` | JOB001 aborted (file does not match Manifest declaration); no publication | 12 |
| `INC-2026-004/` | JOB005 aborted; candidate not generated | 8 |
| `INC-2026-005/` | JOB003 aborted (runtime environment injection); no publication | 12 |
| `INC-2026-006/` | Current system publishes with RC0; control totals do not match the upstream declaration | 0 (defect) |
| `INC-2026-007/` | JOB002 structural failure (record length/alignment mismatch); no publication | 8 |

- `INC-2026-005` has the same inputs as `normal`; the failure comes from the runtime environment (see its `student/run.sh`).
- Data is fixed and deterministic (FR-10), with no randomness or seed.
- A **copy of the original inputs** for each event is stored separately in `INC-2026-00X/student/input/`; the contents are identical.
- `enterprise-customer/customer.v1` is **not** an input-directory fixture. It is the independent, versioned enterprise customer layout V1 baseline for the 11.5 maintenance lesson (23 bytes), without a MANIFEST, used only for migration/rollback/parallel verification.

Generator: `python3 instructor/modules/11-incidents/tools/gen_course.py` (rebuilds `fixtures/`, `expected/`, and `SHA256SUMS`).
