## CUSTOMER v1 实物（27 字节）

Copybook `copybooks/CUSTOMER-V1.CPY`：`X(8) + X(10) + X(8) + X(1) = 27`。原始字节（第一条
normal 记录，`\n` 为 LF，不计入记录长度）：

```text
00000001(8) ALICE+5空格(10) 00012345(8) A(1) \n
00000001ALICE     00012345A
```

```bash
head -c 27 curriculum/modules/02-data/fixtures/normal/customer.dat | wc -c
# 27
head -1 curriculum/modules/02-data/fixtures/normal/customer.dat | od -An -tc
# ... A L I C E (spaces) 0 0 0 1 2 3 4 5 A \n
```

`experiments/layout/LENGTH-PROBE.COB` 对两种 `-I` 编译实测：

```bash
cobc -Wall -I .../copybooks -x -o /tmp/probe-canon .../LENGTH-PROBE.COB && /tmp/probe-canon
# CUSTOMER-RECORD=27  NAME-LENGTH=10
cobc -Wall -I .../experiments/layout -x -o /tmp/probe-off .../LENGTH-PROBE.COB && /tmp/probe-off
# CUSTOMER-RECORD=28  NAME-LENGTH=11   （名称被错写 X(11)）
```

## 限制与未解决项

- 仅在 Linux x86-64 验证；macOS/WSL/ARM 未验证。
- 运行时的 `libxml` 版本 warning 走 stderr，不影响 stdout/报告。
- 名称字段本模块限制 ASCII（单字节=单字符）；多字节/EBCDIC 是后续模块的独立实验。
- `balance_demo` 仅为教学金额，单位“分”、无符号；进入 ACCOUNT v1 后的带符号/币种/期初语义
  留待账户模型模块；本模块不实现账户余额（遵循 BANK-SYSTEM 的演进说明）。
- `curriculum/check.sh`（全局门禁）本次未修改、不包含本模块入口；本模块用自带
  `scripts/check.sh` 验收。
