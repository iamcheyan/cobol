# 第 21 课修改练习参考答案

本答案只覆盖 `exercise.md` 中的两项修改练习，不提供举一反三练习答案。两项都在临时目录的夹具副本上做：

```sh
scratch=$(mktemp -d)
cp lesson.cob accounts-unsorted.txt "$scratch/"
cd "$scratch"
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o lesson_21 lesson.cob
```

## 1. 交换输入的前两行

把副本 `accounts-unsorted.txt` 的 `A000000005` 行与 `A000000001` 行互换（其余两行不动），文件变为：

```text
A000000001C0001001000100000
A000000005C0001005000025075
A000000004C0001004000002500
A000000002C0001002000000200
```

排序输出与原始夹具完全相同，仍按账户号升序：

```text
ソート済み 口座番号=A000000001 顧客番号=C0001001 残高=0001000.00
ソート済み 口座番号=A000000002 顧客番号=C0001002 残高=0000002.00
ソート済み 口座番号=A000000004 顧客番号=C0001004 残高=0000025.00
ソート済み 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75
入力レコード数=004 出力レコード数=004
```

输入过程 `1000-LOAD-INPUT` 读取四行、各执行一次成功的 `RELEASE`；输出过程 `2000-RETURN-SORTED` 从排序工作文件 `RETURN` 四行。退出码 `0`。

## 2. 添加账户 A000000006

在原始副本末尾追加（共 27 字符）：

```text
A000000006C0001006000000001
```

账户号 `A000000006` 是排序键中的最大值，因此出现在最后一行；余额数字 `000000001` 按 `9(7)V99` 显示为 `0000000.01`：

```text
ソート済み 口座番号=A000000001 顧客番号=C0001001 残高=0001000.00
ソート済み 口座番号=A000000002 顧客番号=C0001002 残高=0000002.00
ソート済み 口座番号=A000000004 顧客番号=C0001004 残高=0000025.00
ソート済み 口座番号=A000000005 顧客番号=C0001005 残高=0000250.75
ソート済み 口座番号=A000000006 顧客番号=C0001006 残高=0000000.01
入力レコード数=005 出力レコード数=005
```

输入过程释放 5 条记录，输出过程取回 5 条，计数不变量 `005 = 005` 成立，退出码 `0`。

两题都不需要改源码：`SORT` 只按 `SD-ACCOUNT-NUMBER` 重排，输入文件的物理行序不影响结果。
