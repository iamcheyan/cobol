# コース図版の規約

このファイルは、レッスンの Markdown に置く SVG 図の描き方を定め、32 レッスンが同じ一連の図に
見えるようにするためのものです。図を追加する前に読み、既存の
`lessons/01_hello-cobol/assets/fixed-format-columns.svg` を手本にしてください。

## 図を入れる価値があるとき

**図が段落一つ分を置き換えられる**ときだけ描きます。典型的な該当例：

- バイト配置、項目のオフセット、同じ記憶域に対する複数のビュー；
- 段階間を流れるデータ（読み込み → 検証 → 突合 → 書き出し）；
- 二つのストリームが並行して進み、統合し、あるいは別の行き先へ分岐する様子；
- 状態遷移とライフサイクル（オープン / 取得 / クローズ）；
- 抽象概念の対比（逐次探索と二分探索、3 通りの引数渡し）。

描かないもの：

- 本文の箇条書きや表をそのまま描き直しただけの図；
- 構文の見本（コードブロックで足ります）；
- 純粋な装飾（アイコン、色ブロック、元の場所へ戻るだけの矢印ループ）。

## 置き場所と参照

- 各図はそのレッスンの `lessons/<レッスン>/assets/` に置き、`record-layout.svg` のような
  短い小文字のハイフン区切り英語ファイル名を付けます。
- Markdown からは相対パスで参照します：`![説明](assets/record-layout.svg)`。
- 図は**一つだけ**描いて三言語で共有するため、ラベルは常に英語（COBOL のキーワードや項目名に
  合わせる）とし、長い文にはしません。説明は図注または本文に書きます。

## キャンバスとサイズ

- `viewBox` は一つだけ。固定の `width`/`height` は付けず、容器に合わせて拡大縮小させます。
- 本文段に合わせます：`viewBox` の幅は 760〜980、高さは内容次第ですが 620 を超えないこと。
- 幅 350px（スマートフォン）でも読めること：本文の文字は 11px 未満にせず、20px 以内の隙間に
  ラベルを詰め込まないこと。

## 描画のルール

- すべての SVG に淡い角丸のカード背景（`rx="10"` の `rect`）を付けます。これにより明暗どちらの
  テーマでも「一枚の図」として見え、黒地に黒文字になりません。
- フォント：`font-family="'DM Sans','Noto Sans SC','Noto Sans JP',system-ui,sans-serif"`。
  コードと項目名には等幅の組み合わせ `'DM Mono',ui-monospace,monospace` を使います。
- 線幅は 1.5px、角丸は 2〜4px。グラデーション、影、発光、グラスモーフィズムは使いません。
- 矢印は `marker` か単純な三角形で描き、レンダラーによって消えないよう必ず `fill` を指定します。
- 文字は枠線に寄せず、四方に最低 20px の内側余白を取ります。
- 図の中に中国語は入れません（上記「一つだけ描く」）。三言語で別々の版を保守せずに済みます。
