# 包围符号编辑：mini.surround

要给一列数字加引号、把 `(` 改成 `[`、删掉一层的括号——手动做是「移到开头、插入、移到结尾、插入」。

mini.surround 把这件事变成 **三个字母加一个目标符号**。

---

## 1. 它解决什么问题

| 任务 | 手动 | mini.surround |
|---|---|---|
| 给词加引号 | `i"` `<Esc>` `a"` `"` | `gsa"` |
| 改 `(` 为 `[` | 找两个括号各改一次 | `gsr([` |
| 删掉外层引号 | 找两处删 | `gsd"` |
| 给整行加括号 | 手动两端 | `gsa(` （视觉模式选中后） |

## 2. 你的配置

`lua/plugins/mini-surround.lua`：

```lua
mappings = {
  add = "gsa",
  delete = "gsd",
  replace = "gsr",
  find = "gsf",
  find_left = "gsF",
  highlight = "gsh",
  update_n_lines = "gsn",
}
```

| 按键 | 作用 |
|---|---|
| `gsa` | **add**：添加包围符号 |
| `gsd` | **delete**：删除包围符号 |
| `gsr` | **replace**：替换包围符号 |
| `gsf` | **find**：向前找下一个包围符号 |
| `gsF` | **find_left**：向后找 |
| `gsh` | **highlight**：高亮当前所在包围 |
| `gsn` | 更新搜索行数（默认 20 行） |

`gs` 前缀是固定的，后面跟操作字母，再跟**目标符号**。

## 3. 添加：`gsa`

### 基本用法

光标在词上，`gsa` 后跟符号：

```text
gsa"      给当前词加双引号
gsa'      加单引号
gsa)      加圆括号（自动匹配成 ( )）
gsa(      同上
gsa]      加方括号
gsa}      加花括号
gsa<      加尖括号
```

### 加在整行上

```text
gsa<CR>   给当前行加换行包围？不——需要先选中
```

正确做法：先在**可视模式**选中多行，再 `gsa)`。这样每行都会加括号。

实测思路（COBOL 场景）：

```text
V 选中 3 行
gsa"      每行都加上了双引号
```

### 自定义符号

可以输入任意字符串作为包围：

```text
gsa<space>   加一个空格
gsa DIVISION.
```

mini.surround 支持「输入自定义文本作为包围符号」，README 里写作 `gsa` 后输入 `f`（find right）等特殊键。**实际使用时最常用的是单字符符号。**

## 4. 删除：`gsd`

```text
gsd"      删掉最近的引号对
gsd)      删掉最近的括号对
gsdb      删除最近的一对，任意类型
```

`gsdb`（b = bracket）会删除**最近的**包围符号，不管是什么类型。不知道外面是哪种括号时用它。

## 5. 替换：`gsr`

```text
gsr("     把 ( ) 换成 " "
gsr)'     把 ( ) 换成 ' '
gsr*}     把 { } 换成 * *
```

**先写旧的，再写新的**。两个字符连续输出。

## 6. 查找与高亮

| 命令 | 作用 |
|---|---|
| `gsf"` | 向前找到下一个 `"` |
| `gsF"` | 向后找到上一个 |
| `gsh` | 高亮当前光标所在的那一对 |

`gsh` 特别有用：光标在一堆嵌套括号里时，按一下就知道自己在哪一层。

## 7. COBOL 里的实用场景

### 场景一：给一批字段加引号

```cobol
01  WS-FLAG-A  PIC X(1) VALUE A.
01  WS-FLAG-B  PIC X(1) VALUE B.
```

让 `A` 和 `B` 变成 `"A"` 和 `"B"`：

1. 光标在 `A` 上
2. `gsa"`

更高效的方式：用多光标（`<leader>n` 逐个匹配）后一次 `gsa"`。

### 场景二：改掉 `PIC X(10)` 的括号

```text
光标在 (10) 内
gsr(]    括号从 ( ) 变成 [ ]  ← 语法上 demo 用，实际 COBOL 不用方括号
```

**注意**：COBOL 的 `PIC` 只接受圆括号。这里的例子只演示替换动作本身。

### 场景三：给 `COPY` 的文件名加引号

```cobol
COPY ACCOUNT-REC.CPY.
```

变成：

```cobol
COPY "ACCOUNT-REC.CPY".
```

1. 光标在 `ACCOUNT-REC.CPY` 上
2. `gsa"`

### 场景四：删掉多余的括号层级

```cobol
COMPUTE X = ((A + B)).
```

光标在内部，`gsd)` 删掉一层，变成 `COMPUTE X = (A + B).`。

## 8. 练习

### 练习 1：加引号

```sh
cd ~/development/cobol
nvim lessons/23_copybooks/lesson.cob
```

1. 找到一条 `COPY 文件名.` 语句
2. 光标在文件名上
3. `gsa"`

**验收**：文件名被引号包围。

### 练习 2：改括号类型

在任意含 `( )` 的行上：

1. 光标在括号内
2. `gsr("[`

**验收**：`(` 和 `)` 变成了 `[` 和 `]`。

### 练习 3：删除一层

1. 找一行有两层括号的算术表达式
2. 光标在内层
3. `gsd)`
4. `u` 撤销

**验收**：只删掉了最近的一层，外层保留。

### 练习 4：`gsh` 定位

1. 找一段嵌套括号的 `COMPUTE`
2. 光标放中间
3. 按 `gsh`

**验收**：能看到当前所在的那一对括号被高亮。

### 练习 5：多行批量加括号

1. `V` 选中 3 行 `DISPLAY` 语句
2. `gsa(`

**验收**：三行各自都被括号包围（不是整体包围一次）。

### 练习 6：配合文本对象

1. `viq` 选中引号内容
2. `gsa'` 变成单引号包裹

**验收**：能组合使用文本对象和 surround。

## 9. 踩坑

### `gsa` 没反应

确认是 `gsa` 不是 `gsA`。并且要**连着一个符号**：`gsa"` 而不是只按 `gsa`。

### 替换后符号不匹配

`gsr("[` 的顺序是「旧符号 → 新符号」。写成 `gsr["(` 会尝试把 `[` 换成 `(`，找不到就什么也不做。

### 找不到目标符号

默认只向上/下搜索 20 行。嵌套很深时用 `gsn` 增加：

```text
gsn100
```

### `gsd` 删错层

它删**最近**的一层。光标位置很关键——先 `gsh` 确认高亮的是你要删的那层。

### COBOL 注释行里的括号

注释行（第 7 列是 `*`）里的括号也会被识别。操作前确认光标不在注释里。

## 11. 边界

- 本篇按键来自你的配置（`lua/plugins/mini.surround.lua`），默认前缀是 `gs`。
- 搜索范围默认 20 行，可用 `gsn` 调整。
- COBOL 的 `PIC` 语法只接受圆括号，`gsr("[` 这类替换在 COBOL 里只适合演示动作本身，不要用在真正的 `PIC` 子句上。
- 批量给多行加符号时，先在可视模式选中，再 `gsa`；它会对**每一行**分别加，不是包围整个选区。
