# Enterprise COBOL Batch Curriculum Design Entry

This directory records the production baseline for the next version of the curriculum. The curriculum follows a single banking overnight batch system across 12 modules and an estimated 76 hours, with emphasis on sequential matching, JOB orchestration, incident investigation, and maintenance of existing systems.

1. [Production specification and implementation sequence](../../tasks/prd-enterprise-cobol-course.md)
2. [Complete 12-module syllabus](SYLLABUS.md)
3. [Banking case, data contracts, and JOB Flow](BANK-SYSTEM.md)
4. [Material requirements, tests, and graduation acceptance](AUTHORING-STANDARD.md)

Implementation is underway in stages. See the [curriculum production entry](../../curriculum/README.md) for the actual code, acceptance entry points, and unfinished work. The legacy 00–29 lessons are archived in [`legacy-workshop/`](../../../legacy-workshop/README.md); do not claim that the new curriculum is complete on that basis. Proceed in this order: technical validation → module 07 benchmark → foundation chain → engineering chain → incidents and graduation. Passing an individual lab does not mean the module is complete.
