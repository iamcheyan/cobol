# 第 06 课修改练习参考答案

本答案只覆盖 `exercise.md` 中对 `WS-LAST-SAMPLE` 的修改，不提供举一反三练习答案。每种取值都从原始 `lesson.cob` 开始，编译和运行命令使用 README 中的 `build/` 流程：

```sh
cobc -fsyntax-only lesson.cob
cobc -x -Wall -o build/lesson_06 lesson.cob
./build/lesson_06
```

## 最后序号为 0

修改为 `01 WS-LAST-SAMPLE PIC 9 VALUE 0.`。初始索引为 1，`1 > 0` 在循环体执行前成立，因此没有样例行：

```text
最終サンプル番号=0
処理件数=000
```

## 最后序号为 1

修改为 `01 WS-LAST-SAMPLE PIC 9 VALUE 1.`。只处理序号 1；递增为 2 后，`2 > 1`，循环结束：

```text
最終サンプル番号=1
例=001 符号=D 額=125.50
処理件数=001
```

## 最后序号为 3

保留原始初值，三笔固定样例各处理一次：

```text
最終サンプル番号=3
例=001 符号=D 額=125.50
例=002 符号=W 額=040.10
例=003 符号=T 額=075.00
処理件数=003
```

## 最后序号为 4

修改为 `01 WS-LAST-SAMPLE PIC 9 VALUE 4.`。索引 4 仍小于等于上限，所以循环体执行；但示例只定义了三个样例，第四轮由 `WHEN OTHER` 标记：

```text
最終サンプル番号=4
例=001 符号=D 額=125.50
例=002 符号=W 額=040.10
例=003 符号=T 額=075.00
例=UNMAPPED
処理件数=004
```

严格大于条件 `index > last` 只在索引超过上限后为真，所以最后序号本身会被处理。
