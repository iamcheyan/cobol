# 固定バイナリフィクスチャ

すべての `.dat` ファイルは [../scripts/generate-fixtures.py](../scripts/generate-fixtures.py) によって決定論的に生成されます（外部の乱数や seed への依存はありません）。各レコードは 7 バイトの `PIC S9(11)V99 COMP-3` で、ファイル内に LF やその他の区切り文字はありません。SHA256 ハッシュは [SHA256SUMS](SHA256SUMS) を参照してください。

- `normal/mixed-valid.dat`：正数、負数、正のゼロ、負のゼロ、最大金額を各 1 レコード。
- `boundary/`：空ファイル、正のゼロ、負のゼロ、最大金額。
- `invalid/`：不正な数字ニブル `0xA`、不正な符号ニブル `0xF`、6 バイトの途中切れ、8 バイト（位置ずれ）。

フィクスチャを更新したら、まず 16 進差分を確認し、その後 `../expected/` の手計算を独立して照合してください。プログラム出力から答えを逆生成してはいけません。不正なバイトは、README に「不正データ」と記述するだけでなく、実際のバイトとしてコミットされています。
