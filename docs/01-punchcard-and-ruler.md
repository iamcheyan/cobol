# 第 1 课：穿孔卡 80 列标准与标尺列穿梭实战 (Punch Card & Navigation)

欢迎开始 COBOL 现代开发环境的第一课！COBOL 是计算机历史上最具生命力的商业语言之一，现代银行、保险、证券等关键金融基础设施的核心账务系统每天依然在运行着成百上千亿行的 COBOL 代码。

在开始编写业务逻辑前，我们必须掌握 COBOL 独特的**固定参考格式（Fixed Reference Format 80 Columns）**。

---

## 1. 核心理论：为什么是 80 列？

现代程序员习惯自由缩进，但标准 COBOL（ANSI 68/74/85）诞生于**穿孔纸卡（80-Column Hollerith Punch Card）**时代。代码是一行行打在卡片上的，卡片只有 80 列物理宽度，因此 COBOL 对每列的定义有着严格的法律级标准：

```text
列号: 1----6  7   8---11  12---------------------------------------------72  73----80
区域: SEQ    IND  Area A  Area B (语句主体)                                  IDENT
Winbar:..SEQ.  *    A...    B............................................72  IDENT...
标尺:        │   │       │                                                │
代码: 000100      0000-MAIN-LOGIC SECTION.
```

### 五大区域职责速查

| 列范围 | 区域名称 (Area) | 语法规则与用途 |
|---|---|---|
| **1 ~ 6** | **Sequence Number (序号区)** | 历史上记录卡片编号（防止整盒卡片掉在地上弄乱顺序）。现代项目中通常留空或填 6 位行号，编译器默认忽略。 |
| **7** | **Indicator (指示列)** | **控制行属性**：<br>• `*`：整行作为注释（必须在第 7 列！）；<br>• `/`：换页并在打印时分页；<br>• `-`：字符串跨行续行。 |
| **8 ~ 11** | **Area A (A区)** | **结构定义区**（必须顶格在第 8 列开始）：<br>• 四大 Division 声明（`IDENTIFICATION DIVISION.` 等）；<br>• 各 Section 节名与 Paragraph 段落名；<br>• 根级记录变量 `01`、独立变量 `77`；<br>• 文件描述符 `FD` / `SD`。 |
| **12 ~ 72** | **Area B (B区)** | **执行语句区**（必须从第 12 列或之后开始）：<br>• 所有具体业务指令（`MOVE`, `PERFORM`, `IF`, `OPEN`, `DISPLAY` 等）；<br>• 从属数据项变量（`05`, `10`, `15` 等）；<br>• 条件变量名（`88` 级）。 |
| **73 ~ 80** | **Identification (识别区)** | 历史上打孔记录程序代号。**严正警告：现代 GnuCOBOL/IBM 编译器会彻底忽略 73 列以后的任何代码字符！** 越界代码会被直接截断，是 COBOL 新手最容易踩的隐蔽致命 Bug。 |

## 2. 插件配备的辅助利器

配合本插件 `cobol.nvim`，无需手动去数空格，你拥有以下现代化辅助：
1. **纯细线标尺（`│`）**：精准标在第 7、8、12、73 列，无粗糙背景色块，文字处自动避让。
2. **Winbar 打孔卡刻度**：窗口顶部常驻 `..SEQ.*A...B...72IDENT`，刻度与下方代码绝对垂直对齐。
3. **72 列越界标红告警**：超出 72 列的代码自动加亮红色波浪下划线警告。
4. **快捷列穿梭按键**：一键直达各个关键列。
5. **智能 Tab 吸附**：行首按 Tab 自动对齐到第 8 列或第 12 列。
6. **第 7 列智能注释**：精准在第 7 列切换 `*`，绝不改动代码原有缩进。

## 3. 实操任务清单 (Step-by-Step)

请在终端中打开测试文件开始演练：

```bash
cd /home/tetsuya/development/cobol
nvim INPUTCSV.COB
```

### 任务 1.1：观察标尺与刻度对齐
1. 观察窗口顶部 Winbar 刻度：
   ```text
   ..SEQ.*A...B..........................................72IDENT... [ PROCEDURE > 2000-PROCESS ]
   ```
2. 观察编辑器内的 4 根纯细钢蓝竖线 `│`，分别对应第 7 列（Indicator）、第 8 列（Area A）、第 12 列（Area B）与第 73 列（Past Area B）。
3. 观察代码字符所在位置：竖线在文字处自动让位，在空行或短行贯穿整屏。

### 任务 1.2：列跳转快捷键穿梭练习
在 Normal 模式下，光标停留在任意一行：
1. 按下 **`g8`**：光标瞬间精准停在 **第 8 列**（Area A 起始列）；
2. 按下 **`g12`**：光标瞬间精准停在 **第 12 列**（Area B 起始列）；
3. 按下 **`g7`**：光标停在 **第 7 列**（Indicator 注释列）；
4. 按下 **`g73`**：光标直跳 **第 73 列**（Identification 区起始列）。

> 💡 **练习技巧**：多连续按几次 `g8` -> `g12` -> `g7`，形成列穿梭的肌肉记忆。

### 任务 1.3：标尺与刻度一键开合
1. 在 Normal 模式下按下 **`<leader>uc`**；
2. **观察效果**：整个 COBOL 标尺线与顶部的打孔卡刻度瞬间隐藏，界面回归干净的极简模式；
3. 再次按下 **`<leader>uc`**：标尺与 Winbar 刻度瞬间重新唤醒。

### 任务 1.4：体验智能 Tab 自动吸附
COBOL 规则要求段落在第 8 列，语句在第 12 列。以往需要狂按空格键，现在只需按 Tab：
1. 找到一个空行，按下 `o` 进入插入模式；
2. 此时光标位于第 1 列，按下一次 **`<Tab>`** 键；
3. **观察**：光标没有按普通 4 空格缩进，而是**智能吸附并精准停在第 8 列（Area A）**！此时适合输入段落名（如 `3100-MY-LOGIC.`）；
4. 再次按下一次 **`<Tab>`** 键；
5. **观察**：光标**智能吸附并停在第 12 列（Area B）**！此时适合输入具体语句（如 `DISPLAY "HELLO".`）；
6. 按 `<Esc>` 退出插入模式。

### 任务 1.5：第 7 列智能注释切换
在 COBOL 中，如果在第 1 列写 `#` 或 `//` 会直接编译报错；普通注释插件往往直接在行首加 `*` 导致整行代码缩进错位。
1. 将光标停留在刚才输入的代码行上；
2. 按下 **`<leader>c*`**（或者输入 `:CobolToggleComment`）；
3. **观察**：光标行的第 7 列自动填入了 `*` 注释符，整行变成合法的 COBOL 注释行，后方的代码缩进完全保持原样！
4. 再次按下 **`<leader>c*`**：第 7 列的 `*` 自动移除，行代码恢复正常执行态；
5. **多行批量注释**：按下 `V` 进入 Visual 行选模式，按 `j` 选中 3 行代码，按下 **`<leader>c*`**，观察选中的多行同时在第 7 列完成注释切换。

### 任务 1.6：触发 72 列越界安全防线
1. 移动光标到任意一行尾部（例如第 99 行 `MOVE ... TO OUTPUT-RECORD`）；
2. 进入插入模式，在行尾输入一长串连续字符，直到光标超过第 72 列；
3. **观察效果**：从第 73 列开始的所有文字字符，立即亮起显眼的**暗红底色 + 亮红波浪下划线**警告！
4. **思考**：这些波浪线字符一旦进入编译器就会被直接丢弃，若写在 72 列之后会导致代码逻辑缺失甚至编译器报不可思议的错。按 `u` 撤销这次越界输入。

## 4. 本课速查总结

| 按键 / 命令 | 模式 | 效果说明 |
|---|---|---|
| `g7` | Normal | 直跳第 7 列（Indicator 列） |
| `g8` | Normal | 直跳第 8 列（Area A 起始） |
| `g12` | Normal | 直跳第 12 列（Area B 起始） |
| `g73` | Normal | 直跳第 73 列（Identification 识别区起始） |
| `<leader>uc` | Normal | 一键开启/关闭细线标尺与打孔卡刻度 |
| `<leader>c*` | Normal / Visual | 在第 7 列智能切换 `*` 注释标记（单行或批量多行） |
| `<Tab>` | Insert | 行首或前导空白处按 Tab：1~6 列吸附到 8 列，7~11 列吸附到 12 列 |
