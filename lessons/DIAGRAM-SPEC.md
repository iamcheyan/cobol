# 课程配图规范

本文件规定课程 Markdown 里 SVG 配图的画法，保证 32 课的图看起来是同一套东西。
新加图之前先读这里，照着已有的 `lessons/01_hello-cobol/assets/fixed-format-columns.svg` 写。

## 什么时候该配图

只有当**图形能替代一大段文字**时才画。典型合格场景：

- 字节布局、字段偏移、同一存储的多种视图；
- 数据在阶段之间的流动（读取 → 校验 → 匹配 → 写出）；
- 两条流并行推进、归并、分支去向；
- 状态机与生命周期（打开 / 取数 / 关闭）；
- 抽象概念的对比（顺序查找 vs 二分查找、三种参数传递）。

不合格、不要画：

- 只是把正文的列表或表格重画一遍；
- 语法演示（代码块已经够）；
- 纯装饰（图标、色块、流程箭头绕一圈回到原处）。

## 文件位置与引用

- 每个图放在对应课的 `lessons/<课>/assets/` 下，文件名用英文短横线小写，例如
  `record-layout.svg`、`file-match-flow.svg`。
- Markdown 里用相对路径引用：`![说明](assets/record-layout.svg)`。
- 图**只做一份**，三种语言共用，因此标签一律用英文（与 COBOL 关键字、字段名一致），
  不写长句；需要解释的内容放到图注或正文。

## 画布与尺寸

- 单一 `viewBox`，不使用固定 `width`/`height`，让它按容器缩放。
- 适合正文栏宽：`viewBox` 宽度 760–980，高度按内容决定，不要超过 620。
- 最窄 350px（手机）时仍需可读：正文字号不小于 11px，标签不要挤在 20px 以内。

## 颜色（与站点一致）

| 用途 | 值 |
| --- | --- |
| 卡片底 | `#fcfbf7` |
| 卡片描边 | `#d8d2c3` |
| 主文字 | `#3f3b3b` |
| 次要文字 | `#5f5b52` |
| 强调/链接 | `#76319f` |

分区用色（填充 0.16 透明度 + 实线描边）：

| 语义 | 值 |
| --- | --- |
| 中性 / 输入输出 | `#64748b` |
| 注意 / 指示区 | `#d97706` |
| 数据 / 成功 | `#0d9488` |
| 主流程 | `#2563eb` |
| 错误 / 拒绝 | `#b91c1c` |

## 绘制要求

- 每个 SVG 自带浅色圆角卡片底（`rect` + `rx="10"`），这样在明暗两种主题下都是
  “一张图”，不会出现黑底黑字。
- 字体：`font-family="'DM Sans','Noto Sans SC','Noto Sans JP',system-ui,sans-serif"`；
  代码/字段名用等宽：`'DM Mono',ui-monospace,monospace`。
- 线宽 1.5px；圆角 2–4px；不用渐变、阴影、发光、玻璃拟态。
- 箭头用 `marker` 或直接画三角，务必带上 `fill` 以免在某些渲染器里消失。
- 文字不贴在边框上，四周留至少 20px 内边距。
- 中文不出现在图里（见上文“只做一份”），避免三种语言各维护一套。
