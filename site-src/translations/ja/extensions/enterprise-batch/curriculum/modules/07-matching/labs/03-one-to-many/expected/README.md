# 独立した期待値

テキストは業務方針と取引ごとの手計算から決定しています。`normal.txt`では口座1が1000+500−200−500=800で終了します。取消は直前でない最初の取引を特定し、4件目は当座貸越で拒否されます。凍結口座の残高50は変わらず、口座3には取引がなく残高0です。入力5件 = 受理3件 + 拒否2件、期首合計1050 + 貸方500 − 借方700 = 期末850です。

`boundary-aggregate-over-13.txt`では口座1に2ラウンドあり、それぞれ貸方/借方9,000,000,000,000です。各回の口座期末は有効で、貸方と借方の累計はそれぞれ18,000,000,000,000です。続いて口座2に9,000,000,000,000を貸方計上します。したがって全体の貸方は27,000,000,000,000、借方は18,000,000,000,000、期末残高は9,000,000,000,000です。全体金額に誤って13桁を使う実装を検出するケースです。

各業務拒否のexpectedには拒否理由と拒否後の残高を明記しています。RC8フィクスチャにはexpected公開レポートがありません。期待結果は公開ディレクトリなしです。`check.py`は全出力をバイト単位で比較するため、ファイル全体をtrimして固定幅の差を隠してはいけません。
