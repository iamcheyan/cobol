本节只使用第 23–28 课讲过的内容：Copybook、`CALL ... USING BY REFERENCE`、`LINKAGE SECTION`、段落、`EVALUATE`/`IF`、`STRING` 与批处理构建脚本。

## 修改练习（会在 `answer.md` 提供参考答案）

两项都从原始源码开始，改完必须用 `./build.sh run` 重跑——脚本会重新编译两个子程序、重新链接主程序，改动才会生效：

```sh
./build.sh check      # 组合语法检查
./build.sh run        # 重新编译、链接并在 build/ 里运行
echo $?               # 退出码
./build.sh clean      # 清理 build/
```

1. 把 `1300-POST-OVERDRAFT` 里的 `2000.00` 改为 `1000.00`。确认这笔取款从拒绝变为成功、最终余额与 `記帳`/`拒否` 计数随之变化，并核对 `build/batch.log` 第三条交易事件的状态。
2. 恢复原始源码后，把 `1400-POST-UNKNOWN-TYPE` 里的类型从 `"X"` 改为 `"D"`。确认过账模块返回 `POSTED`、账户报告反映这笔存款，且日志仍使用同一个交易序号 `004`。

**正确性判据：** 每项都要同时核对标准输出、`build/batch.log` 与计数不变量（`記帳 + 拒否 = 5`）；只改测试夹具或只重跑不重新链接都不算完成。两项练习都要说明控制流：`CALL` 在哪一段发出、`GOBACK` 把控制返回到哪里、计数在哪一侧增加。

参考答案见 `answer.md`。
