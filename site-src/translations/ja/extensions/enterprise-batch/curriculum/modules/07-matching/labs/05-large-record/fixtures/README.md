# L4 フィクスチャ

旧/新ファイルは`ENTERPRISE-CUSTOMER-V1`の固定幅バイナリレコードストリームです（1レコード1,778バイト、区切り文字やLFなし）。値は合成ASCIIで、フィールド単位の比較規則を試せるよう構成されています。`old.dat`と`new.dat`には一致、旧のみ、新のみの顧客キーと、RAW、TEXT-NORM、NUMERIC、IGNORE-AUDITの動作を確認する変更が含まれます。

フィクスチャを直接編集しないでください。変更演習には作業コピーを使い、原本ハッシュを保持します。独立検証ツールはフィールドオフセット、値、比較分類、出力manifest全体を確認します。
