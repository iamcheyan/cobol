# 第 05 课修改练习参考答案

本答案只覆盖 `exercise.md` 的四个代码修改，不提供举一反三练习的分类答案。每次从源码初始版本出发，只改变一条 `VALUE` 子句。

`VALUE "W"` 时：

```text
TRANSACTION-REFERENCE=TXN-00000001
TRANSACTION-CODE=W
CATEGORY=WITHDRAWAL
ACTION=SUBTRACT_FROM_ACCOUNT
```

`VALUE "T"` 时：

```text
TRANSACTION-REFERENCE=TXN-00000001
TRANSACTION-CODE=T
CATEGORY=TRANSFER
ACTION=PROCESS_BOTH_ACCOUNTS
```

`VALUE "X"` 时：

```text
TRANSACTION-REFERENCE=TXN-00000001
TRANSACTION-CODE=X
CATEGORY=UNKNOWN
ACTION=REJECT_FOR_REVIEW
```

`VALUE "d"` 时：

```text
TRANSACTION-REFERENCE=TXN-00000001
TRANSACTION-CODE=d
CATEGORY=UNKNOWN
ACTION=REJECT_FOR_REVIEW
```

`X` 没有对应的 `WHEN` 值；`d` 与大写 `D` 不相同。两者都走 `WHEN OTHER`。`REJECT_FOR_REVIEW` 只是程序输出的动作标签，本课没有实现真实拒绝流程。
