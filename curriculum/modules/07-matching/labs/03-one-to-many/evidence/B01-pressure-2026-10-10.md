# B01 memory and throughput observations (2026-10-10)

The intended check measures the matcher child process only (`wait4.ru_maxrss`, KiB). Input generation, external `cut`/`sort`/`uniq`, and the Python checker are outside the measurement. The uniqueness precheck writes IDs and sorted results to files; it does not capture the full ID stream in Python memory. Each tier independently validates the report, accepted raw transaction stream, rejected stream, and full 47-byte closing-master output.

- Session 5167 ended RC 1 and printed `bounded_growth_pass=false`: micro RSS 17,468 KiB; 10k accounts/100k transactions 28,860 KiB (4.465 s); 100k accounts/1m transactions 125,632 KiB (48.327 s); one account/100k same-key group 125,632 KiB (4.695 s), growth 108,164 KiB.
