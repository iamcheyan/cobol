# 夹具清单

所有数据均为合成ASCII，正常账户记录47字节、交易55字节，LF另计1字节。唯一二进制异常是 `invalid/transaction-nul.dat`，第11字节为真实00，不是文字“\\0”。`transaction-no-lf.dat`故意没有末尾LF。

`normal` 为完整三类突合；`boundary` 的empty可用于任一侧，single文件覆盖首条=末条的情况。invalid文件名标明应替换哪一侧，其他输入使用normal；全部预期RC8且不发布输出。文件缺失请传不存在的路径，预期RC12。

在本目录执行 `sha256sum -c SHA256SUMS` 验证原始数据未被修改。不要直接编辑夹具练习；先复制到自己的临时目录。异常夹具的详细根因放在讲师说明；文件名在此基础课明确暴露原因，后续事故课会使用隐藏根因的发放包。
