# 画面内の高速ジャンプ：flash.nvim

`snacks picker` は「探す対象が分かっていて、文字で検索する」。**flash は「見えているが、カーソルをそこへ運べない」。**

72 桁の COBOL 文、画面に 50 行、カーソルは 8 行 12 桁、目標は 45 行 60 桁。行数と空白を数えるか、`45G` + `60|`。どちらも先に番号を知る必要があります。

flash は**見えている目標に向かって打つ**だけです。`s` を押し、目標付近の文字を 1 つ入力すると、画面中の一致位置に文字ラベルが付きます。その文字を押せば移動完了です。

---

## 1. 何を解決するか

非効率な 3 つの移動：

| やり方 | 問題 |
|---|---|
| `j` / `k` で 1 行ずつ | 長距離だと数十回押す |
| `45G` | 先に行番号を数える必要がある |
| `/pattern` + `<CR>` | 一意な検索文字列が要る。次に進むだけ |

flash の利点：**1 回の入力、複数の候補、ラベルで直接移動**。正規表現より弱いのではなく、正規表現より速いだけです。

## 2. 実際の設定

`lua/plugins/flash.lua` に 3 つのキーだけがあります。

```lua
{ "s", mode = { "n", "x", "o" }, function() require("flash").jump() end, desc = "Flash" },
{ "S", mode = { "n", "x", "o" }, function() require("flash").treesitter() end, desc = "Flash Treesitter" },
{ "<c-s>", mode = "c", function() require("flash").toggle() end, desc = "Toggle Flash Search" },
```

| キー | モード | 動作 |
|---|---|---|
| `s` | n / x / o | 任意の位置へ移動 |
| `S` | n / x / o | **Treesitter ノード**単位で移動 |
| `<C-s>` | コマンドライン | 検索中に flash を切替 |

**`r` と `R` は削除されています**（設定内でコメントアウト）。理由は設定に書かれているとおり `substitute.nvim` との衝突回避です。したがってネット上のチュートリアルにある `r`（remote flash）は**この環境では使えません**。

`o` モードは operator-pending で、`d` `s` のような組み合わせに使います。

## 3. 基本：`s` + 文字 + ラベル

### 3 ステップ

```text
1. s を押す
2. 目標位置にある文字を 1 つ入力
3. 画面に出たラベルの文字を押す
```

実測（`A` が多数ある行で `s` → `A`）：

```text
   IDENTIFICAaION DIVISION.
   PROGRAM-ID. FLAdHTEST.
   DAfAgDIVISION.
   WORKING-STORAhE SECTION.
   01 WS-AjPHAkPIC X(10) VAlUE "Aqwertyuiop.
```

すべての `A`（大文字小文字を区別しない）の後ろに小文字ラベルが付きます。

| ラベル | 位置 |
|---|---|
| `a` | 1 行目 `IDENTIFICATION` の `A` |
| `d` | 2 行目 `FLASHTEST` の `A` |
| `f` | 3 行目 `DATA` の `A` |
| `h` | 4 行目 `WORKING-STORAGE` の `A` |
| `j` | 5 行目 `WS-ALPHA` の `A` |
| `k` | 5 行目 `PIC` の後の `A` |

`j` を押すと 5 行目 `WS-ALPHA` の `A` へ移動しました（実測 `col(".")` は `14`）。

### 候補が多すぎる場合

ラベルが尽きると（通常 26 個）、flash は追加の 1 文字を要求して範囲を絞ります。**そのまま打ち続けてください**。やり直しにはなりません。

### 中止

`<Esc>` でカーソルを動かさずに終了します。

## 4. `s` と操作子の組み合わせ

`s` は `o`（operator-pending）モードでも効くため、`d`、`c`、`y`、`v` と組み合わせられます。

| 組み合わせ | 意味 |
|---|---|
| `d` `s` `)` | 次の `)` まで削除 |
| `c` `s` `X` | 次の `X` まで変更 |
| `y` `s` `;` | 次の `;` までコピー |
| `v` `s` `}` | 次の `}` まで選択 |

考え方：行頭で `ds"` と押し、ラベルを選ぶと**その**引用符まで削除します。**`dt"` より強力**です。`dt"` は最も近い 1 つにしか届きません。

### COBOL での実用的な組み合わせ

```text
d s )      ある括弧まで削除 — PIC X(10) の処理に便利
v s "      ある引用符まで選択 — 文字列リテラルを掴む
c s .      あるピリオドまで変更 — 文の半分を書き換える
```

## 5. `S`：構文ノードで移動

`S` は Treesitter を使って**構文ノードの開始位置**を探します。任意の文字ではなくノード境界にだけラベルが付くため、数はぐっと少なくなります。

実測（同じ COBOL ファイルで `S`）：

```text
abcIDENTIFICATION DIVISION.
PROGRAM-ID. FLASHTEST.a
```

ラベルは 2 つだけでした。`IDENTIFICATION` の先頭（文全体のノード）とファイル末尾で、これがトップレベルのノード境界だからです。

### `S` と `s` の使い分け

| 移動したい先 | 使うもの |
|---|---|
| 特定の文字 | `s` |
| 次の段落や文の先頭 | `S` |
| 括弧や引用符 | `s` |
| 次の関数や段落定義 | `S` |

COBOL では段落（`0100-INIT.`）、`SECTION`、`DIVISION` の先頭へ飛ぶのに `S` が特に有効です。これらは明確な構文ノードだからです。

**前提**：Tree-sitter の COBOL パーサーが必要です。無い場合 `S` は何もラベルしません。確認：

```vim
:lua print(vim.treesitter.language.add("cobol"))
```

## 6. `<C-s>`：コマンドラインでの flash

コマンドラインモードで `<C-s>` を押すと、`/` 検索が flash モードになります。検索中に一致位置がラベル表示され、ラベルで直接移動できます。

```text
/WS-RECORD<C-s>
```

検索語が長い、一致が多い、N 番目へ一気に飛びたい、といった場合に有効です。

## 7. 実測記録

| 操作 | 観察結果 |
|---|---|
| `s` を押す | 入力待ち状態になり、ラベルは出ない |
| `A` を入力 | すべての `A` の後ろに小文字ラベルが出る |
| `j` を押す | 5 行目 `WS-ALPHA` へ移動、`col()` = 14 |
| `S` を押す | 構文ノード境界にのみラベル（本例では 2 個） |
| `<Esc>` を押す | カーソルを動かさず終了 |

## 8. 演習

### 演習 1：基本の移動

```sh
cd ~/development/cobol
nvim lessons/17_fixed-length-files/lesson.cob
```

1. `s` を押す
2. `D` を入力
3. ラベルの分布を見て、1 つ押す

**合格条件**：押したラベルの `D` にカーソルが乗ること。`:echo line(".").":".col(".")` で確認します。

### 演習 2：画面をまたぐ移動

1. `gg` で先頭へ
2. `s` を押して `PIC` を入力
3. ファイル後半のラベルを選ぶ

**合格条件**：1 回のキー操作で後半へ移動し、行数を数えていないこと。

### 演習 3：操作子との組み合わせ

破棄してよいコピー上で：

1. ある行の先頭にカーソルを置く
2. `d` `s` と押し、`"` を入力してラベルを選ぶ
3. `u` で元に戻す

**合格条件**：削除範囲が**選んだ引用符**までで、最も近いものではないこと。

### 演習 4：`S` で段落へ移動

1. `gg`
2. `S` を押す
3. ラベルが構文ノード境界にだけ出ることを確認

**合格条件**：`s` で頻出文字を指定したときより明らかにラベルが少ないこと。

**比較実験**：`s` で `D` を入力してラベル数を数えると、`S` と `s` の差が分かります。

### 演習 5：コマンドラインの flash

1. `/WS-RECORD-COUNT<C-s>`
2. 一致にラベルが付くのを確認
3. ラベルで移動

**合格条件**：`n` を押さずに目的の箇所へ移動できること。

## 9. つまずきやすい点

### `r` / `R` が効かない

設定で**意図的に削除**しています（`substitute.nvim` との衝突回避）。ネット上のチュートリアルにある remote flash や treesitter search は使えません。**これは不具合ではありません。**

使いたい場合は自分で追加し、衝突を解消する必要があります。

```lua
{ "r", mode = "o", function() require("flash").remote() end },
```

### `s` が元の `s` を上書きしている

vim 本来の `s` は「1 文字削除して挿入モードへ」です。flash がそれを奪っています。本来の動作が欲しいときは `c` `l` を使ってください。

### ラベルが見えない

`FlashLabel` ハイライトグループで制御されています。現在値を確認：

```vim
:hi FlashLabel
```

### 日本語のテキストでずれる

flash はバイト単位で位置を決めるため、マルチバイト文字（日本語コメントのかな）ではラベル位置が 1 ずれることがあります。コード部分は ASCII なので COBOL では実害が小さいです。

## 11. 範囲と限界

- 本ページのキーはローカル設定（`lua/plugins/flash.lua`）由来で、`s`、`S`、`<C-s>` の 3 つだけです。`r`/`R` は削除済みです。
- `S` は Tree-sitter の COBOL パーサーに依存します。無い場合はノードにラベルが出ません。
- 実測記録は実際のターミナルセッションによります。ラベルの文字割り当ては flash 内部のアルゴリズムが決めるため、同じファイルで 2 回押すと並びが変わる場合があります。
