# 第 04 課演習：IF 条件判定

この演習では第 04 課で扱った `WORKING-STORAGE` の `VALUE` 初期値、関係条件（`=`、`<`、`>`、`<=`、`>=`）、`IF` / `ELSE` / `END-IF`、`DISPLAY`、`STOP RUN` のみを使います。

## 変更演習（解答例は `answer.md`）

### 基準

変更されていない元の [`lesson.cob`](./lesson.cob) から始めます。各シナリオは毎回元のソースに戻して実施してください。

### 変更箇所と制約

次の2つの `VALUE` 句の初期値だけを変更します。

```cobol
       01 WS-ACCOUNT-STATUS PIC X VALUE "A".
       01 WS-TRANSACTION-AMOUNT PIC S9(7)V99
          SIGN IS LEADING SEPARATE CHARACTER VALUE 125.50.
```

`PIC`、`SIGN IS LEADING SEPARATE CHARACTER`、`WS-MAXIMUM-AMOUNT` の初期値、関係演算子、ネスト順、`ELSE` の対応関係、すべての `DISPLAY` 文言は変更しません。金額は `-0.01` のように小数2桁のリテラルで指定し、`COMPUTE`、`MOVE`、ループで境界値を作らないでください。状態は `"I"` のような1文字リテラルにします。

### コマンド

```sh
mkdir -p build                                   # 先に出力先を作成
cobc -fsyntax-only lesson.cob                    # 構文検査
cobc -x -Wall -o build/lesson_04 lesson.cob      # コンパイル
./build/lesson_04                                # 実行して判定を確認
echo $?                                          # 終了コード
```

### 7つのシナリオ

標準出力は常に6行です。`取引参照番号=` は `TXN-00000001`、`上限金額=` は `0001000.00` のままで、`口座状態=` には設定した状態が表示されます。その他は次のとおりです。

| # | 金額 `VALUE` | 状態 `VALUE` | `取引金額=` | `判定=` | `理由=` |
|---|---|---|---|---|---|
| 1 | `0.00` | `"A"` | `+0000000.00` | `REJECTED` | `AMOUNT_NOT_POSITIVE` |
| 2 | `-0.01` | `"A"` | `-0000000.01` | `REJECTED` | `AMOUNT_NOT_POSITIVE` |
| 3 | `0.01` | `"A"` | `+0000000.01` | `ACCEPTED` | `WITHIN_RULES` |
| 4 | `1000.00` | `"A"` | `+0001000.00` | `ACCEPTED` | `WITHIN_RULES` |
| 5 | `1000.01` | `"A"` | `+0001000.01` | `REJECTED` | `AMOUNT_OVER_LIMIT` |
| 6 | `125.50`（初期値のまま） | `"I"` | `+0000125.50` | `REJECTED` | `ACCOUNT_INACTIVE` |
| 7 | `-5.00` | `"I"` | `-0000005.00` | `REJECTED` | `AMOUNT_NOT_POSITIVE` |

シナリオ4（金額 `1000.00`、状態 `"A"`）の出力例：

```text
取引参照番号=TXN-00000001
口座状態=A
取引金額=+0001000.00
上限金額=0001000.00
判定=ACCEPTED
理由=WITHIN_RULES
```

どのシナリオも終了コードは `0` です。

### 問い

1. 境界値の差が `0.01` だけのシナリオ1・2と3を分ける関係条件はどれですか。
2. 3と4はいずれも受理されます。理由は異なりますか。上限の端点 `1000.00` が拒否されないのはなぜですか。
3. 4と5の結果を変える関係条件はどれですか。
4. 金額が適合しているシナリオ6が拒否されるのはなぜですか。どの `ELSE` に入りますか。
5. 金額と状態の両方が不適合なシナリオ7で、理由が1つだけ表示されるのはなぜですか。状態検査は実行されますか。

各シナリオの実出力を記録し、結果を決めるソース文を示してください。解答例は [`answer.md`](./answer.md) を参照してください。

## 学んだことを応用する（解答なし）

最低金額 `5.00`、最高金額 `5000.00`、受取口座状態が `A` であることを条件とする振込検証プログラムを設計します。項目名と `PIC` を選び、符号の要否と整数桁数を説明してください。拒否理由は最初に該当したものだけを表示するため、ネスト順も決めて説明します。各端点を受理するか決め、`4.99`、`5.00`、`5000.00`、`5000.01`、金額適合時の非 `A` 状態を検証してください。符号付き項目なら負の金額も確認します。

この課の宣言、`VALUE`、関係条件、`IF` / `ELSE` / `END-IF`、`DISPLAY`、`STOP RUN` のみを使います。ループ、段落、表、`EVALUATE`、`AND`、`OR` は使いません。基準を残すため `lesson.cob` を一時ディレクトリにコピーして編集します。ソース、コマンド、各入力の実出力、各比較が分岐を決める仕組みの説明を提出してください。解答はありません。
